# 婚房一期双端测试流程

使用当前已婚的 **000** 与 **狂战弑天**，先同频道登录。保留当前婚姻进度，无需重新订婚或办婚礼。本轮只更新服务端。

## 1. 登录与进出

1. 登录双方，查看婚姻信息、配偶外观、戒指和心意点。部署时个人钱包各 20；首次选角领取当天 +1 后，预期各 **21**。同一天反复重登不能继续加点。
2. 从赛丽亚房间原生婚房门分别进入。双方应在同一婚房互相看见，移动正常。
3. A 从房门退出，确认回到来源城镇；再进入。B 在房内退出游戏，重登应在普通安全位置，重新进房后资产仍在。
4. B 切到别的频道再进房：家具/树相同，人物不应跨频道互见。切回同频道继续测。

## 2. 商店、家具与双人编辑

1. 在婚房 NPC 云清处购买一件便宜、可收回的家具。只扣购买者个人心意点，配偶点数不变；家具应进入夫妻家具保管箱，数量与购买数一致。
2. A 打开物品保管箱，B 也尝试打开：B 应得到忙碌/不能同时编辑的正常提示，不能掉线。A 关闭后 B 应能打开；再测试持有编辑权的一方退出房间或正常退出客户端后，另一方能打开。
3. 摆放家具，双方都应看到；收回后家具数量恢复；移动保管箱内部格位、堆叠，确认没有复制或丢失。
4. 删除一件可消耗测试家具，确认双方保管箱同步。点数不足或包满购买必须失败且不扣款，失败后还可继续打开保管箱/使用邮件。
5. 壁纸和地板本期不可收回；已占用槽暂不支持替换。先测普通家具，再决定是否放置这些永久装修。

## 3. 婚戒

1. 先看心意点不足时购买最低阶婚戒升级券能否正常失败，金币与点数不变。
2. 完整成功路径需要购买方至少 **50 心意点、50 万金币**。可通过 GM 邮件领取心意通 `10002901` 并使用，补到至少 50；不需要给另一方同步补点。
3. 在商店购买最低阶升级券 `10002611`：仅购买者扣 50 点和 50 万金币。双击使用，消费一张券，双方戒指应升一级；使用时不再次扣钱/点。
4. 再用同阶券或跳阶券应拒绝且不消耗。重登双方，确认等级一致且不会重复加属性。

## 4. 爱情树与奖励邮件

1. 在云清购买种子种植。三种种子为 `10002766`、`10002768`、`10002767`，先选一种即可。双方应见同一棵树。
2. 普通洒水壶 `10002765` 每次 +10，每个日周期夫妻合计只能成功浇水两次。A 浇一次、B 浇一次，再点应拒绝并保留道具。
3. 要当天测收获，可先通过 GM 邮件准备强力洒水壶 `10002905`：**在当天尚未浇水时，用一次强力水 +20、一次普通水 +10** 到 30。若先用了两次普通水，就等下一个日周期再浇到成熟；不要期望重登重置次数。
4. 任意一方收获：双方各收到一封爱情树奖励邮件，奖励独立随机，允许碰巧相同；立即重复收获不能再发奖励。树仍在，成长归零，到期时间不延长，当天用水次数不清零。
5. 下一周期继续培养并再收获，验证不是一次性树。最后再测试清除。30 天自然到期边界已有自动化，后续长期观察。

## 5. 属性与恢复

1. 摆放家具使装饰值跨过属性档位（首档 10），比较双方属性面板和婚房属性说明。
2. 依次换宠物、进普通地下城、回城、重登，确认家具与婚戒加成没有消失或逐次叠加；在决斗场核对没有婚房加成。
3. 最后双方正常退出、重新登录，确认婚戒、家具、树成长/用水、个人点数和奖励邮件均保持。

遇到问题时记录**哪一方、进行到第几步、时间、窗口原文、资产前后数量**即可。尤其观察保管箱按钮、树的浇水次数显示和成功/失败后的窗口关闭，这些仍需要 A21 原生客户端验收。
