# Specification: 幸运星与装备租赁

## Why and Outcome

当前A21已有幸运星余额/租赁面板但无法完成购星或租武器。补齐账号星币与角色真实装备生命周期闭环，部署后交用户测试。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 账号幸运星统一读写；规则读取当前PVF上限/金价/通关奖励/排除地下城及消耗品rent point。已有超过400余额保留可消费，增加不得继续超过当前上限。 |
| RQ-002 | 金币购星与扣金币原子完成；购星或兑换道具不能完整入账时整笔拒绝，免费通关奖励可封顶为0并记录已处理。 |
| RQ-003 | 按当前职业、等级、PVF商品白名单报价租赁；发真实UID武器，InventoryOnly，租期从操作捕获的一次now起24小时。按声明执行物品限制。 |
| RQ-004 | 初版同角色同模板最多一个有效租赁，重复租同模板按同一报价将原UID期限重设now+24h，不叠加剩余时间；不同模板可并存，职业与等级逐项验证。模板限制有更强客户端证据时以证据修订局部规则并记录。 |
| RQ-005 | 租赁关系绑定真实UID，期限以物品ExpireTime为真源；登录/频道重入复用通用过期物品清理，查询过滤过期或缺失实例，不复活装备。在线即时回收不新增周期，与当前PVF“换频道或重登生效”一致；在线操作不得把已过期租赁当有效续租实例。 |
| RQ-006 | 使用当前A21 CMD03CF/03D0核实的body22B，忽略内部前14B冗余，字段位于14/18；成功/拒绝载荷按客户端handler读取，统一完整NOTI03C1余额+租赁列表，不启用遗留019D。 |
| RQ-007 | 购星/租赁/消耗品在当前DomainTransaction直接结算；满包/不足/失败/重放不产生部分资产变化。通关发星绑定真实整次通关、适正判定及run+角色去重；处理重复重放不会补领已封顶旧奖励。 |
| RQ-008 | 两个核心领域服务各经规则服务读取内容；handler/命令不承担PVF解释，不创建新的装备或外观体系。变化后读取当前状态统一投影，需要角色外观时复用完整CharacterUserStateProjection。 |
| RQ-009 | 保留测试库/配置/PVF与回退输入，验证部署版本、健康、监听；实机验收由用户进行。 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001、RQ-002 | 余额0购2星扣200000金币；星币不足、金币不足、负数/溢出/超过上限拒绝且无资产变化；旧余额999保持可消费。 |
| AC-002 | RQ-003、RQ-004 | 合法商品扣正确价格并生成一个指定期限真实装备；非法模板/职业/等级/满包拒绝无扣费；同模板重复操作按续租规则保持UID且新期限不累加。 |
| AC-003 | RQ-005 | 租赁关系在持久化重开与移动/穿戴后保持；到期/缺失的UID不出现在面板中，登录/切换回收通过通用清理完成。 |
| AC-004 | RQ-006、RQ-008 | 真实PVF目录与固定无PVF夹具均可验证；协议codec/handler测试覆盖非零冗余前缀、准确成功/拒绝载荷以及完整当前状态面板。 |
| AC-005 | RQ-007 | 通关处理按run+角色只发一次，排除/不适正不发；0奖励仍去重；故障回滚金币、星币、物品、关系和去重标记。幸运星道具消耗与入账同事务。 |
| AC-006 | RQ-009 | 部署前备份完整性ok，运行身份与提交一致，健康与原监听就绪；给出购星、租赁、续租、换角色余额、重登及到期实机清单。 |

## Evidence and Choices

PVF `etc/chnrentsystem/rentsysteminfo.etc`：上限400、金价100000、pdungeon1、14职业8档；[discount rentalprice]60和[discount charge event]1存在但没有活动开启事实，初版按各package selection基础价格，不自动启用历史折扣。租期24小时来自当前装备说明。并存与重复租赁采用本Spec明确的初版行为，不冒称已ClientVerified。

协议独立取证证据：`artifacts/lucky-star-rental-20261020/clientstatic-disassembly.txt`，确认MakeHeader追加外部14B后另追加body22B；不能误减为body8B。更详细消费结构写协议人工区后，协议实现以其静态证据为依据。

资产原子性、实例UID/期限及去重结果以数据库/领域集成回归作忠实oracle，避免用服务调用次数替代行为验证；native界面、武器使用效果和期限显示仍待用户测试。
