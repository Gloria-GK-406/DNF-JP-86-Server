# 部署后的实机测试清单

自动化验证不代替下列实机验收。每项只需报告现象，可逐项执行。

1. 重新登录1123，打开镜像阿拉德选图。剩余次数应等于每日上限减数据库当日已入场数；不会凭重登恢复10次。
2. 成功进入一次镜像，加载完成后剩余数只减1；返回选图、重新登录，仍保持同一数值。
3. 尝试会被拒绝的入场（如疲劳不足或次数耗尽），次数保持不变；正常循环地下城入场不扣镜像次数。
4. 完成镜像任务并领奖一次，奖励只到账一次；重复领奖不多发、不多扣次数。
5. 使用一个已有限次规则的消耗品，UI已用次数只加1；重复点击超限/冷却中不会多消耗物品或次数，重登显示一致。
6. 使用已开通的权益（BUFF/免费金牌/免费修理等现有功能），对应次数只加1；双倍罐续期保持每日累计上限。
7. 若方便跨重置时刻测试，镜像沿用午夜，消耗品/权益沿用已有日周期；界面刷新和重登恢复正确。无需为测试改系统时间或清DB。

出现不符时保留界面，告诉我动作和角色；通过服务端日志/数据库核对，不先修改客户端。
