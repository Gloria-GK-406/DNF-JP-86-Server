# 实施计划

采用 direct 模式，一个完整计划维护入口、任务与通知的依赖，不建任务注册表。共享工作区写入者串行，读证据可并行。

1. 入口：PVF 镜像配对配置读取与规则服务，镜像入场领域服务，实际迷宫/难度/入场条件复用；布局冻结镜像包装、来源区域、任务三个身份。增加领域行为测试。
2. 当局任务：独立场次绑定状态，支持 PVF 的击杀、通关、限时、不复活、房间数量及地图目标；专用接取、触发器、结算和放弃处理。复用通用奖励效果，不写普通 active/cleared；可靠离场订阅及任务变化事件。
3. 接线：02B6 decoder/handler、原 opcode 拒绝、0278 加载顺序，共用入场 CMD 路由；地下城普通退出、放弃、断线、团灭的离场事实。普通任务保持原调用链。
4. 验证：串行构建与针对性领域/协议/持久化/架构测试，真实 PVF 配对探针；独立完整结果审查后修复并复验。
5. 交付：更新协议记录和自动化/实机边界，记录结果，仅本地提交，不部署。
