# 镜像阿拉德：入口与场次任务

日期：2026-10-10；代码基线：b9717c65。

| 要求 | 行为及验收 |
|---|---|
| RQ-001 / AC-001 | 02B6 正文两个 u32：历史地下城、镜像任务。仅有效选图上下文、队长和 PVF 配对可进入；拒绝同 opcode 回包。8000 是包装入口，实际地图采用上报历史图，复用共用入场事务与加载。 |
| RQ-002 / AC-002 | 先发送 0278(u32 当局任务)，再发送普通地下城加载；不额外发送会导致客户端重发 000F/0010 的成功 ACK。合法 001F 接取以当前 run 为授权，重复接取不重置进度。 |
| RQ-003 / AC-003 | 镜像任务单独按角色和 RunId 记录；不占普通持久任务槽，不写永久 cleared。进度与完成依据服务端事实，奖励最多一次；非当前 run 拒绝接取、进度和领奖。普通任务仍走原路径。 |
| RQ-004 / AC-004 | 地下城离场成功发布包含角色和 RunId 的事实；任务系统 Reliable 订阅清理，任务变化继续由 EventBus 投影。清理重复无副作用，旧 run 事件不影响新 run；断线及再次入场的旧状态不恢复为有效任务。 |
| RQ-005 / AC-005 | 主线任务不因镜像离场被删除；击杀/通关仍可推进合法普通任务。普通、循环入场及已有任务回归保持。 |
