# 实施与验证

1. 装备和附魔规则接管内容源，摊位选址进入规则层。复核内容边界和装备入口。
2. 职业状态存储统一入口与默认行，迁移所有消费者的事实读取。共用经验与配方解锁。复核入场、跨级与 NPC 专卖。
3. Quests 提供授职和清理，Characters 合并技能额度、选槽与写入，Inventory／Character 提供资产能力。复核任务进度、原子性及职业重选。
4. 城镇转移与会话清理传递精确摊位关闭结果，移除空营业入口。复核旧会话、投影顺序、闭店与重开。
5. 整理卡片内容和库存到达。复核卡片、普通宝珠、职业宝珠和卡片升级。
6. 审查所有迁移完成的入口，构建并跑结构、应用、协议和持久化相关测试。更新领域设计和结果记录。

工作树已有实机改动，以路由文档的快照树作为差异和恢复参照。按五组边界复核生产差异，必要时只修复该组拥有的差异。
