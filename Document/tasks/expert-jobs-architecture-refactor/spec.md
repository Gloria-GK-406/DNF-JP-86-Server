# 副职业架构重构规格

[任务契约](TaskContract.md)的 SC-1 至 SC-6 为验收条件。现有职业服务、数据库结构和协议主线作为兼容边界。静态规则由所属内容规则服务解释，职业、任务、技能和库存的实时事实来自各自领域。就职、放弃及摊位交易继续在原工作单元中结算。

关闭结果只来自关闭实际实例的摊位登记服务。协议按场景使用其精确访客和既有城镇范围。职业状态读侧对缺行按无职业解释，无职业字段归一并保留合法放弃计数。活跃职业校验可持久化的类型、经验、设备与配方。全链自动验证使用隔离数据和 dev PVF。

卡片升级复用附魔所依赖的档位读取与库存到达能力。两项业务有各自资格、费用与结算结果。
