# Specification：异界气息与异次元属性

## Outcome and Evidence Boundary

在角色自有装备上，`0x00CC` 对未鉴定气息执行净化或清除，`0x00CD` 对无属性装备赋予属性、对已鉴定装备扭转属性。材料和属性数值来自 A21 `etc/amplifyitem.etc`，不从请求信任。客户端静态可识别的响应与权威物品刷新接通；实机 GUI/实帧仍留给集中验收。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 对照 70、上游、A21 构包/响应和真实 PVF，记录 `0x80` 未鉴定状态、属性编码、材料、费用及 `0x00CD` action 2 动态尾部边界。 |
| RQ-002 | 净化/清除仅作用于未鉴定且合格装备；赋予仅作用于无属性、无升级装备；扭转仅作用于已鉴定有属性、无升级装备；错误所有权、槽位、材料、锁定、过期和状态均不结算。 |
| RQ-003 | 成功消耗实际 PVF 指定数量材料并原子写回原装备 UID、属性类型/值；保持其它字段，提交失败可回滚，重试不双扣。 |
| RQ-004 | A21 已闭合的固定请求入口得到静态接收函数能读取的结果，并在成功提交后刷新权威装备和材料；普通强化拒绝非零 `AmplifyType`，增幅升级本身不在本 Spec 偷接。 |
| RQ-005 | Human Test List 提供固定物品/材料样本、成功/拒绝/重登与日志/抓帧位置。 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001 | 证据定位到具体 ELF/上游路径、A21 RVA 和 PVF 节及样本，差异和未知单列。 |
| AC-002 | RQ-002 | 确定性测试覆盖三类状态转换及状态拒绝；无权、重复、错误模板或不足材料不改变资产。 |
| AC-003 | RQ-003 | SQLite 提交/故障注入、重读或等效实事务测试证明 UID 与无关属性保留且材料守恒。 |
| AC-004 | RQ-004 | 字节/handler 测试验证两入口的成功/失败及装备/材料更新；action 2 在动态尾未闭合前明确隔离。 |
| AC-005 | RQ-005 | Markdown 清单可让用户集中 A21 验收，并明确本轮没有 ClientVerified。 |

## Stop Boundaries

`0x00CD` action 2 会在 14 字节固定字段后经虚调用追加动态字符串，未证实尾部及材料结果前不扣资产。净化以外的异常材料不按上游猜测映射。增幅升级概率路径属于根任务外；本子项只检查普通强化对气息/属性的拒绝及未来增幅入口需要的已鉴定状态。
