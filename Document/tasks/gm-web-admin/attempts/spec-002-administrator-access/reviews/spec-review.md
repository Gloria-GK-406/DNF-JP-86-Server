## 阻塞发现

**F-1 / CH-4：成功登录响应的秘密禁止规则与 Cookie 会话交付冲突。**

`spec.md` 的 HTTP Contract 要求会话 Cookie，AC-005 要检查 TLS 下的 `Set-Cookie`；AC-002 又要求“登录响应……不得含……会话秘密”。按整份 HTTP 响应理解，登录无法把必要会话凭据传给浏览器；按仅正文理解，则现有文字没有表达这个边界，验收可能产生相反结论。

最小修复：仅澄清 AC-002 中成功登录所必需且符合规定标志的 `Set-Cookie` 是传递会话凭据的受控例外；JSON 正文、错误内容、日志和审计仍不能泄露会话秘密，数据库仍不得保存可直接重放的原始秘密。无需改变认证路线、scope、权限或其他接受条件。修复后重新审查这一处及直接一致性。
