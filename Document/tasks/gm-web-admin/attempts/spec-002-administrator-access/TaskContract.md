# TaskContract: 管理员认证、权限与操作追踪

## Context

### Source Request

根合同授权 GM 后台和典型管理功能，要求逐模块独立验收。当前已有独立启动/页面骨架，尚无管理身份或私有端点。

### Current Situation

已接受基线0630348d，共用 HTTP Host/GmWeb，管理员功能从闭合认证边界开始。

## Goal

管理员能够初始化独立身份、登录后台、注销失效，并按权限访问管理功能；管理操作可查询追踪。

## Scope

### In

- 独立管理员凭据与会话持久化，部署初始化，不把真实凭据写入源码/配置样例/日志。
- 登录、当前会话、注销、后台页面登录状态、独立权限分类与鉴权接入点。
- 跨站请求保护、远程凭据传输保护及合理的失败限流。
- 可复用审计记录能力、登录/注销事实与分页查询页面，为后续邮件和点券原子审计提供接缝。
- 分层实现与自动认证/权限/会话/失败路径验证。

### Out

- 玩家查询、邮件和点券业务；多管理员管理 UI；当前真实服务部署/账号初始化。

## Constraints

- 玩家票据不具备管理员权限；所有后续私有管理 API 共用当前鉴权边界，健康端点及静态登录页不含私有资料。
- 账号密码安全散列，注销后捕获的旧会话不能继续访问；过期/禁用身份被拒绝。
- HTTP 层不能直接访问 Persistence，实现经领域服务和存储契约。
- 所有探测使用隔离数据库，不触及当前玩家和服务。

## Success Conditions

| ID | Observable condition | Required evidence |
|---|---|---|
| SC-1 | 初始化安全且持久化；正确管理员可登录/重连，错误或玩家身份不能进入 | 凭据与初始化/HTTP 集成场景 |
| SC-2 | 会话注销、过期、权限不足、非法跨站请求和远程明文请求被拒绝 | 可观察 HTTP 状态/持久化断言与独立安全审查 |
| SC-3 | 页面完成登录状态切换、退出及按权限菜单，审计可查且无秘密泄露 | UI 构建、API 与审计记录验证 |

## Authorization

| Capability | Evidence | Authorized scope |
|---|---|---|
| task | 根合同中的完整用户授权 | 当前管理员/审计模块设计、开发、隔离测试与本地验收提交 |
