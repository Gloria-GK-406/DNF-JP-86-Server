# 公会领域服务边界重构契约

用户授权「你来设计方案，写任务契约后完成这部分重构任务」。交付位置为现有 guild-system 工作树，输入为该树当前磁盘实现及上一轮公会重构成果。

| 范围 | 验收条件 |
| --- | --- |
| 会籍、资料、捐赠 | 建会、入会、职务和会籍退出只有一个写入负责人。资料和捐赠各自提供专用入口，捐赠的角色金币、会员记录及公会 GM 保持同一事务。 |
| 签到、月贡献、每日奖励 | 签到独立。进城在同一工作单元分别记录签到与月贡献，任一有变化就刷新。日奖励保持独立失败语义。 |
| 购买、权益、礼物、仓库 | 商店负责收费和购买资格，权益负责激活、续期、使用和到期，礼物领取复用激活，仓库容量归仓库。保留拒绝优先级和通知时序。 |
| 查询及规则 | 公共会籍和名单可跨功能读取。权益、捐赠和月榜查询归各自负责人。职级展示与写操作共用同一有效职级和权限解释。 |
| 名称操作会话 | 建会草稿和改名许可在同一会话互斥，更换目的、检查失败、取消和重放保持已有处理。邀请保留独立生命周期。 |

完成条件为正常调用入口全部接通、解决方案构建、领域与协议回归和针对边界的验证结果入档。保留现有协议、数据结构、时间口径和用户工作树修改。采用隔离测试库。实机游戏、发布和远端操作不在本次授权中。
