# 全区广播：用户测试流程

## 前置

- 用两个客户端登录两个不同账号：
  - A：`DNFClient-A21-protocol`
  - B：`DNFClient-A21-protocol2`
- A 用来触发播报，B 只负责看。
- 除第 9 步外，A、B 都留在不同频道。

预期的共同部分：
- 每条播报 A、B 都应收到，显示为聊天框系统行。
- 满级和二次觉醒是红字。
- 不该播的情况，两边都不出现。

道具经 GM 后台发信获得：

| 道具 | ID |
|---|---|
| +12 装备强化券 | 7275 |
| +12 增幅券 | 10008107 |
| 炽星魔盒 | 200 |
| 黑钻售货机代币 | 7454（需要黑钻服务） |

## 必测

1. **强化券成功**：
   - 操作：A 对一件可强化的武器使用 +12 装备强化券。
   - 预期：`玩家[A]强化 +12 <武器名>成功`。
2. **强化失败**：
   - 操作：A 用 NPC 普通强化，把一件 +12 装备往 +13 强化，直到失败一次。
   - 预期：失败时显示 `玩家[A]强化 +13 <武器名>失败`。
   - 不该播：从 +10 往 +11 强化，无论成败。
3. **增幅券**：
   - 操作：A 对红字装备使用 +12 增幅券。
   - 预期：成功时显示 `玩家[A]增幅 +12 <装备名>成功`；券失败时不播。
4. **魔盒**：
   - 操作：A 批量开启炽星魔盒（例如 50 个）。
   - 预期：
     - 开出带公告标志的稀有行（例如 100 个 421、物品 3 等）时，原生显示 `玩家[A]从[炽星魔盒]中获得了[物品]`；
     - 普通行不播。
5. **满级**：
   - 操作：A 用 85 级角色获取经验升到 86。
   - 预期：红字以外的系统行 `恭喜玩家[A]达到Lv86！`。
6. **黑钻售货机**：
   - 操作：A 投币若干次。
   - 预期：只有抽中带公告标志的奖品才播，格式 `[A]从黑钻售货机中获得了…`。
   - 可选：概率低，没抽中不算失败。
7. **抽奖罐**：
   - 操作：A 开袖珍罐等抽奖罐。
   - 预期：奖品稀有度 ≥ 3 时，原生显示 `玩家[A]从[罐名]中获得了[装备]`。
   - 可选。
8. **绝望之塔**：
   - 操作：A 通关第 10 层。
   - 预期：`恭喜玩家[A]征服了绝望之塔的第10层！`。
   - 可选。
9. **全区范围**：
   - 操作：B 依次处于以下三种位置时，各重复一次第 1 步：
     - 与 A 同频道同区域；
     - 与 A 同频道不同区域；
     - 与 A 不同频道。
   - 预期：三种情况 B 都能看到。
10. **退出重登**：
    - 操作：两边正常退出、重新登录。
    - 预期：不补播之前的公告；道具和等级正常保存。

## 不在本次实机范围

以下各项只有自动测试：
- 锻造第 6 阶段及以上；
- 设计图释魂成功；
- 二次觉醒；
- 远古地下城拾取史诗。
