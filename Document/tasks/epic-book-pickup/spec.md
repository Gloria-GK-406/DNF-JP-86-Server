# Specification: 史诗碎片入图鉴

## Why and Outcome

深渊地面碎片是图鉴进度而非普通材料。规则服务提供 PVF 映射，领域服务维护账号的累计数量并提供无副作用查询。拾取的到账与地面掉落提交共同成功或撤销。

## Scope

完成碎片拾取、账号图鉴、旧背包数据迁移及登录/拾取通知。不实现装备合成或其他奖励入口；不部署、不改运行中的数据库和客户端。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 规则服务从 PVF 加载装备/碎片映射，领域查询返回目录和账号数量；未知碎片不能到账 |
| RQ-002 | 每账号/碎片持久化累计值；正数新增按 min(int.MaxValue,current+requested) 饱和，查询只读 |
| RQ-003 | 拾取命令在普通背包处理前识别碎片，无需空背包格；满额也成功清地面，重复拾取不重复到账；事务撤销恢复双方 |
| RQ-004 | 登录发送 mode=0 全量非零计数；实际增加后发送 mode=1 累计值，满额不产生多余余额更新；拾取成功 ACK 和地面移除仍发 |
| RQ-005 | 旧普通持有碎片在角色背包加载前转换为账号计数并移除旧持有；与已有图鉴数量合并饱和，重复迁移不增加 |
| RQ-006 | 协议记录区分上游布局、客户端静态证据和待实机验证；普通物品、金币及登录原顺序保持 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001 | 真 PVF 映射正确，多个图鉴条目可列出；未知 ID 不被误识别 |
| AC-002 | RQ-002 | 增加、满额、临界溢出、账号隔离和同账号共享可验证；重读恢复，查询无写入 |
| AC-003 | RQ-003 | 背包满的碎片拾取成功；同一地面编号再拾取余额不变；事务失败不留下余额或丢掉落；普通拾取回归通过 |
| AC-004 | RQ-004 | 0x0465 编码为 u8 mode + u32 count + count*(u32 pieceId,u32 balance)，登录真实数据替代空基线，拾取先 ACK/移除后图鉴余额 |
| AC-005 | RQ-005 | 临时 SQLite 中多个角色旧碎片合并到同账号，满额饱和，正常物品保留，二次执行无变化，异常迁移回滚 |
| AC-006 | RQ-006 | 协议记录有来源和置信度；相关服务端测试、构建通过，真实客户端展示明确留待验收 |

## Success Evidence

真实 PVF 规则检查、临时数据库及拾取集成测试、通知编码/登录投影测试、相关回归和独立结果审查。原有未提交协议调查以工作区证据列出的路径原样保留。
