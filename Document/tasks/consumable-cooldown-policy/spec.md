# JP86 消耗品冷却归属

工作区任务契约修订 3 定义验收范围，编号 AC-1 至 AC-6。契约与 dev PVF 逐道具索引由工作区 Document 维护。

| 归属 | 判定 | 状态与同步 |
|---|---|---|
| A21 客户端 | 普通道具缺少第三位或时长为零 | A21 根据模板和原生重置规则计时。服务端继续校验等级、职业、地点、期限、库存及业务资格。 |
| 角色持久化 | 既有使用入口、正时长、维护第三位为真 | 普通持续计时记录来源物品和 UTC 截止。默认独立物品键，经验秘药 99 组沿用共享键。角色入场、刷新和重放投影当前剩余时间。 |
| 疲劳药 | 疲劳专用结算、正时长、维护第三位为真 | 使用既有账本的最后使用时间与模板时长计算唯一截止。每日 06:00 更新每日可用次数的判定。 |
| 选角会话 | 未标记且有正时长的城镇瞬移与已接入遗忘之地移动胶囊 | 成功提交时安装到精确的选角会话。城镇瞬移发送既有即时通知。带标记的瞬移使用持久化规则。 |

模板的第一、第二位分别描述 A21 复活和副本重置时的保留策略。普通客户端请求、准确的专用动作与通知进入不同的既有命令。跨会话恢复使用现有 0x00AC 包形，无从判断截止的旧冷却行留存。A21 对重复时长取最后一条。超出客户端毫秒范围时限制线级秒数，服务器仍保留原始期限。

AC-1 验证实际模板值与布尔组合。AC-2 验证人偶请求与资产，并在 A21 观察同局、换房、下一剧情图及重开。AC-3 对照混合组、两类瞬移和遗忘之地两类道具。AC-4 验证 7518、限次疲劳药、迁移、重登、跨业务日、重启及剩余秒数。AC-5 验证拒绝、事务回滚、资源扣减、重复命令和会话接管。AC-6 对每个样例记录证据等级。现有入口之外的候选仍沿 #371 的动作接入边界处理。

术语与证据见 [0x00AC 文档](../../../protocol/game/server-to-client/NOTI-0x00AC.md)。
