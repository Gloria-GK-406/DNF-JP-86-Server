# A21 消耗品冷却验收

环境切换与玩家库准备依照 [功能开发流程](../../FeatureDevelopment.md)。本单用于授权后的 A21 人工验收。记录实际日期、服务端提交、ClientStore 组件与 PVF 哈希，并为每项保留实际请求、ACK、资产和屏幕表现。

| 顺序 | 操作 | 通过条件 |
|---|---|---|
| 1 | 带阿甘左与死亡之纳特亚进入剧情图。召唤一个后在同房、走门后查看另一人的图标。进下一剧情图后再使用。再覆盖正常回城重开及一次普通副本重开。 | 同次副本沿客户端原生共享组；客户端发出下一场的合规请求时，服务器允许，消耗一件并出现召唤。 |
| 2 | 准备已合规的无标记城镇瞬移药和标记的 `10151895`。成功瞬移后检查通知和落点，分别正常重登。 | 无标记瞬移在当前会话有即时 0x00AC；标记物品重登恢复原剩余量。使用前后记录库存、位置、剩余秒数。 |
| 3 | 在遗忘之地使用移动胶囊和变身药，分别走门、尝试使用另一件、回城再进入和重新登录。 | 胶囊只在实际移动成功时启动会话 CD，仍遵守地图禁用。变身药由客户端计时，每次合规成功只扣一件。记录各重置点的图标状态和实际请求。 |
| 4 | 使用 `7518`，正常退出并重登，间隔一段时间再次登录。另在独立测试期间覆盖 06:00、通过授权准备好的真实进程重启及原截止。用 `416` 或 `2600026` 验证用尽每日次数与重置。 | 同一 CD 到时才放行。日次数和疲劳实际变更分别正确。记录 0x00AC 剩余秒数以及 0x021E 次数。 |
| 5 | 使用两种合法的经验秘药 99 组成员，登出前用完来源件，再登回看其他组成员。补测带维护的礼盒、单独作用的通用道具及混合组 1028。 | 服务端 99 组按同一截止限制。采集 0x00AC 对其他 A21 成员的显示和未持有来源件时的行为。混合组的客户端成员若发出请求，不能因服务器已有记录被拒。 |
| 6 | 用至少各一件修理剂、赫拉斯次数券、升级或任务券与开盒物品做本来的流程。再覆盖塔内不允许的道具。 | 扣物、效果、次数、期限、拒绝和响应顺序与各自入口一致。 |

维护位组合 `0 1 0` 与 `1 1 0` 在当前 dev 无样本。相关结论仍来自静态路径，新内容实机行为另行取证。
