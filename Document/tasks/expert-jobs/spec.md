# JP86 四副职业实现规范

角色通过现有 A21 任务就职和放弃，可使用当前职业的专属玩法。实现沿用 [领域服务设计](DomainDesign.md) 和 [上游与 70 证据](UpstreamEvidence.md)，按当前 JP86 PVF 解释任务、配方、资格和产物。

## 范围

实现分解师、炼金术师、控偶师和附魔师的职业操作及登录和在线同步。怪物卡独立合成、强化和绑定保留为调查项。原 NPC/便携分解和普通宝珠接口属于回归范围。

| ID | 要求 | 验收 |
| --- | --- | --- |
| RQ-001 | 角色副职业的类型、经验、放弃次数、设备和配方持久化 | AC-001。旧档无职业可正常登录，已有职业状态和零耐久重登一致。USERINFO0、EXPERT_JOB_INFO 和查询来自同一事实 |
| RQ-002 | 统一入口通过任务就职并支持放弃、重选和职业任务条件 | AC-002。四个当前 PVF 任务授予对应技能、设备与起始配方，任务材料和授职同时提交。放弃按计数收费并清理，只清 PVF 指定数据，关闭本角色营业摊位与访客。拒绝保持原状态 |
| RQ-003 | 按角色取得对应职业服务，职业不符时返回空 | AC-003。分别验证四种匹配和无职业/不匹配查询。操作时用当前会话、职业和摊位重新校验，过期调用无法结算 |
| RQ-004 | 玩家分解机、自用和付费、设备修理及升级 | AC-004。按设备与物品资格计算玩家分解成果、经验和耐久，修理和升级读各自 PVF 档位，耗尽关店。双人资产一起结算、失败完整回滚 |
| RQ-005 | 炼金术师与控偶师的设计图、制作、提取、经验和自动学习 | AC-005。按各自配方和提取器资格执行。材料、成品、经验与跨级解锁一起结算，提取器和配方即时刷新 |
| RQ-006 | 附魔师的设计图、提取、卡片转宝珠、设备修理和顾客附魔 | AC-006。使用自己的卡片资格、装备目标和费用规则，分开验证制作和附魔。双人金币、材料、装备、设备和经验一起结算 |
| RQ-007 | 选中会话和城镇限定的摊位生命周期 | AC-007。创建、加入、主动关闭、耗尽、离区、换角和下线均检查精确身份；顾客离开只清自身绑定，进区收到可见的已开摊位 |
| RQ-008 | 四职业通过正常协议入口，保持既有行为 | AC-008。实现完成后运行构建、相关自动测试和集成验证；记录 A21 包形尚需实帧核对的点以及用户验收顺序 |

## 验收证据

开发验证在测试库和匹配的 dev PVF 下进行。检查内容配置解析、旧角色存档、事务拒绝和回滚、两方会话变更、成功及失败出站。A21 实机在四职业完成后进行，按 TaskContract 的 SC-1 至 SC-6 验收。已知的 `0x021C` 尾部、放弃刷新与附魔时序以本仓协议依据及当前上游实现为参照，记录待实机核对项。
