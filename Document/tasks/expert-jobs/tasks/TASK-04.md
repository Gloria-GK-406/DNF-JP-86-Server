# TASK-04 · 炼金、控偶与共用配方和提取

## Task Unit Contract

- Revision: 1
- Outcome and references: T-004、RQ-003、RQ-005。按角色提供炼金术师及控偶师服务，以现有发放机制结算配方和装备提取。
- Owned boundary: 配方、设计图、提取的 PVF 内容和业务、道具使用接入、`0x00EE` 与 `0x01A0` 协议。附魔师复用这些共用选择，专属宝珠和摊位在 TASK-05 补全。
- Required checks: 构建及核对 dev PVF 内可学习配方、普通成品和提取结果的规则解码。所有职业接入后运行功能用例。
- Dependencies: TASK-01、TASK-03 的共用装备事实与物品发放约定。
- Result review: required。生产数量或满包判断有误会改变付费消耗与产物，可重复的写入还必须保留原有重放约定。

## Detailed Plan

1. 以 `[items]`、`[compound rate]`、`[product exp]`、提取配置为规则事实，正确读取实际分段和每档单位。设计图类型、职业技能、等级、已学配方与实际物品槽一起校验。
2. 设计图学习接入普通物品使用的工作单元。制作计划仅消耗实际配方材料，按尝试计算扣料，按成功数量发放。提取不消耗提取器，装备资格依照职业及 PVF 装备状态。产物和资格做统一预检，有限背包按发放规则拒绝。
3. 每次结算的经验与跨级配方在同事务写入。接通制作与提取的正常协议和槽位投影，提取器成品补背包全量及职业快照。登记现有库存效果并保持已提交请求的正常重放语义。

## Result

- Outcome: done
- 角色副职业门面按当前职业提供炼金、控偶及附魔专属服务。设计图学习接入普通道具使用的同一工作单元。普通道具通过 PVF 候选索引排除，未配置 PVF 时沿用旧道具逻辑。
- 普通制作覆盖三职配方。按尝试次数扣料，按成功次数发放，并在同事务写入经验和跨级配方。装备提取按当前职业和等级、实际提取器及目标装备资格校验，提取器保留在背包。产物统一预检背包容量。
- 接通 `0x00EE`、`0x01A0` 及 `0x00CD` 职业刷新。制作回复包含尝试产量、成功和失败次数，提取回复包含产物位置和实际增量。库存变化沿用标准效果投影及已提交请求重放。
- Data、Abstractions、Application、Infrastructure 和 Protocol 定向构建均为 0 警告、0 错误。用编译后的解析器只读检查 dev PVF，普通配方候选 135 张，附魔、炼金及控偶配方分别为 11、71、53 条。三职各有 6 种提取器和 57 条产物规则。普通药剂 8474 未被判定为设计图。
- 附魔资格设计图、宝珠制作及摊位由 TASK-05 完成。自动测试和 A21 实机验证安排在四职业接通后。
