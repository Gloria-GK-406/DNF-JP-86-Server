# Specification: 赛利亚物品合成

## Why and Outcome

玩家在赛利亚处放入一件可合成装备，选择界面允许的随机或定向模式，确认后消耗底材及显示的材料，取得一件新装备。分解获得的账号灵魂可直接用于合成。

## Scope

沿用 A21 原生界面、现有 PVF 与物品容器。证据见 [evidence.md](evidence.md)。同号八字节形状的归属待证，其请求必须安全拒绝。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 已选中角色须处在城镇，提交有效的主背包装备槽及模式。装备须为该角色持有的合格单件底材。 |
| RQ-002 | 依据部署 PVF 的装备分类、例外、模式、材料、倍率和等级权重生成计划。用普通稀有品质的底材可抽到传承，传承底材只产传承。定向限制到与底材一致的细分装备组，随机可跨类别。 |
| RQ-003 | 同一事务中销毁底材、扣账号与角色材料并创建一件新装备。新建实例按正常物品生成规则初始化，沿用上游处理保留底材的封装与解除封装状态。 |
| RQ-004 | 成功发结果槽响应，响应发出前投影已提交的相关库存。同槽替换时先清空旧装备，随后填入新装备。失败拒绝与同帧重放无重复资产变化。 |
| RQ-005 | 提供准确的协议证据、验证记录和编号实机测试步骤，按项目流程准备连接候选。 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001、RQ-004 | A21 六字节请求才可结算。畸形长度、未选中、非城镇、不可合成的底材、无效模式、空候选或资源不足时无扣料或产物。 |
| AC-002 | RQ-002 | 对真实 PVF 校核四档费用、同档／升五级、定向筛选及合成边界。加权选择只从有候选的有效等级抽取；传承与例外权重遵从下述候选策略。 |
| AC-003 | RQ-003、RQ-004 | SQLite 经提交可读到新 UID、精确扣料与原始底材销毁。同一请求回放不会再次结算，后续不同帧的合法请求仍可结算。事务失败还原已消费资产。 |
| AC-004 | RQ-004、RQ-005 | 首次结算背包及账号材料变化先于 0197 结果槽响应。记录静态、自动验证与用户实机的边界，实机覆盖正常、缺料和重登。 |

## 合成权重

PVF 的等级权重、传承权重和例外模板权重是规则输入。候选策略沿用上游对普通传承模板的 `0.01` 权重缩放。单件的权重还要与同档其他候选的权重一起归一化，日服实服概率待证。

## Success Evidence

使用真实 PVF 规则测试、编解码与 SQLite 结算测试、协议台账与候选环境测试说明核对本规格。
