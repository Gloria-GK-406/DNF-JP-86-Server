# TASK-003 宠物运行闭环

## 目标
依据已取得70证据接上在线时间、战斗/休息、饲料和清房经验，客户端通知独立于领域。

## 实现
- 统一共享调度，按时间差结算，不创建每宠物timer；离线不恢复。
- 会话按代次隔离，内存时间锚点和持久化状态同事务提交；失败不提前推进时钟。
- 仅穿戴且战斗中消耗，其余在线宠物恢复；0饱食回城复活为1。
- 饲料24恢复30，上限100；使用资格失败不消费。
- 清房按70疲劳计量基数授予经验，PVF等级表，饥饿/等级上限限制。
- 0066/0067/0064/006B按A21静态分支编码，通知面与状态分离。

## 验证
可控时间和事务回滚，离线/重登/换宠物，饲料消耗，经验阈值；协议字节向量。样本数据修复和实机验证在集成单元执行。
