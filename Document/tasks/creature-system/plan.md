# 宠物重构计划
## Route
渐进任务单元：公式和协议尚需70/A21调查，避免提前猜测细节。整体接口：宠物store读取实例与当前穿戴，领域服务编排动作和事务，规则服务读取PVF并纯计算，协议层做投影。
## Work map
- T-001 调查：70生命周期/公式、A21 payload、现状入口和不变量。覆盖全部RQ；先交付证据矩阵，后续接口细节据此确定。
- T-002 身份与本体：宠物store、默认状态、完整加载与迁移；修复错配样本及登录marker。覆盖RQ-001/002/003。
- T-003 常规运行：穿戴、饥饿时间、喂养、经验升级和副本生命周期。依赖T-001/002，覆盖RQ-003/004/005。
- T-004 道具及特殊转变：改名、孵化、进化、技能协议/状态；依赖调查及本体，覆盖RQ-004/005/006。
- T-005 全链集成、协议文档、自动与实机验收准备，覆盖全部RQ。
## Shared boundaries
持久化不复制第二套宠物身份；宠物明细随world item移动。客户端CreatureKey在边界映射。道具消耗与宠物变更在同一DomainTransaction，提交后发送通知。迁移/测试修复只处理有证据的行并先备份。
## Next planning boundary
TASK-001 收集信息；证据与未决矩阵到位后再规划T-002及其后实现任务。无客户端证据的请求不猜布局。受影响功能检查完整入口，而非只补单个handler。
## Verification
身份一致性、事务回滚、生命周期时间边界、进化/等级/过期限制、协议编解码、登录全序列、现有容器和背包回归；最终独立review，实机结果单独记录。
