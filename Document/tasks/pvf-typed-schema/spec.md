# Specification: PVF 字段声明与读取全量迁移

## Why and Outcome
调用方按静态具名字段读取，声明表达名称、目标类型和形状。合法输出仍为现有业务记录。

## Scope
遵循 TaskContract。包含普通字段、结束标记、列表、重复/嵌套块、动态固定集合和工具读取。枚举值、路径及通用探针外部输入不是固定字段。

## Requirements
| ID | Requirement |
|---|---|
| RQ-001 | 全部固定读取和判定使用静态声明 |
| RQ-002 | 标量类型明确，复合/列表/块保留合法形状 |
| RQ-003 | 可选缺失与损坏分开，明确诊断，不弱化严格校验 |
| RQ-004 | 声明与档案绑定分离，通用库无游戏概念 |
| RQ-005 | 合法数据的业务记录、规则和 effect 结算兼容 |
| RQ-006 | 全量覆盖保护、独立审查、新鲜验证与提交 |

## Acceptance Criteria
| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001 | Server/src 和 Tool 无裸 GetTag/字段字符串辅助调用/字段字面量比较；声明、枚举值、动态探针可区分 |
| AC-002 | RQ-002 | 整数/浮点/字符串/可选/列表/混合/嵌套读取通过合成测试 |
| AC-003 | RQ-003 | 类型/截断/范围/非法重复有字段和来源诊断，合法缺失/重复/未知字段不误拒 |
| AC-004 | RQ-004 | 偏移不同的两个档案共用声明仍读对，Dfo.Pvf 无游戏依赖 |
| AC-005 | RQ-005 | 真实 PVF 及完整服务端测试无新增失败，条件跳过和基线问题另记 |
| AC-006 | RQ-006 | 完整 diff 独立批准，审查后新鲜验证并完整本地提交 |

## Success Evidence
合成解析、真实 PVF、调用点扫描及保护、完整构建/测试。这些不是新客户端实机证据。
