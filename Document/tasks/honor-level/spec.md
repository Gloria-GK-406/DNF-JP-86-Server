# A21 账号荣誉品级规格

玩家使用达到 Lv.86 的角色获得经验后，荣誉窗口刷新本级进度。同账号角色共享荣誉，换角和重登后可继续查看。品级关联客户端已有徽章、城镇特效和升级提示。

## 规则与范围

| 编号 | 要求 |
|---|---|
| RQ-001 | `etc/honorlevel.etc` 的每个等级对提供达到该等级所需的增量及所属品级。累计值扣除已达等级所需的经验后得到本级进度。荣誉最高级的本级进度最多为 `[maxexp on maxlevel]`。 |
| RQ-002 | 角色经验超出 Lv.86 上限的部分按既有规则进入账户累计荣誉与成长胶囊。启动、登录、刷新界面、换角或重放通知期间只读取累计进度。 |
| RQ-003 | 登录、角色列表、选角和回选沿用 `NOTI 0x0289` 的顺序和布局，发等级与本级经验。`USERINFO` subtype 0 的尾部写入 `+39/+43`，subtype 1 的 body 写入 `+9/+13`。USERINFO 取被描述角色的账号，保留其余字段。 |
| RQ-004 | 所有 `NOTI 0x0025` 的荣誉字段由结算后账号状态产生。没有本次奖励或只有角色等级变化时仍同步当前荣誉，避免覆盖客户端已有值。 |
| RQ-005 | 保留账号账本、现行资源、现有消息身份和其他玩法的行为。实机和自动测试证据分别记录。 |

## 验收

| 编号 | 覆盖 | 判据 |
|---|---|---|
| AC-001 | RQ-001 | 开发 PVF 的 `0 → Lv.1/品级 1/0`，`449,999,999 → Lv.9/品级 1/89,999,999`，`450,000,000 → Lv.10/品级 2/0`，超过 `17,699,999,999` 后稳定在 `Lv.59/品级 6/589,999,999`。 |
| AC-002 | RQ-002 | 隔离库验证既有满级结算、跨满级溢出、事务回滚及防重复。同步和读取既有非零进度无额外经验写入。 |
| AC-003 | RQ-003 | 非零荣誉账号在登录、选角、回选和同账号换角时的相关字段同源。两个不同账号的角色资料传回各自的进度。消息长度和周边字段兼容。 |
| AC-004 | RQ-004 | 在奖励后捕获经验帧，核对等级和本级经验与账号累计变化一致。没有奖励的经验帧仍发已存荣誉。A21 验收操作覆盖跨品级、同账号小号、城镇特效和重登。 |
| AC-005 | RQ-005 | 构建、相关自动测试及协议对账有可复核结果。客户端观察和无法覆盖的项目在交付记录中说明。 |

## 设计依据

- 内容源继续负责读取 `honorlevel.etc`，现有经验规则负责使用同一张刻度计算累计上限和荣誉投影。账号读取沿用 `IAccountTable.FindExperienceAsync`，角色满级奖励仍经既有经验事务落库，保持旧库兼容。
- 由账号领域读取提供 `AccountHonorLevel`，选角和在线角色资料随目标账号的角色资料视图走。经验消息使用发给该角色的荣誉快照，编码器只写字段。各处复用同一换算规则。选角名单中未确认的相邻字段保持现有布局。
- 开发 `Script.pvf` SHA-256 `A97132DDA0970B3E0CE7C3DE8052ACF0BE2664F52E26C819B1D8CB6D427CFCD2`，参照客户端 `8FA275A3…`，参照服 `E0F24B1C…`，三者 `PvfProbe dump etc/honorlevel.etc` 输出一致。ServerS4A21 `1870c858` 的 `HonorLevelDataProvider.ResolveHonorProgress` 提供单级经验换算参照。台服 70 的 `Script.20130704.pvf` 文件索引无 `honorlevel`，未据该版本推导成长规则。
- [A21 `0x0289`](../../../protocol/game/server-to-client/NOTI-0x0289.md) 有 8B 抓包样本。A21 镜像 `AAAE2421…` 的 `VA 0x02F02F60` 注册 `VA 0x008A8660`，后者读取两个 u32。`VA 0x0117903A/0x01179046` 的经验包读取经 `VA 0x008A6A80/0x008A6AD0` 写入同一荣誉状态。`VA 0x008A6E80` 在新等级对应品级高于旧品级时进入提示路径。USERINFO 字段依据参照服 `UserInfoSubtype0Builder` 与 `USERINFO1客户端消费结构.md`，并与 [本仓 A21 角色入场证据](../../../protocol/patterns/world-entry.md) 对照。效果显示仍需实机检查。
