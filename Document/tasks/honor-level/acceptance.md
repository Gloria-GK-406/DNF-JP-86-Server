# A21 荣誉品级实机验收

适用客户端为 JP86 A21，客户端和测试服使用匹配的开发 PVF。验收使用经协调的测试服务。
跨品级预置和精确到账核查使用隔离的测试库及测试账号。玩家库上的测试角色采用其实际已有进度。

1. 选一个拥有 Lv.86 角色和低等级小号的账号，记录当前累计荣誉值。进 Lv.86 角色后打开 `Esc → 荣誉`，核对等级、本级经验和品级。隔离用例可从累计 `449,999,999` 开始，预期是荣誉 Lv.9、品级 1、本级经验 `89,999,999`。
2. Lv.86 角色正常击杀会给经验的怪物或完成有经验奖励的副本。从上述隔离进度开始时，第一笔正经验应进入荣誉 Lv.10、品级 2。本级经验应等于到账后累计值减 `450,000,000`。记录经验包、荣誉窗口和跨品级提示。角色经验仍封顶，成长胶囊按原规则增长。
3. 再获得一次经验，检查本级经验持续增加。留意副本成功结算、退图和回城后，荣誉窗口不回落到初始值，也不在没有品级变化时重复显示升级提示。
4. 回选并进入该账号的小号，检查荣誉等级、品级和经验与 Lv.86 角色相同。低等级角色正常获得人物经验时，账号荣誉不增加。再用另一账号进入同一城镇区域，检查各自的角色荣誉与城镇特效。
5. 在游戏设置中切换荣誉特效显示。正常退回选角并退出，重新连接，核对荣誉窗口和实际账号累计值与退出前一致。

通过条件以当次 A21 界面、出站帧及库结果为依据。实际执行者、客户端版本、相关帧及观察结果在执行后填写。
