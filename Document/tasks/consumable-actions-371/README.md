## 结论

#371 是协议路径、物品规则和多个玩法能力共同缺失的问题，不能通过放开动作号白名单一次解决。现行 dev PVF 中，issue 表内涉及 **79 种 action type、819 个模板**。应先完成协议路径与语义核实，再按真实领域分批实现；没有证据的活动保留为待取证，不能记作“A21 不支持”而关单。

实物调查还表明原验收中的“成功都扣 1 个”需要修订：打开指南等只读客户端动作不应消耗物品；消费型动作则需区分使用券、额外材料和确认/取消时点。
