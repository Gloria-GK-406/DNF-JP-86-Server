## 1. 验收预期怎样确定

每行开始实现前，先冻结该行的“预期卡”：

- 物品ID/模板路径、客户端/PVF/补丁身份、动作参数组合、最终CMD、请求体和目标语义。
- 实际角色/账号、等级/职业/成长、位置、活动状态、源/目标UID和容器；不能预写成当前主干库已经有这些测试物品。
- 规则来源：PVF文案及数据表、客户端读取/动作分支、已有明确用户策略；第三方仅作线索。
- 精确预期：改变哪些事实、数量/上限/单位、哪些字段保持、额外材料及奖励、持久化或仅会话有效。
- 界面预期：立即效果/提示、选择框收尾、取消行为、原地/跨区/旁观者表现。
- 审核后的前后检查口径：实际表/字段或具名领域查询与UI/日志对应关系，依据当时schema，不能臆造SQL字段或仅看界面。

预期依然Unknown的行先执行取证，不假设通过条件去写功能。随机效果先证明候选与权重语法，实机验证结果属于候选及资产一致；不能用一次抽样证明概率。

## 2. 总体通过条件

| 场景 | 预期 |
|---|---|
| 合法消费成功 | 产生预期效果；使用道具扣1；仅扣该操作声明且已证的额外材料；未关联资产不变 |
| 只读指南/打开界面 | 界面正常打开/关闭，不因打开或取消就扣源物品/材料；最终确认另按实际行为验证 |
| 失败 | 不产生效果/奖品/次数，不扣源物品和材料；客户端有明确提示或按已证流程正常关闭/返回可操作状态 |
| 同帧重放 | 不再次消费、抽奖、发奖、推进或传送；按已提交事实恢复必要投影 |
| 新序号双击 | 按当前资产和效果事实再次判定；一次性开关只成功一次，可重复合法操作按规则执行，不能把所有双击都强制幂等 |
| 重登/重启 | 持久事实保持；会话效果按已证生命周期结束或恢复；不再发一次性奖励 |
| 不支持A21 | 有该构建不支持的可复核证据，明确拒绝且无消费；单纯缺本服实现不能使用此结论 |

正常失败不得用静默错误码2掩盖；传输损坏、无有效身份等非法请求的处理遵循既有安全/关闭规则，不强求给不存在的客户端显示业务提示。

## 5. 每个动作的统一实机步骤

对矩阵A001～A079中的每一行执行以下流程；如果尚未实现，先作取证并标记“未实现”，不冒充功能验收。

1. **建立前态。** 登录已选角色，记录物品ID、UID（如有）、源wire容器/槽、业务槽、数量、目标身份/属性、材料持有量和对应领域状态；保存截图与只读事实快照。冻结该行的预期卡。
2. **取消与不适用条件。** 右键打开界面后取消，或选择不适用目标；记录实际CMD、UI是否关闭及无消费。对直接使用无选择框的动作，改测该行对应的合法拒绝条件。
3. **正常使用。** 回到合法前置状态，进行一次实际右键/选择/确定，不以WireSmoke合成请求代替；记录发包、回包、效果和界面收尾。
4. **核对资产与效果。** 使用物品、额外材料、奖励、次数/余额/目标变化逐项比对；消费型成功应为前态减1，额外材料依本操作定义变化；只读UI始终不扣。观察是否发生客户端本地减量后再减一次。
5. **重复与边界。** 根据动作分别测试连续点击、已开栏/已完成/满级/上限、材料不足、目标失效、期限或场景限制；失败后资产不变，不产生隐形副作用。
6. **正常退出并重登。** 走游戏内正常退出，保存退出flush与最终帧；重新登录比对库存、目标、任务/额度/余额。会话效果按其生命周期验收，不把正常消失误判丢失。
7. **必要的第二视角。** 涉及账号共享时切换同账号另一个角色；涉及外观/公会/伴侣/对象时用另一个账号的客户端观察。双人角色、位置和会话需实际记录。
8. **归档并登记。** 立即归档本次日志，标明原文件SHA与客户端/服务端身份、case ID、seq和发生时刻；填实际结果、差异与证据路径。日志未归档前不覆盖运行。

重复帧、篡改动作号和提交失败等协议/事务注入优先在隔离自动化中完成；不要为覆盖异常用例向主干玩家库发送破坏性合成请求。

## A079 隔离服复验

使用 `Client-11` 的本地登录器连接 `http://127.0.0.1:43291/`。隔离库副本 `artifacts/consumables-371-probe/a079-371-verify.db` 中，Lv.86 的「pv」初始剩余疲劳为 105，快捷栏有两瓶秘药，普通背包有两个碎片。本次隔离配置的疲劳上限为 156。

1. 登录并选择「pv」，在城镇记下疲劳和两个道具的数量。
2. 右键秘药一次。预期疲劳变为 125、130、135、145 或 155，秘药剩一瓶，碎片仍为两个。
3. 等至少两秒再右键剩下的一瓶。预期疲劳、秘药和碎片的数量保持原值。
4. 退回选角再进「pv」，核对疲劳和道具数量一致。只读库对账中 `consumed_today` 保持 51。

服务端定向回归用真实 PVF 验证了五档的权重边界、105 与 106 的分界、零碎片使用和同序号重放。

2026-11-19，用户确认实机恢复 25 点并通过本项验收。隔离库在一次使用后显示剩余疲劳 130、秘药 1、碎片 2，累计消耗疲劳仍为 51。第二次操作与重登显示没有单独验收。
