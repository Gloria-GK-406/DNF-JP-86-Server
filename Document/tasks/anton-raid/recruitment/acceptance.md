# 安图恩招募 A21 验收记录

## 2026-11-19 隔离服实测

使用 ClientStore 生成的 `Client-12`、`Client-13`，原始 A21 客户端与 dev PVF。两个测试账号使用独立 SQLite 玩家库。三个角色均为 86 级，`RaidA` 和 `RaidB` 的任务 12829 完成标记为 1，`RaidNo` 无完成标记。普通频道为 CH10，团队频道为 CH200。

| 判据 | 当前实测证据 |
| --- | --- |
| AC-001，未完成任务 | `RaidNo` 进入 CH10 后，点击系统菜单的「团队频道」。A21 提示「若想移动到攻坚队频道，必须先完成任务『异次元的安徒恩』」，角色仍在 CH10。此为客户端本地检查的证据。 |
| AC-001，完成任务 | 两条隔离客户端连接都收到了团队频道就绪 `0x04BD` 和初始目录 `0x024F`。操作者到了甲板，并成功从海岚·克拉夫打开建团窗口。 |
| AC-002，建团及目录 | 操作者建团后，另一端在列表看到安图恩攻坚队。隔离服向两端发出 `0x0250` 与 `0x024F`，并向建团端返回 `0x0299` 成功应答。 |
| AC-003，申请与审批 | 修复后，A21 申请触发团长端审批通知，获批后双端均收到两人成员表，操作者随后编辑了两人的编组。拒绝分支的客户端表现另待实测。 |
| AC-004，编组 | 操作者确认两位角色都能编入第 6 队（F 组），招募阶段没有自动建立普通小队，符合规范。日志确认双端均收到编组后的成员表更新，未记录原始组号字节。第 7–10 队的操作结果还未逐项确认。 |

在 `013AB047` 的 A21 静态入口查到了独立的活动标识 181 查询。更新后的服务端由选角与活动刷新共用的聚合逻辑，在目录配置团队频道时向客户端发出该无详情标识。详见[活动信息协议](../../../../protocol/game/server-to-client/NOTI-0x006C.md#安图恩团队频道入口2026-11-19)。

早期构建缺少活动标识 181 时，已完成任务角色通过任务检查后看到「使用日期不准确」。入口修复日志 `.local-evidence/a21-recruitment-lab/host-20261119-151308-948.stdout.log` 的第 1468、1470、1928、1930 行记录两条连接的团队频道就绪及目录投影。

建团操作应在 town 19 area 1 的甲板右侧找 NPC 330「海岚·克拉夫」，切到 area 2 后可从左侧退回。dev PVF 的 `npc/hiram.npc` 声明 `[create raid] 1`，菜单文案为「创建攻坚队」。操作者观察到 area 2 的鹰眼杰克特仅显示对话和送礼，与其 PVF 角色只有 `[leave raid zone]`、`[start raid]` 一致。

同一日志第 2398–2408 行记录建团广播和应答，第 2511–2527 行记录申请异常。申请读取复用角色视图自己的装备快照，退出应用层命令的只读工作单元。新增协议回归确认申请能向团长投影申请者及审批通知，团长批准后服务端成员关系成立。

修复后日志 `.local-evidence/a21-recruitment-lab/host-20261119-152229-913.stdout.log` 的第 2328 行记录建团应答，第 2356 行记录 `0x0007` 审批通知，第 2370、2376 行记录双端的两人成员表，第 2500–2676 行记录后续成员表更新。第 6 队取自操作者的客户端观察。
