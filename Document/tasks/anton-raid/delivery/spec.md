# 安图恩攻坚完整链路

将已实现的招募流程接到最终翻牌和城镇收尾。规则、材料和证据边界以[修订设计](../design.md) §4–8 为准。A21 人工验收在版本具备完整流程后集中开展。

| 需求 | 验收 |
| --- | --- |
| RQ-001。开团只接受符合条件的当前团长和成员，冻结准备代次。组内最多四人，实际小队与冻结名单一致，门票同一决定提交。 | AC-001。正确阵容可开；人数、门票、失效代次或成员变化阻止开团，且失败无部分扣款，重复提交至多扣一次。普通小队的组建、离开和查找仍正常。 |
| RQ-002。阶段玩法按地图、时间、通关和触发器推进；只有当前团、阶段及编组的成员能进入可用地图。 | AC-002。隔离测试完成阻截到间歇再进入灭杀，验证地图限制、并行出战、复位、超时和出战退出。 |
| RQ-003。离线成员可在保留期重入，超时和结束清理会话、小队、选图及出战占用。 | AC-003。覆盖替换会话、过期保留、团长继任和结束后的资源归还，旧命令不能影响新实例。 |
| RQ-004。具备资格者可以翻牌或自动翻牌，奖励与阶段任务按名单和次数规则落账。失败按设计发重试材料。 | AC-004。测试在线领取、离线邮寄、重复领取、资产事务失败及重试，验证无重复发放。 |
| RQ-005。一次交付包含能运行的隔离构建、协议证据及整体验收顺序。 | AC-005。构建与相关自动测试有鲜明结论，A21 待测项列在集中流程中，结果在实机发生后登记。 |
