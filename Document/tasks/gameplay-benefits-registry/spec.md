# 玩法权益登记与结算

| 要求 | 可观察行为 | 验收 |
|---|---|---|
| RQ-001 | 来源在作用范围内声明具名权益，带稳定顺序与可选生效时间。重新发布取代同来源同范围的整个声明，空声明表示明确撤回。缺席来源可省略 | AC-001 在同一读取时点验证排序、范围、替换、撤回、旧更新与到期。已经读出的快照保持一致 |
| RQ-002 | 怪物、结算、任务及适用的塔经验消费权益。账号、公会、频道、冒险团、药剂和副本来源保留适用场景、计算和显示口径 | AC-002 对照现有经验测试，覆盖正常与限制分支、幸运本人和同伴以及疲劳的计算顺序 |
| RQ-003 | 全局投掷倍率、账号成长 Boss 装备概率和幸运队伍共享神器额外投掷通过权益进入结算。幸运额外投掷沿用独立随机序列和队伍共享归属 | AC-003 验证已存在的全局、Boss 和幸运分支，覆盖额外装备的品级与归属 |
| RQ-004 | 普通装备强化可查询角色时效权益并在原判定内提高概率。强化券、增幅和勋章保持独立规则 | AC-004 固定随机数经过强化入口，验证有效与到期的不同结果，以及强化券仍使用自身判定 |
| RQ-005 | 完工后按三个领域复扫实现 | AC-005 记录迁移入口、适用边界和未归拢情况 |

已有状态的权威保留在各自领域。角色、账号或全局权益可以由权威状态在查询时声明。临时发布由发布者管理其恢复和撤回。服务按结算时点读取，已入账或冻结的结果继续使用原值。
