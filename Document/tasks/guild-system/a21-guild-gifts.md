# A21 同盟送礼验收

日服 2016 年改版允许同盟双方当天各向对方送一次公会内容。本服按服务器本地日期结算额度。当前 PVF 支持赠送 1 天公会经验加成和 1 天公会属性加成，各 200 GM。会长赠送时扣发送公会的 GM，接收公会的会长领取时激活权益。[日服改版说明](https://arad.nexon.co.jp/campaign/2016april_guild.aspx)

## 实机步骤

同盟送礼使用隔离验收服 `127.0.0.1:52580`。Client-38 对应 `1123`（「测试测试」会长），Client-39 对应 `GuildPilot`（「同盟验收乙」会长）。验收库保留两家已结盟的关系，并给每家准备至少 1,000 GM。

```powershell
python 'E:/Project/DNF/DNF-JP-86-Server/.worktrees/guild-system/Document/tasks/guild-system/.local-evidence/a21-guild-benefits/guild-gift-acceptance.py' launch both
```

1. 两边到暗黑城，找「公会管理」博肯，打开「查看同盟」。用 `1123` 给「同盟验收乙」送 1 天公会经验加成，核对发送方扣 200 GM。
2. 用 `GuildPilot` 打开主公会窗口，点带计数的「同盟公会」，切到礼物页。勾选待领礼物，再点「接受礼物」。确认待领项目消失，公会已激活内容增加经验加成，接收方 GM 余额维持原值。
3. 打开博肯的「查看同盟」，核对「收到的礼物详情」和日期。用 `1123` 当天再送一次，确认上限提示和余额。用 `GuildPilot` 反向发送 1 天公会属性加成。两家各只显示收到的那一项。

## 协议与证据

| 动作 | CMD | 请求与成功回执 |
| --- | --- | --- |
| 赠送 | [0x02FA](../../../protocol/game/client-to-server/0x02FA.md) | `u16` 内容 ID，`u32` 目标公会 ID。成功回 `01` |
| 待领取 | [0x02FB](../../../protocol/game/client-to-server/0x02FB.md) | 空请求。成功回 `01`、`u8` 行数及列表 |
| 记录 | [0x02FC](../../../protocol/game/client-to-server/0x02FC.md) | 空请求。列表结构同上 |
| 领取 | [0x02FD](../../../protocol/game/client-to-server/0x02FD.md) | `u32` 发送公会 ID、`u16` 内容 ID、`u8` 权益类型、`u32` 发送时间。成功回 `01` |
