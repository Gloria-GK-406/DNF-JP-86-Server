# A21 公会地下城延长券

## 规则与实现

开发及配对验收 PVF 的安德商店（NPC 382、商店 149）在「其他」页出售 `10155510`。该道具价格 1,000,000 金币，声明 `[guild dungeon time ticket] 10000 1`，购买和使用均要求会长，使用位置为城镇。只接入当前商店内的跳过一次重置券。[日服更新记录](https://arad.nexon.co.jp/news/update_view.aspx?no=7398)

在普通购买命令校验会籍、会长和本公会设施实例，使用时复验会长与场景。扣除一张券、扣除 10,000 GM、记录新的重置时间在同一事务。延期期间，公会地下城入场、通关、莱茵商店资格和选角恢复共用同一有效周期。净化率继续写入原周期，下一次实际重置时使用空的新周期。同一个有效周期只允许延期一次，个人礼盒和月度贡献仍按原规则结算。

## 验收

修正版使用 Client-51 登录会长 `1123`，可用 Client-52 登录同公会非会长 `GuildPilot`。登录地址为 `http://127.0.0.1:53680/`，进入 CH10。新版验收库来自 53480 的一致副本，保留会长第一次验收购买的一张延长券和当时的资产。可以从步骤 3 开始。

1. 从赛丽亚房间进公会基地，走大厅右侧到公会地下城入口。先看伤城净化率和选图界面里的下次重置时间。
2. 会长点「安德 → 商店 → 其他」，买两张公会地下城延长券。每张扣 1,000,000 金币，购买时公会 GM 保持原值。非会长可尝试购买，预期无法完成。
3. 会长在城镇打开消耗品栏，右键用一张。预期扣一张券和 10,000 GM。重开选图，伤城净化率保持原值，下次重置时间后移一个月。
4. 再用剩下的一张，预期拒绝，GM 和剩下的券保持原值。重登后，核对延期、净化率和公会余额仍正确。

原版 A21 已实机购买。第一次使用时，客户端发 `0x0204` 动作 `0x90`，旧构建未分派该动作，券和 GM 保留。修正版用抓到的请求布局验证购买权限、GM 不足、错误槽、成功回执、双端进度和余额、重复拒绝与重登。持久化回归使用精确月初边界验证只跳过一次、相邻公会正常重置和迁移保留既有净化率。

2026-11-28，用户在 Client-51 使用了原先购买的券。验收库对账确认延长券由 1 张减为 0 张，公会 GM 由 25,000 减为 15,000，伤城 209 次通关保持原值，下次重置记录为北京时间 2027-01-01 06:00。重登后用户确认选图界面显示剩余 34 天，符合预期。原生购买、使用和重登后的倒计时已实机验收。

使用保存了这笔延期的两份独立副本平移周期，复核了重登时 `0x02E5` 在跳过的重置后仍报告 209 次通关，到下一次实际重置后报告 0 次。验收服继续使用原时间和原库。
