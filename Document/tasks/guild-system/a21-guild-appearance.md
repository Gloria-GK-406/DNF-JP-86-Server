# A21 公会图标与公告验收

以当前公会申请验收库的一致副本执行 20 → 21 迁移。测试工会保留 GuildPilot 会长、GuildViewer 副会长和新加入的 GuildAlt。

1. Client-25 选 GuildPilot，Client-26 选 GuildViewer。进同一频道后打开公会信息。
2. 用会长更换一个不同的免费图标。核对两端面板图标，同时核对 GM 余额。
3. 用会长发布一条公会公告。两端应收到通知，并在公会信息看到新公告。原有宣传语仍独立显示。
4. 让会长重新进入游戏，核对图标和公告仍可见。用副会长尝试修改时，应被服务端拒绝。

构建、24 项公会定向用例、2,421 项协议用例、3 项公会 PVF 读取用例及 47 项迁移用例通过。隔离双端线路覆盖中文公告推送、免费和付费图标、重复提交免扣、余额不足及保存。付费线路在单独副本设置初始 2,100 GM，扣款后可用 GM 为 100，累计贡献为 2,100。当前验收副本保留用户已有余额。

用户反馈 A21 验收通过。验收库确认图标为 7，可用 GM 为 98,000，已花费为 2,000。读取时公告为空，公告通知沿用双端线路验证。
