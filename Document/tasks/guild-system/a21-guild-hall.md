# A21 公会基地入口验收

A21 客户端字符串 21484 指向赛丽亚房间的公会基地入口。开发 PVF 里的 `town/guildagit.twn` 定义公会大厅，初始区域的 `map/guildagit/guildagit_s.map` 放置了名为「公会仓库」的 NPC 99。

隔离验收服地址为 `http://127.0.0.1:49680/`，Client-25 和 Client-26 已同步配置。数据库是前一轮公会技能验收库的一致副本，保留 GuildPilot、GuildViewer、已购买内容和剩余 9 次公会组队传送。

1. 用 GuildPilot 和 GuildViewer 进入 CH10，到同一城镇的赛丽亚房间。
2. 走房间里的公会基地入口。两人应进入公会大厅，能互相看见，并找到「公会仓库」。
3. 用基地出口回赛丽亚房间。另让一人留在基地正常退出再登录，确认回到进入基地前的赛丽亚房间。
4. 用未入会角色和另一个公会的成员复测。未入会角色无法进入。同频道的另一个公会进入自己的基地，双方在大厅内互相不可见。

隔离双端线路已覆盖初始基地状态、同公会成员可见、不同公会隔离、未入会角色拒绝、公共街道直接进入拒绝、按原入口返回与重登。2026-11-26 原生客户端用 GuildPilot 进入大厅并点击仓库，日志记录 `1:0 → 8:0` 与 [仓库查询](../../../protocol/game/client-to-server/0x0105.md)。用户看到仓库窗口显示 `0/0`。

协议套件通过 2,345 项、跳过 69 项。应用选测中的两条城镇入场断言在功能改动前的 `e493c238f` 也失败，原因是断言把已有的安图恩入场通知算进了城镇投影次数。

[仓库存取现已通过 GuildPilot 实机复测](a21-guild-contents.md#仓库存取验收)。从大厅右侧进入 Area 1 可到达公会地下城选图入口，伤城的 [入场和结算已通过线路验证](a21-guild-dungeon.md)。公会基地战另行实现。
