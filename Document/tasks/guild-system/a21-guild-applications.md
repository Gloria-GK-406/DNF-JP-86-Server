# A21 公会申请验收

验收服登录地址为 `http://127.0.0.1:49280/`。验收库沿用上一轮的「测试工会」，开测前无待审申请。`GuildAlt` 尚未入会，`GuildViewer` 是副会长，已保存的职级权限包含审批申请。

1. Client-25 选 **GuildAlt**，Client-26 选 **GuildViewer**。两端进 CH10。
2. GuildAlt 查找「测试工会」，点击「申请公会」，填一条易识别的留言。确认申请侧显示待审。GuildViewer 打开申请列表，核对角色名、职业、等级和留言。
3. GuildViewer 拒绝。确认待审列表清空，GuildAlt 可以再次提交。GuildAlt 再申请一次后自行撤回，审批端重新打开列表确认该项消失。
4. GuildAlt 再提交一次，保持公会窗口打开。GuildViewer 点击同意。确认申请从列表移除，并检查 GuildAlt 的已入会界面和双方成员名单。GuildAlt 应显示为普通成员。
5. GuildAlt 回到选角并重新进入，确认公会和职级仍然可见。

服务端构建、23 项公会定向测试和协议回归通过。独立库的双端线路覆盖了申请、重复申请、待审状态、权限拒绝、拒绝与通知、撤回、同意与身份／名单更新。线路以已有副会长权限验证，批准记录为 GuildAlt 普通成员且待审队列为空。用户在 A21 确认申请提交、申请列表和同意符合预期。验收库确认 GuildAlt 已为普通成员，待审队列为空。拒绝、撤回、即时窗口切换和重登沿用线路或待实机证据。

协议和状态见[公会协议目录](../../../protocol/catalog.md)。
