# A21 公会勋章光环

会长在公会信息页配置公会统一的纹章和装饰框。当前 PVF 提供两类各 25 个选项。角色属于该公会且装备了神器或更高稀有度的公会勋章时，才投影该光环。游戏图形设置可以关闭光环显示。[日服改版公告](https://arad.nexon.co.jp/news/update_view.aspx?no=7398)

权限、样式编号和写入由现有公会管理用例处理。样式跟随公会记录，会员离会后不再投影该公会的光环。登录和在线外观都从持久化的穿戴槽读取勋章，因此选角时也能恢复效果。SQLite v39 迁移将原有公会的光环初始化为未设置。

## 实机验收

隔离服登录地址为 `http://127.0.0.1:54780/`。用 Client-59 的会长 `1123` 和 Client-60 的会员 `GuildPilot` 进入 CH10，再到同一个可见城镇区域或公会基地大厅。两个角色均已穿戴可显示光环的勋章。验收库为上一轮莱茵验收库的一致副本，GuildPilot 原来的勋章移到了勋章包。

1. 用 1123 打开「公会 → 公会信息」，进入勋章光环装饰界面。选两个可辨认的纹章和框并保存。GuildPilot 应能看到应用后的效果，普通会员无法保存全会配置。
2. 用两端各看一次本人和对方。若图形设置关闭了勋章光环，先开启。GuildPilot 摘下勋章后光环应消失，重新穿戴后应恢复。
3. 正常退出 GuildPilot 再登录，确认光环和原样式仍在。1123 重开编辑窗口时，应能读回上次选项。
4. 最后由 GuildPilot 主动退会，勋章保留，光环即时消失。1123 和公会的原样式保持。可用会长在编辑界面解除样式，确认会长的光环也随之消失。
