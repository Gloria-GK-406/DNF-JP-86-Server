# A21 莱茵商店守护珠轮换

## 原生入口

现用和上游 A21 PVF 都提供 NPC 383 的货单 150–159。十套货单的勋章和卡片一致，各自有一套四颗守护珠。日服同期公告说明商店换货随公会地下城实际重置，延长地下城时也延长原货单。[日服更新公告](https://arad.nexon.co.jp/news/update_view.aspx?no=7398)

**WireCaptured。** 用户在旧 PVF 的两台隔离探针上分别收到地下城通知偏移 9 为 1 和 151，然后在原版 A21 各买一颗守护珠。两次 `CMD 0x0015` 均为商人 383、货单 150、商品 90032。探针记录分别见 `guild-rotation-probe.runtime.json` 和 `guild-rotation-probe-absolute.runtime.json` 指向的本地日志。

**ClientStatic。** 使用 A21 b1 full `E5A34BBF…`。下列地址为 VA。

| 地址 | 证据 |
| --- | --- |
| `0x02A42C2F` | NPC 解析器识别 `[guild secret shop list]`，读取一至十个货单号，在 `0x02A42CD7` 打开秘密商店标记 |
| `0x019AAC78` | 将标记复制到运行时 NPC 的 `+0x5B5` |
| `0x005BC5B9`、`0x005BC7AE` | 将 `NOTI 0x02E5` 的偏移 0 和 1 保存为莱茵启用标记和完整货单号 |
| `0x025A7D58`–`0x025A7DBB` | 商店菜单在标记打开时调用 `0x005BCD10`，用返回的 ID 替代 PVF 默认 150 |
| `0x0175A850`–`0x0175A871` | 已标记的 NPC 使用同一查询，未开放时返回 -1 并隐藏 |
| `0x005BC9DA` | 偏移 9 写入另一个字段。两次探针对照中没有改变莱茵货单 |

`Tool/PvfGuildMedalShopPatch` 只修改 `npc/guild_reghin.npc`，补上原生列表标签和 150–159。初版内容为 `0.3.3-dev.guild-medal-shop.1`。

## 周期及兑换

当前货单由公会 ID 与有效周期开始月份共同确定。同会成员得到同一货单，延期修改截止时间并保留开始月份。实际重置会换到新的周期，永恒殿堂回到未满净化状态。达到 100% 后，客户端收到开放标记及新货单。兑换按照当前货单重新检查公会、基地实例、净化率和商品，旧货单或当前未上架的商品均被拒绝。数据库结构仍为 v38。

**WireTest。** 使用上一轮延期记录的独立副本平移周期，双客户端分别观察了保留的 154 和实际重置后重新解锁的 155。重置时收到关闭标记和货单 -1，旧货单被拒绝。双端均从当前货单成功兑换，正确货单里的未上架商品也被拒绝。

## 实机验收

Client-55 为会长 `1123`，Client-56 为同公会的 `GuildPilot`。两端指向 `http://127.0.0.1:54280/`，使用 SHA-256 `8E06AC3AEC7A5ACD02C0546818D8B57A56775651DD48BB323F635047D01973A6` 的配套 PVF。验收库为上一轮 53680 延期验收库的一致副本，保留该次延期并将本公会地下城预设到满净化，两个角色均有兑换证书。

1. 两个角色进 CH10，从赛丽亚房间进公会基地，走到右侧地下城入口，打开「莱茵 → 商店 → 守护珠」。
2. 两个客户端应均看到魔法防御力、攻击速度、移动速度和火属性强化四款。
3. 各买一颗，核对证书扣除及守护珠入包。服务端日志应显示 NPC 383、货单 155。
4. 重登后货单应保持相同。跨月隐藏、重新满净化后的换货已通过隔离线路，可用周期副本继续做界面对照。

2026-11-28 用户确认两个客户端货单一致、兑换正常。验收服日志记录会长和普通成员均从货单 155 成交。随后用户截图指出莱茵的头顶名称和菜单名称丢失，旁边安德正常。

## 名称修正

A21 的列表解析使用会前进游标的整数读取函数 `0x028A9310`。当列表后的首个非整数是 `[name]` 时，`0x028A9523` 会消耗该标签。旧 PVF 字符串池已有 `[/guild secret shop list]`，新版在十个货单号后补上这一结束标签，保留后续名称、头顶名称和商人称谓。使用 `0.3.3-dev.guild-medal-shop.2` 的隔离双端线路再次收到货单 155 并成功购买。

名称修正版验收服为 `127.0.0.1:54480`，Client-57 为 1123，Client-58 为 GuildPilot。数据源是 54280 实机购买后的 SQLite 一致副本，逐格核对证书和守护珠一致。配套 PVF SHA-256 为 `88A1474F78034CDB62242F430D34A9DF3E7E997D1C4012FF751A9BF8E37009F7`。进公会地下城入口即可复测头顶称谓与点开 NPC 菜单后的名称。

**ClientVerified（2026-11-28）。** 用户用 1123 确认永恒殿堂满净化时，莱茵头顶和右键菜单的名称均已恢复。仅将该公会当期永恒殿堂的进度降到满值以下后，线路验证了关闭标记和货单 -1，用户重登后确认莱茵消失。守护珠兑换、名称显示和未满净化时隐藏通过实机验收。
