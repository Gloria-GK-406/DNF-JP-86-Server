## 公会频道复测

2026-11-26，用户用 `GuildPilot` 在暗黑城博肯处完成原生建会。数据库记录「测试工会」、唯一会长 `GuildPilot` 和 50 万金币。用户截图中公会名正确，设置按钮仍提示「只有公会会长才能设置」。

首轮修正版同步了职级。第二张 A21 截图确认「设置」仍灰显。服务端日志记录了未处理的 `0x0153`，客户端静态证据确认该按钮读取 `0x0046` 的查看者标志。详见 [公会详情协议](../../../../../protocol/game/server-to-client/NOTI-0x0046.md)。

当前隔离服已迁移到数据库版本 15。隔离库副本的线路探针验证会长可设置 CH11，普通成员尝试改成 CH10 失败，会长重登读回 CH11。现有验收库中的频道初始未设置，会长仍为 `GuildPilot`，金币为 50 万。

用户复测反馈「设置符合预期了」。验收库只读查询确认「测试工会」保存为 CH10，会长仍为 `GuildPilot`，金币为 50 万。换角、重登和旁观身份分别保留各自的证据边界。

1. 在普通频道登录 `GuildPilot`，打开「测试工会」的信息页，点「设置」并确认设为当前频道。
2. 确认面板显示当前频道。回到选角界面再选 `GuildPilot`，检查频道仍在。

92 项协议、71 项应用、7 项公会持久化和 12 项迁移测试通过。扩展的写入口分类测试报告了三条队伍租约方法尚未分类。

## 首轮创建操作

1. 在 Client-25 登录，选择 `GuildPilot`，进游戏后打开原生公会创建入口。名字填「鸢尾25」，宣传填「公会验收」，按窗口流程验证名称、取得单人许可并确认创建。记录入口或发生问题的按钮，以及创建完成提示、剩余金币和眼前公会名。预期金币从 80 万到 50 万。若此前已用 `Iris25` 建会，保留该结果，继续检查身份。
2. 如方便，启动 Client-26，用 `GuildViewer` 进入同频道、同区域，查看 `GuildPilot` 的角色详情或可见名称。核对公会名称。异地时优先记录创建和重登结果。
3. 在 Client-25 正常回到选角，选择 `GuildAlt`。确认未显示前一个角色的公会名称。尝试验与上一步相同的名字，预期被拒。另用一个尚未使用的名字，如 `AltProbe`，继续走创建。预期 0 金币无法建会。
4. 正常退出再登录 `GuildPilot`。确认公会名仍与创建时一致、余额仍为 50 万。若在前面一步卡住，停在该步并反馈界面文案或截图。

两个客户端均使用 trace 配置。反馈到第几步、看到什么，或直接贴截图即可。服务端日志、客户端帧及数据库前后值由开发方核对。当前适用范围为原生创建与身份，申请和完整公会管理界面按后续阶段验证。
