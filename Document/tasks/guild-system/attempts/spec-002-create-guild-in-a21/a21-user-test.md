# A21 公会创建实机验收

## 测试环境

- 隔离服务器网关为 `http://127.0.0.1:48080/`，频道入口为 47001，游戏频道使用 48011 至 48013。客户端配置由 ClientStore 生成。
- [Client-25 登录器](E:/Project/DNF/Client-25/DfoLauncherLocal.exe) 使用测试账号 `GuildA21Lab25`。已有 `GuildPilot`（80 万金币）和 `GuildAlt`（0 金币）。
- [Client-26 登录器](E:/Project/DNF/Client-26/DfoLauncherLocal.exe) 使用测试账号 `GuildA21Lab26`，角色 `GuildViewer`。两个账号的临时密码在聊天里提供。
- 开发 PVF `A97132DD…` 的建会费为 30 万金币。开测前已只读核对三个角色余额，隔离库中公会数为 0。

## 操作顺序

1. 在 Client-25 登录，选择 `GuildPilot`，进游戏后打开原生公会创建入口。名字填 `Iris25`，宣传填 `Guild check`，按窗口流程验证名称、取得单人许可并确认创建。记录入口或发生问题的按钮，以及创建完成提示、剩余金币和眼前公会名。预期金币从 80 万到 50 万。
2. 如方便，启动 Client-26，用 `GuildViewer` 进入同频道、同区域，查看 `GuildPilot` 的角色详情或可见名称。核对公会名 `Iris25`。异地时优先记录创建和重登结果。
3. 在 Client-25 正常回到选角，选择 `GuildAlt`。确认未显示 `Iris25`。尝试验同名 `Iris25`，预期被拒。另用一个尚未使用的名字，如 `AltProbe`，继续走创建。预期 0 金币无法建会。
4. 正常退出再登录 `GuildPilot`。确认公会名仍为 `Iris25`、余额仍为 50 万。若在前面一步卡住，停在该步并反馈界面文案或截图。

两个客户端均使用 trace 配置。反馈到第几步、看到什么，或直接贴截图即可。服务端日志、客户端帧及数据库前后值由开发方核对。当前适用范围为原生创建与身份，申请和完整公会管理界面按后续阶段验证。
