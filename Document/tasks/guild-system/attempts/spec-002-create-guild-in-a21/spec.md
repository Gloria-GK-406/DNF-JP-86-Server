# A21 原生公会创建与身份恢复

| ID | 需求 | 验收 |
| --- | --- | --- |
| RQ-001 | 创建窗口完成名称检查、宣传、许可和最终提交。成功操作只消耗一次部署 PVF 对应的金币 | AC-001，A21 原生 UI 完成一次创建，余额、唯一公会与会长状态实测相符 |
| RQ-002 | 创建许可与授予它的所选角色会话绑定；重名、取消、状态陈旧、余额不足或重复请求按已证形式拒绝 | AC-002，真实帧与自动验证对照拒绝、换角和复发路径，任何拒绝均不产生额外扣费或关系 |
| RQ-003 | 创建后和重登时，角色的公会身份由持久关系决定，查看这个角色时能读到同一身份，切到无会角色时显示清空 | AC-003，采样真实帧和界面，检查当前角色名与公会字段，其余身份数据位置保持正确 |
| RQ-004 | 采样与实现可复查，使用本项目组件及相同 PVF 的隔离服 | AC-004，构建、相关回归、客户端组件标识和协议资料更新通过，正式用户库仍由其所属流程准备 |

范围限于单人创建和对应身份投影。在协议证据不足处继续取证，期间区分真实帧、上游观察以及静态分析。
