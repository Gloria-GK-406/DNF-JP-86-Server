# A21 公会管理验收

验收服沿用「测试工会」。Client-25 是会长 GuildPilot，Client-26 是普通成员 GuildViewer。两边都进 CH10。

1. 用 GuildPilot 打开「公会管理」，确认宣传信息右侧「输入」可点。修改为「管理验收」并保存。在 GuildViewer 界面核对同一公会的宣传。
2. 在「设置各等级权限」中展开普通成员一行，确认会长能操作。保存一次权限设置，重新打开确认修改保留。若客户端提供等级名称编辑入口，改一次名称后重开面板检查。
3. 用普通成员打开管理页，检查宣传和权限写入口是否禁用或提示无权限。
4. 会长重新登录，核对宣传和职级配置。若仍出现「您没有权限」，记录触发提示的具体按钮。

中间的加成购买涉及商品和生效规则，保留在公会成长阶段。此次不以购买结果判断管理配置是否通过。
