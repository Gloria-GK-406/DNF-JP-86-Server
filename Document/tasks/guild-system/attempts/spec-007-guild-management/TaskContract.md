# 公会管理权限和资料

用户确认签到验收后，报告「我用工会会长点击显示我没有权限」，要求完成公会管理。截图显示宣传、加成商品和职级权限，现有公会详情已经恢复会长身份，六档职级权限和名称仍是空记录。

| 意图 | 归属 | 结果 |
| --- | --- | --- |
| 会长管理 | `in_scope` | A21 获得真实会长的管理权限和各档名称，能打开本期支持的管理操作；服务端按持久成员身份校验 |
| 宣传和等级配置 | `in_scope` | 会长可编辑宣传、职级名称和权限配置；在线成员看到刷新，重登不丢，普通成员无法直接写入 |
| 加成购买和权益 | `preserved_upstream` | [根契约 SC-05](../../TaskContract.md)继续负责商品资格、GM 扣费、具体加成生效和到期，其事务和实际收益单独验证。未实现权益的商品不扣 GM |
| 职级关联的其他入口 | `preserved_upstream` | [根契约 SC-02/03/06/07](../../TaskContract.md)保留成员审批、角色任命、设施和社交入口的完整实现 |
| 线上发布 | `not_applicable` | 当前为功能分支实现、独立测试和用户实机验收 |

## 成功条件

| ID | 可观察结果 | 验证 |
| --- | --- | --- |
| AC-1 | 会长收到有权限的职级配置和可用管理入口，普通成员仍只拥有允许的操作 | A21 静态布局、隔离双连接、用户实机 |
| AC-2 | 会长保存宣传、等级名称和权限后，公会成员可读到新状态，重登保持；普通成员、故障或畸形包不能写入或自升权限 | 线路和持久化测试 |
| AC-3 | 上一期数据库可升级，保留公会、角色、GM、捐赠和签到 | 迁移测试及隔离副本验证 |

## 授权

| 类型 | 证据 | 范围 |
| --- | --- | --- |
| task | 用户要求「然后是工会管理，我用工会会长点击显示我没有权限。接下来完成这个功能吧」 | 既有公会项目内实现、测试和本地证据 |
