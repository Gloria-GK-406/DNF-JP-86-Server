# A21 公会管理权限与资料

| ID | 行为 | 验收 |
| --- | --- | --- |
| RQ-1 | `NOTI 0x0046` 按职级顺序写六项掩码、名称。会长默认管理权限由既有会长身份约束。线上刷新、签到和捐赠读取同一份配置。 | AC-1 |
| RQ-2 | `CMD 0x02E3` 编辑宣传。`0x02EB` 写职级权限，`0x02EC` 写职级名。后端只允许当前公会的会长写入，保留会长原有管理权限。严格校验内容、职级和尾随字段。 | AC-2 |
| RQ-3 | 管理写入提交后向当前公会在线成员更新面板，保留各自会长标志和个人贡献。重登恢复。 | AC-2 |
| RQ-4 | v18 升级新增公会职级配置，旧公会按默认配置读，公会资产保留。 | AC-3 |
