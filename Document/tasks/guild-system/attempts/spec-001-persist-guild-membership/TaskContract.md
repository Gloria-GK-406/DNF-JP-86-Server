# 任务契约 · 公会创建与成员关系基础

## 背景与请求

根任务要求「完整公会系统分期实现」。主线有角色金币和软删机制，当前没有公会、成员及待处理申请的权威存储。本期提供后续 A21 用例能复用并独立验证的持久化与领域行为。

## 目标与范围

- 增加核心公会、成员和申请的空库与向前迁移支持，保留旧存档。
- 提供领域契约和实现，用于原子创建、入会申请和审批、持久化身份及名册查询，以及核心成员退出／踢出和解散。创建从开发用 PVF 可取的价格扣角色金币，作为真实写事务的一部分。
- 角色软删时保护现有成员，并清理被删除非成员的待申请。角色身份和公会关系的查询可供后续协议用例调用。
- A21 协议接线、创建许可会话、成员职务和社交扩展由根契约中的后续阶段继续交付。

## 成功条件

| ID | 可观察结果 | 所需证据 |
| --- | --- | --- |
| AC-1 | 建新库及升级基线副本都能得到所需表，升级保留存量账号、角色和资产 | 迁移回归并对照既存数据 |
| AC-2 | 创建一次只扣一次费，产生一个公会和一个会长。余额不足、名称或成员冲突、持久化失败不会留下部分写入 | 服务端事务测试，含失败回滚和重复提交 |
| AC-3 | 有效申请按申请角色与目标公会持久化并可读。批准后角色只加入一个公会，清除待申请。无权限与无效申请不能写成员，查询能读到与记录一致的身份及成员 ID | 领域与真实 SQLite 测试，含两个公会争取同一角色 |
| AC-4 | 普通成员可自行退会，会长必须走解散等允许的路径才能离会。会长能移除本会普通成员并清除其成员关系，越权踢人被拒绝。会长解散清除成员与申请。软删成员被拒绝，软删仅有申请的角色清除待申请 | 应用或持久化回归，检查清理与回滚 |
