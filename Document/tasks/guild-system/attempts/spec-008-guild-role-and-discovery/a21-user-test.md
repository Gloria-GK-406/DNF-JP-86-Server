# A21 成员任命和公会查找验收

验收服沿用「测试工会」。角色用 CH10。两端登录时会长仍是 GuildPilot，GuildViewer 默认普通成员。

1. Client-26 用 GuildViewer 入场。Client-25 用 GuildPilot，在公会成员名单中把 GuildViewer 任命为副会长。核对会长有成功提示、目标收到职级更新，并重开名单或让目标重登确认。
2. Client-25 返回角色选择，用未入会的 GuildAlt 进游戏并打开公会窗口。在「我加入的公会」核对「测试工会」和加入角色 GuildPilot。
3. 点「查看信息」，确认正常打开公会摘要。搜索「测试工会」应返回同一公会，输入不存在的名称应显示找不到。「推荐公会」可打开另一项公会信息。

头像角标取决于客户端是否已加载对应角色。如果在核对角标，两端先走到同一区域。
