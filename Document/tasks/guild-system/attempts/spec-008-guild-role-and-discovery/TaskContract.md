# 公会成员任命与入会前查找

用户要求「先把权限赋予和寻找工会的功能做了吧」，并询问账号内其他角色的公会。A21 实机已抓到成员任命和发现页查询。日服更新说明确认发现页支持账号公会与推荐。

| 意图 | 归属 | 结果 |
| --- | --- | --- |
| 成员任命 | `in_scope` | 会长可任命副会长和其他成员职级。配置具有任命权的副会长可管理同公会较低职级。角色重登后保持新职级 |
| 查找与查看 | `in_scope` | 未入会角色按公会名称打开公开信息。推荐公会及同账号其他角色所在公会也可查看 |
| 资料边界 | `in_scope` | 私有账号公会列表按已认证账号获取。当前角色的会员事实独立于同账号其他角色 |
| 入会申请、会长转让与加成资产 | `preserved_upstream` | 由[根契约](../../TaskContract.md) SC-02、SC-03、SC-05 继续负责 |
| 线上发布 | `not_applicable` | 本轮功能分支实现与独立验收 |

## 验收

| ID | 结果 | 证据 |
| --- | --- | --- |
| AC-1 | 同公会的授权任命立即更新目标身份，新名单及重登读取新职级。其他越权拒绝 | 测试、双连接与用户实机 |
| AC-2 | 名称搜索及查看信息生效，账号列表列出自己其他角色，推荐可查看。未知名称与其他账号的私有列表受限 | A21 静态、线路与用户实机 |
| AC-3 | 旧库升级保留会长、成员、签到、捐赠以及职级配置 | 迁移和独立副本 |

## 授权

用户的「先把权限赋予和寻找工会的功能做了吧」授权两项实现、测试和本地检查点。
