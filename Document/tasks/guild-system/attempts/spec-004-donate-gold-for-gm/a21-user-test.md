# A21 金币捐赠验收

隔离库沿用「测试工会」，推荐频道 CH10。普通成员 `GuildViewer` 起始有 31,000 金币，会长 `GuildPilot` 有 500,000 金币。两人的累计贡献和公会 GM 都从 0 开始。

1. 用 `GuildViewer` 进 CH10，打开「公会信息 → 金币捐赠」，输入 **10,000** 并确认。
2. 核对成功提示、背包金币 **21,000** 和公会 GM **10**。关闭再开公会界面，到「贡献度」查看个人累计 **10**。
3. 捐 **22,000**，核对客户端提示金币不足，背包和 GM 保持上一步数值。
4. 重登 `GuildViewer`，核对金币 **21,000**、GM **10** 和个人累计 **10**。
5. 可切到 `GuildPilot`，确认同一公会 GM 为 **10**，其个人累计为 **0**。

隔离线路已走通两种成员身份、成功回包、金币和 GM 刷新、拒绝及重登。用户界面结果待填写。

## 公会积分内容

最新验收服沿用用户已捐赠的库。选择 `GuildViewer` 进 CH10，直接点公会 GM 旁的蓝色信息按钮。预期公会 GM 为 **100**，列表已有 `GuildViewer` 的「金币捐赠+50GM」、日期和时间。重开窗口或重登后可以复查，不需要再捐金币。

用户在前一版再次看到空列表。此时库里已经记录该笔 50,000 金币和 50 GM，实机服务日志有两条未处理的空请求 `0x02EA`，修正版本已接入并在隔离线路读回这笔实际捐赠。

### 首次捐赠明细验收准备

首次实机验收发现公会 GM 旁的信息按钮打开「公会积分内容」，旧构建没有填充列表。隔离验收库在实机后读到 `GuildViewer` 随身金币 50,000、个人贡献 50、公会 GM 50。新库由该验收库复制升级，旧累计仍可见。

1. 用 `GuildViewer` 进 CH10 捐 **10,000**，预期金币 **40,000**、公会 GM **60**。
2. 点公会 GM 旁的蓝色信息按钮。核对列表出现 `GuildViewer`、「金币捐赠」、本次捐赠日期和 **10**。
3. 关闭再打开，或者重登后再看同一列表。可用会长 `GuildPilot` 核对能看到同一记录。
