# 金币捐赠验证

## 已验证

- AC-1。A21 协议隔离线路使用 `Tool/WireSmoke`，从 0 GM 开始。普通成员捐 10,000 金币后按序收到 `CMD 0x015A` 成功体 `01`、`NOTI 0x000E` 金币 21,000 和 `NOTI 0x0046` GM 及个人贡献各 10。会长重开见 GM 10、个人贡献 0，继续捐 2,000 后金币为 498,000、GM 为 12、个人贡献为 2。普通成员重登读回 GM 12 和个人贡献 10，库中两角色的对应余额一致。
- AC-2。线路验证了负数、零、非 1,000 整数倍、超过 10,000,000、金币不足、错长度和非成员的拒绝，余额与积分无变化。域测试覆盖两个点数上限和成员贡献 UPDATE 故障注入，确认同一事务回滚此前扣金币和 GM 更新。
- AC-3。SQLite backup API 复制上期在用的隔离库，读副本完整性正常，再使用 DbMigrate 实际升级 15 → 16。角色金币、原成员与会长关系和 CH10 均保留，两列新增积分初始为 0。回归覆盖 v13、v14、v15 升级和新库。
- 完整协议项目 2,326 通过、69 跳过。迁移项目全部 42 通过。公会定向运行中，17 项持久化、2 项真实 PVF 和 4 项 Application 测试均通过。Application 扩展架构检查 118 项通过、1 项失败，失败的模块测试夹具缺少落地物配置 `DropMaterializationLimits`。已核对该夹具和依赖在子任务基线相同，隔离发布服成功进入游戏并完成捐赠。
- Host 与 DbMigrate 已发布至独立目录。代码通过[独立审查](../reviews/change-review.md)。独立验收服通过监听端口和 Launcher 网关状态确认，测试数据从零准备。
