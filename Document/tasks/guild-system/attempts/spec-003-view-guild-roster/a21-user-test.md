# A21 公会成员名单验收

验收库副本保留「测试工会」与 CH10，`GuildPilot` 为会长，`GuildViewer` 是为本次名单复测预置的普通成员。`GuildAlt` 仍无公会。原建会验收库保持独立。

1. 用 `GuildPilot` 进 CH10，用 `GuildViewer` 进 CH11。打开公会成员页，核对两人都在、只有 `GuildPilot` 是会长，两人的在线频道各自正确。
2. 将两人切到同一个频道，并走到暗黑城的同一张地图。等双方能在场景里看到对方，再关闭并打开成员页，核对两行是否都有亮色及头像。
3. 切换到「全部成员」，核对两名角色和会长职级。正常退出 `GuildViewer`，关闭再打开成员页，核对其仍在名单里并变为离线。
4. 切到同账号的 `GuildAlt`，确认无法查看「测试工会」成员。

用户截图显示两人均在线，一行亮色，一行灰色并带频道图标。收到截图后复查两条游戏连接，`GuildViewer` 对应 CH10，`GuildPilot` 对应 CH11。用户随后确认两名角色在同一区域时名单亮起。亮色检查见 [名单协议](../../../../../protocol/game/client-to-server/0x0043.md)。

隔离线路已验证普通与全量回包、跨频道和断线状态、无公会拒绝和分页参数拒绝。85 项协议、7 项持久化和 58 项架构定向测试通过。真实界面结果待回填。
