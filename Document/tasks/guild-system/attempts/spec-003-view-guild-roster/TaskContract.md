# 任务契约 · 在 A21 查看公会成员

上一阶段已建立可在客户端识别的公会与会长身份。用户确认推荐频道设置符合预期，要求推进下一项。匹配版本的客户端打开公会面板时发出成员名单请求，现有隔离服日志记录了该请求，持久化公会关系已可查询。

## 目标与范围

公会成员能在 A21 成员页查看所属公会的会长和成员，列表显示角色名、等级、职业、职级、在线频道或离线状态。覆盖默认列表与首次查看全部成员。无公会角色、格式错误和未经证实的后续分页请求不能取得名单。

## 根意图覆盖

| 意图 | 归属 | 验收 |
| --- | --- | --- |
| 公会身份和名册使用同一角色成员关系 | `in_scope` | AC-1、AC-2 |
| 协议证据归档及隔离验证 | `in_scope` | AC-3 |
| 搜索、申请、审批、员工操作、备注写入、精确离线时长及其他阶段功能 | `preserved_upstream` | 仍由[根任务](../../TaskContract.md)处理 |
| 正式运行环境切换、PR 或发布 | `not_applicable` | 根任务的本地实现与隔离验证授权 |

## 约束

- 返回角色数据及在线状态时分别使用当前持久成员事实与在线会话。客户端可提交的分页参数不授予查看其他公会的能力。
- 以本项目 A21 为验收对象。区分上游形状、当前客户端静态证据、隔离线路验证与实际界面反馈。自动验证使用隔离副本。

## 成功条件

| ID | 可观察结果 | 所需证据 |
| --- | --- | --- |
| AC-1 | 当前公会的普通名单及首次全量名单都显示正确的会长和成员资料，在线者标明其实际频道，离线者不显示在线频道 | 同公会双角色、另一公会或未加入角色的对照数据，匹配 A21 的收发与界面观察 |
| AC-2 | 无公会、格式错误与非初始全量请求不返回名单，不改动公会或角色数据 | 隔离线路与持久状态前后核对 |
| AC-3 | 产品可构建，协议实现和实机待确认项有可复查记录 | 定向回归、协议资料页与 A21 操作步骤 |
