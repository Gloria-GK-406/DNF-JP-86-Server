# A21 公会成员名单

| 需求 | 结果 | 验收 |
| --- | --- | --- |
| RQ-001 | 普通名单与首次全量名单读取当前角色所在公会，显示会长和成员的角色名、等级、职业、职级及在线状态 | AC-001，核对持久成员、在线和离线角色与隔离收发结果，实机打开两个名单视图 |
| RQ-002 | 畸形请求、无公会角色和没有证据支持的非零分页参数收到拒绝，不能选择公会或更改存档 | AC-002，比较拒绝帧、关系和余额 |
| RQ-003 | 使用与现有 A21 匹配的名单帧和会长职级投影 | AC-003，核对普通和全量回包的区别，确认协议文档与操作步骤对应 |

[普通名单](../../../../../protocol/game/client-to-server/0x0043.md) 的请求为空，首次 [全量名单](../../../../../protocol/game/client-to-server/0x008C.md) 请求为四字节零。两者的名单包含在线和离线成员。客户端读取全量名单末尾的附加四字节。公会成长、备注编辑和精确离线时长沿用根任务后续边界。
