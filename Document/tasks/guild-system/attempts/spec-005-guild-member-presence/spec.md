# 公会成员上下线通知

| ID | 规则 | 验收 |
| --- | --- | --- |
| RQ-01 | 选角进入世界并发布当前会话后，向所属公会的其他在线成员发送 `NOTI 0x0040`。用 `u8 1`、`u8 频道`、角色名 DSTR 表达上线。A21 客户端更新名单内状态并显示进入频道提示 | AC-1 |
| RQ-02 | 正常回选、退出、断线和会话替换共用会话清理。只对已经入场且确实离开的角色发送 `u8 0`、`u8 0`、原角色名 DSTR。已进入世界的后继会话有优先权，未入场或重复清理不发离线 | AC-1、AC-2 |
| RQ-03 | 同会名单由持久成员关系决定，收件人的在线性由现有通知机制解析。本人、其他公会与未在世界的角色不收通知 | AC-2 |
| RQ-04 | 保留验收公会、角色与捐赠数据，在独立服启动两端。用户看着打开的名单，操作另一端上线、回选和断线，再核对提示和原地更新 | AC-3 |
