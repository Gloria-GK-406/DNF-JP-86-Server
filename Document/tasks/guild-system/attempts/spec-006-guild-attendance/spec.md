# A21 公会签到

| ID | 可观察行为 | 验收 |
| --- | --- | --- |
| RQ-1 | 已发布入场的公会角色按服务器本地日期签到。同会同日同角色只记一次。记录独立于在线状态，查询和下线不写签到。 | AC-1 |
| RQ-2 | 公会信息 `NOTI 0x0046` 填写新签到人数和成员总数，首次签到向同会在线成员投影各自的公会信息。频道设置及捐赠刷新沿用相同的计数。 | AC-2 |
| RQ-3 | 实机点击蓝色信息按钮发出空体 `CMD 0x02E9`。成功 `01 count:u16 names:DSTR[count]`，取当天已签到的当前成员，非会员收不到记录。 | AC-2 |
| RQ-4 | 旧库保留成员与捐赠，升级后从空签到记录开始。 | AC-3 |
