# 公会自动签到

## 目标和范围

A21 成员选角进入游戏时自动签到。右侧公会信息显示今日已签到人数和当前成员总数，左侧「今日签到情况」从同一数据列出今日已签到的现成员。

| 意图 | 归属 | 结果 |
| --- | --- | --- |
| 自动签到 | `in_scope` | 入场时按当前公会、角色和当日去重，签到在下线和重启后仍有效 |
| 计数和明细 | `in_scope` | 两处共用记录，延续既有公会身份、频道与捐赠字段 |
| 日期口径 | `in_scope` | 使用服务端本地日历日，依据已检查的 A21 参照行为。原服的重置时刻仍待证实 |
| 签到奖励与其他成长功能 | `preserved_upstream` | 由[根契约 SC-05](../../TaskContract.md)承接，具体奖励需同版本证据 |
| 线上部署与实机代操作 | `not_applicable` | 本期交付实现与隔离验证，原生客户端由用户操作 |

## 成功条件

| ID | 可观察结果 | 验证 |
| --- | --- | --- |
| AC-1 | 角色进入游戏后签到一次。重登、切频道、下线与重启不会增加同日计数，跨日至新日计数。非会员无签到 | 定向持久化及 A21 双连接线路，覆盖跨日、去重和隔离 |
| AC-2 | 右侧人数和左侧明细一致。两成员依次入场为 1/2、2/2，已下线当天仍列出，其他公会不可读。公会身份和捐赠信息保持 | 线路验证原生协议，实机由用户确认进度和明细呈现 |
| AC-3 | 可从上期库升级并保留公会与捐赠 | 迁移工具及独立库验证 |

## 授权

| 类型 | 证据 | 授权范围 |
| --- | --- | --- |
| task | 用户在确认自动签到与两个显示区的方案后说「你来实现吧」 | 现有分期内实现、测试和本地检查点 |
