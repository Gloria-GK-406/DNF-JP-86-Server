# A21 加百利秘密商店规格

普通地下城进入通关结算时，玩家可按 A21 配置遇到加百利，并从原生商店界面购买本场商品。范围和用户参与见任务契约第 1 版。功能交付为供 A21 实机验收的候选。

| 需求 | 行为 | 验收 |
|---|---|---|
| RQ-001 | 普通副本结算按 PVF 抽 NPC 和商品。副本专表优先，通用表用副本基础等级及入场人数。未命中有效货池时使用德利拉。 | AC-001 用确定性抽签覆盖 1000、1002、1003、1004 和空池。清场通知后发一次 NPC，只有秘密商店分支跟商品列表。 |
| RQ-002 | 同场各成员 NPC 一致。各人当场商品、价格和剩余量独立，关窗重开及重复投影保持已生成的货单。 | AC-002 双人同局、重复结算、重开窗和成员离场回归。 |
| RQ-003 | 购买使用个人当局货单，支持金币或道具支出、限量与有限拒绝。扣费、入包和库存共同提交。同一效果请求重放只恢复当前状态，不再次结算。 | AC-003 自动覆盖币种、数量、余额、容量、回滚及重放。客户端 ACK 和背包更新同已提交状态一致。 |
| RQ-004 | 离图、退出和换局后旧货单不可用，普通 NPC 商店与特殊副本结算保持既有行为。 | AC-004 验证旧货单不可访问、特殊副本分支、德利拉通知及普通购买回归。 |
| RQ-005 | 交付可构建候选、协议证据与编号实机测试步骤，由用户操作真实客户端。 | AC-005 记录当前构建、自动测试、候选启动条件及待采客户端样本。 |

契约加成、浮价、活动附加条目及史诗碎片交易延续调查边界。A21 购买和商品列表宽度有客户端静态证据。商品支付、ACK 业务含义与组队库存先采用参照服语义，后续以真实客户端结果确认。
