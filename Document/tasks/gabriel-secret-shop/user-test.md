## 步骤

1. **金币购买、重开与售罄。** 单刷赫顿玛尔旧街区。通关后点加百利，记录初始金币、晶块数量和货单。买一个，预期扣 100 金币、加一个黑色小晶块、剩余两枚。关窗重开应仍剩两枚。买完后确认货单售罄，回城再进新一局应重新生成三枚。第一次成功和售罄时各保留抓包。
2. **道具支付。** 在腐烂之地首次验证时用少于两个雕像的角色出场，尝试购买并记录拒绝提示。准备两个雕像后再进图，购买手镯，预期雕像减二、金币保持、装备入包、货单售罄。记录购买前后背包与 ACK。
3. **1004 与重登。** 刷绝望的棋局，购买设计图，预期扣 300 金币并入包。正常回城、退出并重登，核对前面各次已购买物品和花费。原局商店随退出失效。
4. **双人隔离。** 双人刷赫顿玛尔旧街区，两边应同时看到同一个加百利。A 买完，B 仍能打开并买自己的三枚。A 回城后 B 若仍在原结算，应保有自己的剩余量。两边分别记录金币、晶块、库存和对应客户端日志。
5. **普通结算回归。** 在同一入口刷蘑菇庄园（DGN 156）。该地图沿用客户端 PVF 的原始权重。观察到德利拉时，确认普通结算和原有回城／翻牌流程正常。

重点采集 `NOTI 0x001F → 0x0117 → 0x0118`、`CMD 0x0129` 开关及 `CMD 0x0128` 购买请求和应答。反馈地图、角色、成功或拒绝提示、三种余额与资产变化，以及客户端日志相应时间段。
