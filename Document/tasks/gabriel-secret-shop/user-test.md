# 加百利秘密商店 A21 实机测试

候选分支为 `feature/gabriel-secret-shop`。实机使用独立 Host、端口、日志和实际主干玩家库的一致性测试副本。启动时先确认主干 Host 与实际数据库配置，使用 SQLite backup API 制作副本并执行 `quick_check`。连接地址、账号角色和数据库副本路径在确定测试窗口后记录。客户端通过 ClientStore 生成或同步 trace 测试客户端。

## 测试配置

- Host 发布目录为 `artifacts/gabriel-secret-shop/host/`，候选二进制版本为 `0.3.5+5a9143e1c88502f42929a80fe22dcec7d58e3fa0`。

- 使用已能进入天空之城这三张普通地图的角色。金币至少 600，准备两个哥布林铜雕像（道具 600）和空背包格。双人测试使用两个不同账号的角色，每方另备 300 金币，以便分别观察各自的账号共享材料余额。

## 步骤

1. **金币购买、重开与售罄。** 单刷龙人之塔。通关后点加百利，记录初始金币、晶块数量和货单。买一个，预期扣 100 金币、加一个黑色小晶块、剩余两枚。关窗重开应仍剩两枚。买完后确认货单售罄，回城再进新一局应重新生成三枚。第一次成功和售罄时各保留抓包。
2. **道具支付。** 在人偶玄关首次验证时用少于两个雕像的角色出场，尝试购买并记录拒绝提示。准备两个雕像后再进图，购买手镯，预期雕像减二、金币保持、装备入包、货单售罄。记录购买前后背包与 ACK。
3. **1004 与重登。** 刷石巨人塔，购买设计图，预期扣 300 金币并入包。正常回城、退出并重登，核对前面各次已购买物品和花费。原局商店随退出失效。
4. **双人隔离。** 双人刷龙人之塔，两边应同时看到同一个加百利。A 买完，B 仍能打开并买自己的三枚。A 回城后 B 若仍在原结算，应保有自己的剩余量。两边分别记录金币、晶块、库存和对应客户端日志。
5. **普通结算回归。** 选测试三图之外、PVF 明确只出德利拉的一张已开放地图，例如冰心少年 DGN 41。确认普通结算、德利拉和原有回城／翻牌流程正常。

重点采集 `NOTI 0x001F → 0x0117 → 0x0118`、`CMD 0x0129` 开关及 `CMD 0x0128` 购买请求和应答。反馈地图、角色、成功或拒绝提示、三种余额与资产变化，以及客户端日志相应时间段。
