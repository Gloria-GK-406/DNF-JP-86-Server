## 收尾检查

1. 正常退出游戏，再重新登录：已开出的物品、强化、期限、交易限制都还在。
2. 失败的打开（第 4 步守护者那次）不扣礼包，背包不变。
3. 每一步都按实际看到的记录：通过 / 失败 / 现象。失败时记下礼包 ID 和角色。

## 未覆盖

- 拍卖行优惠券、技能类型扩展券等仍拒绝的服务类道具：后续处理。
