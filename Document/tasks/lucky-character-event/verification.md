## 用户反馈后的复测

隔离复测 Host 重新发布并通过 TCP 验证。幸运角色进城默认状态 0，在城镇和普通选图界面均可通过 `0x0233` 切换为 2 再切回 0。普通角色收到资格拒绝。Application 筛选 85 项与 Protocol 筛选 72 项通过，覆盖击杀及通关经验在既有奖励之上完整翻倍，以及单独投影燃烧增量。两套新客户端均通过 ClientStore 校验。

A21 静态确认状态 1 会画成勾选，状态 0 才是未勾选；确认通关面板有两项幸运奖励，频道内的即时明细无预设名称。静态结论和证据见 [燃烧状态](../../../protocol/game/server-to-client/NOTI-0x01EB.md)、[频道奖励](../../../protocol/game/server-to-client/NOTI-0x0025.md#幸运角色与频道奖励明细2026-11-28) 与 [选角绘制](../../../protocol/game/server-to-client/NOTI-0x0406.md)。复测用的 PVF 为开发通道 `A97132DD…`，对照 PVF 为上游 `8FA275A3…`。
