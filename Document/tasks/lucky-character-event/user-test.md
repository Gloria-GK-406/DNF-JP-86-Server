# 幸运角色 A21 实机验收

使用 A21 客户端、功能测试服务及获授权的主干玩家库。准备两名不同基础职业、处于可得经验等级的角色，分别在两条客户端连接上登录。角色 A 的职业先进入活动名单，角色 B 暂为普通角色。保留开始前的经验、技能等级和疲劳截图。

1. **活动关闭与排期。** GM 活动管理里找到「幸运角色」，确认初始关闭。通用配置中选角色 A 职业，设置一个短的未来时段，保存后启用。到开始前选角，确认两个角色均无标记。开始后重新请求选角列表，确认 A 命中、B 未命中。再测同基础职业的不同转职或觉醒角色。
2. **入城和手动切换。** A 进入城镇，记录幸运提示、一个已学 PvE 技能、一个未学技能及一个 EX 技能。已学的适用 PvE 技能应临时加一级。分别检查停用后的等级回退和重新启用后的恢复，确认快捷栏未重新排列。进入决斗频道核对决斗技能等级。
3. **经验对照。** A 与 B 组队进入普通图。关闭疲劳燃烧，保持其他经验福利一致。分别记录杀怪和通关界面。A 的杀怪经验基数增加 10%，A 显示本人通关 +15%，B 显示队伍通关 +10%。第二轮把 B 的职业加入名单，两人各获本人 +15% 及队伍 +10%。另用 A 完成有基础经验的普通任务，核对 +10%。
4. **疲劳燃烧。** 在城镇让 A 开启燃烧，核对按钮状态。记录进入普通图、首次走到新房间、回到旧房间的疲劳差值。常规每房耗 1 点时，前两次各耗 2 点，回访采用原规则。核对相应杀怪和通关燃烧经验，关闭后再跑一次。另用疲劳不足、无消耗活动和封印的藏宝地确认原行为。
5. **共享神器。** 恢复 A 幸运、B 普通的混合队伍。已用固定样本自动核对额外神器的无专属归属。实机出现可辨识的额外装备时，由 B 拾取，记录装备代码和入包结果，同场拾取方式遵循现有队伍设置。若自然掉落未能区分来源，保留功能实机的地面和拾取日志，将额外掉落识别留为待补证据。
6. **过期和跨局。** 在一局开始后让活动到期或手动停用。完成当前局，核对进图冻结的福利。随后返回城镇，检查技能、按钮和选角标记消失，再进一局确认使用停用后的规则。另在活动中途切换职业范围，确认已开副本和之后的普通任务分别取正确资格。
7. **重连与退出。** 在混合队伍局中，分别以重连原有副本与永久退出队伍走两轮。核对仍在原局的冻结权益，以及离队后普通角色通关加成的变化。完成后再次查询该次已结算结果，核对总经验只入账一次。

反馈时按编号给出通过、失败或未跑，附角色、地图、时间点及相关截图。抓包重点关注 `0406 → 0013 → 01EB`、`0233` 应答、清算 `0023` 和累计经验 `0025`。当前状态为待实机。
