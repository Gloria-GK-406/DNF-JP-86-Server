# 独立实现复核

初轮复核通过共享神器生成、共享归属和普通队友拾取路径，也确认清算以当前成员与可结算成员的交集为准。初轮发现实际疲劳扣除、图内刷新以及断线测试步骤需要修正。

复核确认新房击杀燃烧按足额实付标记发放，扣费与房间发布共用事务。普通副本入场按冻结名单投影技能，图内暂缓活动刷新，回城按当前配置重发。断线场景按基线的退席、重选和再取资格验证。
