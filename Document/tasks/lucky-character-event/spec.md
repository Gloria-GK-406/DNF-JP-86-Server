# 幸运角色活动规格

## Why and Outcome

运营指定一段时间和一批职业。开放时，合格角色在原生客户端看到活动资格并按本期规则领取全部适用收益。同行的普通角色可领取组队通关经验。

## Scope

覆盖 GM 活动操作、普通副本、普通任务和 A21 资格刷新。按 [TaskContract](TaskContract.md) 保留已有掉落、账本和事务边界。

## Requirements

| ID | Requirement |
| --- | --- |
| RQ-001 | 默认禁用。GM 配置职业名单或全职业、开始和结束时间，独立操作开关。资格在 `Enabled && StartsAt <= now && now < EndsAt` 成立时有效。 |
| RQ-002 | 开始副本时冻结每位角色的幸运资格及本次燃烧选择。清算用实际参团资格，永久退出丧失后续队友收益贡献。当前局跨时间边界继续按进入时的资格。 |
| RQ-003 | 幸运击杀和任务经验分别 `+10%`，本人通关 `+15%`，与至少一名其他合格幸运角色组队通关 `+10%`。以各自基础经验计算，加成按来源分别入账。 |
| RQ-004 | A21 选角、入城及活动变化后获得名单投影。通关显示两个新增经验值，一致反映实际入账。 |
| RQ-005 | 幸运角色可在城镇显式免费燃烧。禁用图和免耗图采用原扣量。适用的实际燃烧扣量与对应加成一致。 |
| RQ-006 | 普通副本的神器额外收益 `+150%` 仅归对应幸运角色。既有共享地面掉落使用现有规则。适用已学 PvE 技能临时 `+1`，保留永久学习等级和 PvP 结果。 |

## Acceptance Criteria

| ID | Covers | Criterion |
| --- | --- | --- |
| AC-001 | RQ-001 | 修改后反读配置、重启恢复、在开始和结束边界选角或进图，只有有效职业生效。 |
| AC-002 | RQ-002、RQ-003 | 分别以 1000 基础经验验证幸运单刷 1150、一幸一普 1150/1100、双幸 1250/1250，多个队友不上叠。任务和击杀的本人增量为 100。重复清算不新增奖，离队和重连按既有结算边界。 |
| AC-003 | RQ-004 | 名单与空名单、`0x0023` 两个金额、`0x0025` 累计可用测试与 A21 画面核对。选角和在线切换不能产生相反的资格。 |
| AC-004 | RQ-005 | 生效的燃烧消耗额外疲劳并获得相应收益。开和关、余额不足、逐房扣除、免耗活动、禁用图和重连都一致。 |
| AC-005 | RQ-006 | 可控抽取证明普通队友不获得额外装备，幸运目标独占额外神器且基础共享抽取保留。普通已学、未学、EX 技能及 PvP 逐项核对。 |

构建、协议编码与玩法实账自动验证 + 用户 A21 编号验收，依定稿契约记录。布局、PVF 与第三方实现的证据见 [取证输入](evidence.md)。
