# 普通决斗场 1vs1 入口取样

用隔离测试服的 CH60。两个账号分别选 `PvPCapture` 和 `aaa`，两名角色身上的测试装备已在隔离库中配置。入口见 [A21 三种决斗场入口](../../../protocol/game/client-to-server/0x00C3.md#a21-三种决斗场入口)。

1. 两边先进 CH11 选角。在城镇点右侧「决斗场」，选中间的「普通决斗场」。确认右上角显示 CH60，右侧出现 1vs1。
2. 只在 `PvPCapture` 窗口点 1vs1 的「开始游戏」。确认界面进入等待，然后点「取消」，确认退回待机。
3. 两边都回到待机后，先让 `PvPCapture` 点「开始游戏」，再让 `aaa` 点一次。观察双方是否出现对阵名单，是否完成加载并进入同一张地图。
4. 有条件时打完一场。确认结果界面关闭后回到决斗大厅，可以再次匹配。

首版覆盖同频道 1vs1。抓包记录与测试服 PID 位于 `artifacts/pvp-skill-capture-20261123/ordinary-matching-capture.path` 指向的目录。
