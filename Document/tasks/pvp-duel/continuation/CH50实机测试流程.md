# CH50 决斗场实机测试流程

本轮用当前隔离测试服的 CH50。先用两个不同账号完成个人战和团队战，再测断线及战绩读回。技能学习已由用户确认，切页和换槽已有 A21 成功回包。

## 准备

- A 用「启动-PK取证客户端.cmd」，选 `PvPCapture`。
- B 用「启动-PK陪测客户端.cmd」。首次登录时在选角界面新建一个角色。
- 两边都从城镇右侧「决斗场」选择左边的「传统决斗场」，进入 CH50。开打前各截一次战绩，记录能看到的胜负场、段位和经验。入口对照见 [A21 三种决斗场入口](../../../../protocol/game/client-to-server/0x00C3.md#a21-三种决斗场入口)。

## 按顺序测

| 步骤 | 操作 | 预期结果 |
| --- | --- | --- |
| 1. 建房与密码 | A 建个人战房，设密码，先单人尝试开局。B 先输错密码，再用正确密码加入。 | 单人无法开局。B 输错时留在大厅，输对后进入房间，A 看到 B 入座。 |
| 2. 个人战与再战 | B 点准备，A 开始。让 A 打倒 B。两边看完结算并关闭，回房后再开一局。 | 两边都能进入场景、看到胜负和结算，并能回到等待房。每局正常结束后，胜方胜场加一，负方负场加一。 |
| 3. 团队战 | 等双方回到等待状态，切到团队战，A、B 分属不同队。B 准备后 A 开始，再打一局到 KO。 | 两边显示同样的队伍配置，胜方对应正确，结算后回房。 |
| 4. 对战中断线 | 再打一局个人战。双方都能行动后，关闭 B 的游戏窗口或进程，A 保持在线。 | A 胜并回到等待房。B 重登后记一场负，A 只多一场胜。 |
| 5. 重登读回 | A、B 正常退出后重新进 CH50。 | 战绩和最后一次结算一致。 |

第一轮优先跑到第 2 步。若无法开战、KO 后没有结算或回房后无法再开，记下最先失败的步骤，同一局先别重开，方便对照两边画面和服务端日志。
