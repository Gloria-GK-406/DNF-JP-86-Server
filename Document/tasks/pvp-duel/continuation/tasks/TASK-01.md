# TASK-01 — 统一频道技能组选取与读取

## Task Unit Contract

- Revision: 1
- Outcome and references: 选角、当前角色状态、完整刷新与回放共用频道的技能组。决斗页仍独立保存，现有选角初始化和技能编辑权限沿用。覆盖 T-001，支撑 RQ-001 和 AC-001 的服务端部分。
- Owned boundary: 频道身份和入场状态的技能组字段、技能组选取及当前状态读取，和受其影响的构造夹具。技能点公式、协议布局、数据库结构和编辑开放规则沿用。
- Required checks: 全解决方案构建。回归普通及决斗频道身份、选角、已存两组数据、技能编辑与切页、回放、持久化及真实 TCP 决斗进房。
- Result review: not-required。这里沿用既有频道映射和技能规则，已定向覆盖各入口与普通组隔离。整期完成后仍做独立结果审核。

## Detailed Plan

1. 从 `ChannelEntryIdentity` 统一导出技能组，将结果写入 `ChannelEntryPolicyState`。入场、在线刷新和回放取同一映射。
2. 当前角色状态经已有技能领域读取页面。选角仍调用现有决斗初始化，完整状态投影读频道的技能组。编辑服务按技能组保持现有编辑边界。
3. 将测试夹具的频道技能标志改成实际组值，检查环境映射与普通、决斗的已存页及账本读回。保持旧评审文件在原路径。

## Result

- Outcome: done
- Changed: 频道身份统一提供技能组，入场状态携带组值。选角、当前视图、刷新和回放都消费该值，当前视图经技能领域读取决斗页。
- Why: 频道分类只有一个来源，技能读取复用现有按组存储和点数服务，保留原先初始化、点数公式及编辑权限。
- Checks: 解决方案构建 0 错误、0 警告。应用 165 项、协议 53 项、持久化 11 项、真实 TCP 8 项通过。生产项目引用检查通过。
- Remaining: A21 首屏与重登入场、编辑和切页采样留给后续单元。
