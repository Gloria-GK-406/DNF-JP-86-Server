# 决斗场一期恢复规格

玩家切入决斗频道后应获得独立技能页和准确点数，能在 CH50 通过自由房完成个人战或团队战，并在重登后读回有效战绩。

## Requirements

| ID | Requirement |
| --- | --- |
| RQ-001 | 当前频道决定技能组。选角时按组初始化并读回，当前角色状态、完整刷新和回放使用同组技能及 SP/TP。普通组活动页和决斗技能行独立。 |
| RQ-002 | 在有 A21 证据且允许编辑的状态下，决斗技能操作写入对应组和页。对战或结算期间拒绝编辑。决斗切页和成长补授按 A21 取证处理。 |
| RQ-003 | CH50 自由房接受个人战、团队战、密码、邀请和准备。第三会话能看到准确的大厅快照与增量。现有普通组队、安图恩及两者的选角和离场行为保留。 |
| RQ-004 | 环境 24 开局即对战。对战中离场判负，终局后保留结果，正常停服取消未终局比赛。按已定一期规则持久化有效战绩并能回到等待、继续开战。 |
| RQ-005 | 逐个核查环境 8、13 的客户端加载、连接、开战和战绩。只对已有验证的环境开放相应流程。 |
| RQ-006 | 可从当前主线数据库结构迁移。保留角色段位、评级、技能初始化和两组技能行，以及既有主线数据。 |

## Acceptance Criteria

| ID | Covers | Criterion |
| --- | --- | --- |
| AC-001 | RQ-001 | 普通与决斗组的数据不同，首次和再次进决斗、完整刷新和重登显示对应的页与按该页算出的 SP/TP。普通活动页保留。自动化覆盖选角和回放，A21 核对客户端表现。 |
| AC-002 | RQ-002 | 用实机样本验证支持的编辑和切页，比较提交或拒绝前后对应组。验证普通加点、换槽、退款和切页。若证实需要成长补授，验证幂等、付费等级和槽位保留。 |
| AC-003 | RQ-003 | A21 两个以上参战位验证密码、邀请、个人及团队模式。第三会话的房间增量等于新进大厅快照。组队互斥和安图恩邀请及离场通过回归。 |
| AC-004 | RQ-004 | CH50 普通 KO 出结算并回等待，能再次开局。对战中断线、终局后离开、停服和重复结算符合约定。重登和重启后校验战绩。 |
| AC-005 | RQ-005 | 各自记录 8、13 开战过程中 A21 实际收发及能否完成，核对未验证环境行为和已验证环境战绩权益。 |
| AC-006 | RQ-006 | 对一致副本演练迁移，比较数据和结构，重复运行无重复写入。 |

## Success Evidence

以 [任务契约](TaskContract.md) 的证据要求为准。把真实 TCP 和隔离数据库测试结果与 A21 观察分开。A21 结果注明构建、PVF、频道与操作，回写对应协议页。
