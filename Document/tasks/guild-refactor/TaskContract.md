# JP86 公会系统重构任务契约

## 背景与目标

用户要求「起任务契约一次性完成全部的重构任务」。范围来源为 [公会系统设计评审与重构方案](../../../../../../Document/JP86-公会系统设计评审与重构方案-20261128.md)。本次在已有公会工作树的磁盘状态上实现五组改动并整体验证，保留现有玩法、活动裁定、协议帧序及历史数据。

## 范围与验收

| 意图 | 归属 | 可验证的完成条件 |
|---|---|---|
| RI-1 通知受众与资料投影 | in_scope | 权益和红包仅选本会成员，解散保留申请人。改名及会标按本会、盟会、外观观察者分别投影，保留私有 ACK。检查调用路径与受众测试。 |
| RI-2 基地实例及准入 | in_scope | 城镇、仓库、基地商店、合成使用相同的实例归属依据；选图离城前保存每名队员本次来源，正式入场拒绝会话、会籍、实例或区域不符；正常单人与组队仍可进入。用准入及现有副本回归验证。 |
| RI-3 会籍代际 | in_scope | 每次入会得到新的持久标识；个人月度累计、领奖资格、日常榜及跨阶段副本资格能区分同秒重新入会。全会历史及角色级、实例级去重保持原语义。新库与隔离旧库迁移、重新入会、重试及历史归属兼容有证据。 |
| RI-4 公会 GM 与金币改名 | in_scope | GM 入账、扣款和历史已花维护一处，捐赠、副本、会标、商品沿原事务执行。金币改名拒绝不会遗留名称写入，正常扣款、临界值、重复结算及回滚可验证。 |
| RI-5 仓库托管、端口与规则归属 | in_scope | 仓库以显式端口绑定同一物品事务，删除运行时能力转换；保护 UID、拆堆、共享材料格与审计回滚。迁走已明确归属的通用存储操作，职级默认值和覆盖值统一解析。验证接线与相关回归。 |
| RI-6 一次性交付 | in_scope | 同一工作树具备上述实现、兼容迁移和验证记录；区分本次自动验证与以往 A21 实机证据。 |

## 执行边界与授权

| 能力 | 授权原文 | 范围 |
|---|---|---|
| task | 起任务契约一次性完成全部的重构任务 | 写契约，在指定工作树完成上述重构、编译和隔离测试。 |

已有未提交文件属于当前功能基线。使用隔离数据验证，保留工作树中既有成果。公会人数上限沿用评审裁定，仅在有确切规则来源时落实数值；单凭线协议容量无法推定产品上限。基地战搁置和升档撤回沿用既有裁定。部署、玩家库切换及远端操作在本任务之外。
