# 实机验收：成就与称号簿

状态：待用户测试。客户端和PVF不修改。

1. 重登角色，打开称号簿五分类；确认既有称号正常、无断线或错位。先验证非空书槽，因为0166扩展尾字段目前仅有上游参照。
2. 对尚未完成的30次击杀条件（PVF achievement4303 → title6501 → item26596）击杀普通怪物，确认进度持续变化；达到条件后称号解锁且书槽有实物。已有角色可能早已满足，不保证该例可重复验收。
3. 取出新称号至称号装备位，再存回；名称、强化/附魔/增幅及外观应保持。重复点击、取出到已占装备位时不应丢物品，也不应卡等待。
4. 使用事件分类开放槽，尝试从主背包存入永久称号、交换、取回；锁定或有期限的称号应拒绝并保持原状态。
5. 打开同频道在线玩家的称号簿；查看不应改变自己或对方进度/物品。
6. 重登后复查进度、书槽和装备；已取出的称号不应因重登再发一件。

评分、职业限制等未支持条件见 [实现说明](implementation.md)，不按任意客户端上报补完。
