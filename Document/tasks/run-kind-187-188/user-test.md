## 1. 普通副本（回归）

1. 单人进入任意普通副本，过房间、击杀首领。预期：通关、翻牌、经验与掉落正常。
2. 通关后选择“再次挑战”（返回选图）。预期：直接回到同一副本的普通迷宫选择。
3. 组队进入普通副本，一名队员死亡并使用复活币。预期：复活成功、扣 1 枚复活币。
4. 组队团灭。预期：约 10 秒后全员回城，按原规则施加虚弱。

## 2. 地狱（手动深渊）

1. 用深渊门票以地狱模式进入一个普通副本。预期：入场帧带深渊雾，深渊房出现深渊怪物。
2. 通关后离开。预期：不恢复普通重挑意图（与改动前一致）。

## 3. 镜像阿拉德

1. 接镜像任务后进入。预期：任务帧正常、怪物等级固定。
2. 房间加载完成后检查镜像次数显示。预期：次数刷新正确。
3. 通关。预期：任务上报正常，不解锁难度。

## 4. SAO 塔 / 绝望之塔

1. 在 GM 页启用 SAO 入口活动，进入 SAO 当前楼层并击杀首领。预期：清场奖励在同一次击杀里发放，楼层推进。
2. 在 GM 页停用 SAO 活动。预期：入口隐藏、无法进入。
3. 进入绝望之塔，通关。预期：楼层横幅正确，不出现翻牌，楼层进度推进。

## 5. 祭坛 / 比武大会 / 守护者祭坛

1. 进入祭坛（终极或无尽），房间加载完成后检查剩余次数。预期：次数刷新正确。
2. 祭坛中团灭。预期：按祭坛失败处理，播放祭坛转场，不施加虚弱。
3. 比武大会中打完一轮。预期：首领击杀不开普通 clear，按轮次推进；团灭按淘汰处理。
4. 守护者祭坛中尝试使用复活币。预期：被拒绝。

## 6. 活动副本（入场路由与开放判定）

1. 南部溪谷：用邀请函进入，击杀首领。预期：清场奖励（封印钥匙）发放。
2. 陶之王国、封印宝藏、赫拉斯、金银角：各进入一次。预期：入场条件和收费与改动前一致。
3. 在 GM 页停用其中一个活动（例如南部溪谷）。预期：入场被拒为“不在开放时间”；重新启用后可进入。
4. 赫拉斯与金银角：入场后查看剩余次数显示，并重登检查。预期：数值正确。

## 7. 两座塔

1. 两人组队进入死亡之塔（11000）。预期：成员带塔专用快捷栏，可拾取塔内地面物品；离塔后快捷栏恢复。
2. 进入幻影塔（11001）。预期：使用普通背包，没有塔内拾取。
3. Boss 塔（领主之塔）正常进入、击杀并结算。预期：经验按领主之塔规则发放。

## 8. Boss 塔内视为在副本中（行为修正）

在 Boss 塔内依次尝试以下操作，预期都与在幻影塔或普通副本内一致：

1. 仓库整理、仓库物品移动、仓库升级与金币存取：被拒绝。改动前在 Boss 塔内会被放行。
2. 疲劳恢复道具：被拒绝。
3. 宠物改名或宠物状态通知：只有塔内队员收到，城镇中的玩家不再收到。
4. 塔内完成任务（转职或觉醒外观变化）：塔内队员看到外观更新，城镇玩家不再收到。

## 9. 婚房与情侣副本

1. 已婚角色从入口进入婚房、走动、离开。预期：正常进出，下线重登后不会停留在婚房。
2. 在婚房商店（NPC 20011）购买家具。预期：按夫妻共享资产扣款与入账。
3. 婚礼计时相关流程（如有条件）：婚房成员按原规则收到通知。
4. 已婚角色打开选图界面。预期：情侣副本（3541）显示难度 2；未婚角色不显示。

## 10. 其他

1. 使用任务清除券。预期：清除任务正常，其它道具无法当作清除券使用。
2. 完成教程奖励流程（教程旗标）。预期：与改动前一致（该项由 #180/#181 修改，本 PR 未改动）。
