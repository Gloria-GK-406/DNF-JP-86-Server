# 遗忘之地到点结束调查

状态：1分钟原生自动结束已获用户实机确认；当前按用户决定设为每局20分钟，实机时长确认待反馈。
用户确认两种道具和热血状态正常；倒计时归零仍可探索。手动返回后先出现乔安“帝国军要来了”提示，再进入专用结算并自动回城。

## 缺口与运行证据

run `b6764b5f-66bc-4950-b0b7-2584f3f9bcdf`，22:02:15.408首次加载后收到NOTI025C原始600／1200参数。
归零后仍接受换房和击杀，22:13:54.691才收到GIVEUP_GAME并结束。
整段日志未发NOTI001F，未观察到普通SET_PLAY_RESULT；同号CMD001F是任务应答，不是结束通知。
[运行摘要](evidence/expiry-runtime-observation.json)保留selector。原日志含混合编码，摘要以替换模式读取，仅截取ASCII事件键和时间，不解释被替换文本。

故障版本只发送显示参数，缺少探索结束。当前run已保存首次加载建立的探索截止、结束中状态及结束通知登记，专用typed定时CMD负责到期推进；热血仍用独立时钟。
普通清图刻意排除LostLand，不能靠解除Boss判定门槛实现专用结束。

## 原生链

A21映像base00400000，SHA256 `6BD2746DA3858E6F29B3E2D386AF4938056269BAD6C9FFF9455E133E7D953507`。

- 00C4E9E6–00C4E9F5计算剩余并调00CB19C0；后者仅把正值或0写入UI+350，显示归零不在此发起结束。
- [NOTI001F](../../../protocol/game/server-to-client/NOTI-0x001F.md)的handler01149B6A–01149B71调用模式虚表+04；0319E028的该槽为00C4D670。
- 00C4D670设置本地符号lostland clear=1，00C4D874提交客户端已有物品统计，00C4D89F将专用总结状态置1。
- 00CACBF0检查总结对象+38C是否大于0；已开始时00C4D6AB跳过重复启动。服务端仍需自己的结束去重。
- 00CACC00只检查总结状态+38C是否等于8；00C4EA00–00C4EA27在此且未发送时构造空体[CMD002A](../../../protocol/game/client-to-server/0x002A.md)，并置一次标记。总结结束后自动请求退出。

补充[有界反汇编](evidence/client-expiry-paths.txt)。手动返回后的演出由用户实机确认；“到点推单字节00的NOTI001F触发同一流程”已在1分钟候选获得用户确认。
结束演出已验收，物品展示及资产交付则仍须独立对账。客户端会在掉落通知阶段累计展示项，不能称为已拾取汇总；已拾取资产不能重复发放，未领取或独立奖励是否应补发见[结果对账调查](ResultDiagnosis.md)。

## 当前实现与验收配置

1. 首次房间加载完成时建立run级探索时钟，换房不重建；入场参数同时控制NOTI025C首字段与服务端截止；当前Host时限策略覆盖为1200秒，第二字段1200保持PVF原值；第二字段用途仍未知，不作为延期上限依据。
2. typed定时CMD在原玩法执行器中，按run身份、当前截止时间和阶段事务性进入“结束中”，停止继续探索及资产推进。
3. 提交后向当前精确会话发送既有NOTI001F、body00，打开原生专用总结；正在加载、断线与重复到期须有明确处理。
4. 保留run至原生总结完成，收到CMD002A后复用现有结束／回城。手动退出与到期竞态只收尾一次，不再扣入场次数，不重新发已拾取物品。
5. 临时SQLite回归覆盖到期、首次加载起算、跨房保持、旧run、事务回滚、加载中到期与单次通知，并通过真实CMD002A及城镇投影核对最终释放。当前结果见[验证记录](Verification.md)。

加载／暂停时服务端时钟与客户端游戏时钟的同步仍需独立核对；本次未发现可靠的专用延时道具或延期触发链，不实现臆测的延期消费。

每局20分钟由Host配置`LostLand:LimitSecondsOverride=1200`明确提供，使用既有入场冻结和到期链；[日服原始公告](https://jp.nexon.com/news/131173?category=4&page=1)写明每局20分钟、昼夜每2分钟切换。当前PVF昼夜各120000毫秒，20分钟对应五轮昼夜；未据此证明独立的“第5日强制结束”判定。配置及部署证据见[验收配置](AcceptanceOverrides.md)。
