# 设置持久化实机验收

状态：服务端自动化与部署证据见verification；以下全部等待用户实测。
本期保存上传blob，不解析设置字段；窗口位置／分辨率等本地DNF.cfg内容不在本期。

每项先修改后点击应用／确定；用游戏正常退出，再重新登录。失败时记录角色、修改项、退出方式和大致时间，便于对照保存日志及回放。

| 顺序 | 操作 | 预期 |
|---|---|---|
| 1 | 1123修改声音音量及两个容易识别的游戏设置，应用，完全退出客户端再登录 | 上传过的设置恢复为修改值 |
| 2 | 修改一个常用键和一个界面快捷键，应用，完全退出再登录 | 两个键都恢复并能实际使用；不只看设置界面 |
| 3 | 两组快捷聊天分别填不同文本（含中文），应用，退出再登录 | 两组内容独立恢复，无乱码／截断；若该版本界面只暴露一组，另一组标未测 |
| 4 | 修改一个角色专属设置，重登1123，再切同账号另一个角色 | 1123恢复；另一角色自己的角色设置不被覆盖。具体字段归属以实际上传协议记录为准 |
| 5 | 普通角色A改键，返回选角并进入普通角色B，再回A | 同账号普通profile共享；没有旧默认槽表覆盖 |
| 6 | 有缔造者时，在缔造者和普通角色设置不同键位，来回切换并重登 | 两种profile独立，不相互串写 |
| 7 | 连续修改同一设置两次，正常退出重登 | 恢复最后一次有效上传值 |
| 8 | 完成前几项后重启服务，再登录 | 已提交数据仍恢复；此项需要协调服务重启 |
| 9 | 返回选角后再次打开设置并改键（若界面允许），再选角 | 当前配置类别正常保存，不因没有选角而串写 |

“已经应用但强制结束进程”的情况只保证服务器已收到并提交的上传；不保证客户端尚未发送的内容。
尚不承诺修改设置后其他玩家看到的隐藏／显示效果，该部分属于字段语义阶段。
