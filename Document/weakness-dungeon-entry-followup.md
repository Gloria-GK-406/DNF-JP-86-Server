# 虚弱入图投影修正

日期：2026-09-21

## 实机反馈

用户已通过失败退图施加、每分钟恢复 9 个百分点、离线继续恢复、客户端 crash 后施加虚弱的验收。随后报告：带虚弱进入地下城后变为满血蓝，未看到虚弱惩罚。此次为单人入图，不是加入队伍。

## 证据与修正

运行日志显示入图重新发送 USERINFO subtype 1，而既有虚弱投影仅覆盖登录、回城和自然恢复。进入地下城后恢复暂停，因此不会由下一次恢复 tick 补发 NOTI 0021。

在首次房间的首次 FINISH_LOADING 通过当前会话及 run 校验后，先发送 LoadingComplete，再发送角色保留的虚弱值。继续持有既有实例与账号锁直到投递完成。RoomVersion 非零、重复加载上报、旧连接均不触发补发，避免重复设置影响战斗血蓝。未修改 USERINFO 未闭合字段，也未在服务端重复缩放属性。

用户已实机确认：虚弱正常带入地下城；停留期间保持 10%，恢复暂停；换房间属性上限不变。自动回蓝属于正常行为，不应视为解除虚弱。带 28% 虚弱完成 Boss 后回城仍为 28%，正常通关没有重复施加失败惩罚。

## 验证

- Protocol 测试 1011 项通过，包括新增 10/28/100 值的入图投影、消息先后及重复上报保护、后续房间不重复设置。
- Host Release 构建通过，零警告、零错误。
- 测试服已启动，监听 7001、10010、10011、18080；继续使用原数据库。

## 验收结论

本轮虚弱核心流程实机验收结束。失败退出及 crash 施加、离线恢复、入图保留且暂停恢复、换房保持、成功通关不追加惩罚均由用户确认。金币恢复验收见 [计价记录](weakness-recovery-price-rule.md)。
