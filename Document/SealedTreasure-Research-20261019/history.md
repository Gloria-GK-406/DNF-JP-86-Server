# 「封印的藏宝地」历史玩法与玩家闭环调查

> 调查日期：2026-10-19
> 调查范围：旧国服公开资料、当前指定 serverPVF 静态内容，以及本项目生产源现状的对照。
> 结论用途：为 GitHub #154 的产品闭环和后续实机取证提供历史参考；本文不把旧国服网页规则直接等同于日服 Act.86 客户端行为。

## 1. 结论摘要

2014 年 4 月国服版本的玩家闭环有较强的同期资料支持：70 级角色从格兰之森山麓进入副本，入场消耗 1 个「导航人偶」，系统每天赠送 1 个，另外最多购买 2 个，因此同期攻略普遍描述为每天最多 3 次；副本不消耗疲劳。玩家在四类元素封印怪中选择并击杀一种，打开相应通路，进入中央区域取得宝箱并击杀领主完成副本。怪物和宝箱提供材料、卡片等掉落，白金宝箱是玩家追求的高价值随机奖励。

这条闭环仅能作为**旧国服历史参考**。当前指定 serverPVF 仍保留 DGN 3557、两种导航人偶、元素怪/封印石资源和白金宝箱；其中 10003235 已由 `[refill item]` 静态声明确认为补给票，目标持有量为 1，模式 0，声明有效至 2030-01-01 06:00:00。生产源把模式 0 解释为 `RefillToTarget`，并在当前选角通用补给链中把不足 1 个的持有量补到 1。以上是 `ContentStatic` 与 `CurrentImplementation` 证据，不是原版日服客户端行为已还原。两个门票的原版扣除关系和优先级、每日挑战次数、中央门判定、退出退票、断线恢复及重新挑战仍未确定。三个相关日常任务文件没有注册进任务列表，也不应据此恢复一条任务闭环。

截至本次调查，公开资料只支持“入场消耗门票”和“击杀领主结束”这两个边界。门票何时扣除、异常退出是否返还、通关后能否重试、断线重连、失败/死亡、耐久和虚弱等均为 **Unknown**，需要真实 A21 客户端与线包验证。

## 2. 证据分层

本文使用以下标签，避免把历史攻略、当前静态资源和真实客户端行为混为一谈。

| 标签 | 含义 | 能证明什么 |
|---|---|---|
| `Historical-CN` | 2014—2017 年国服官方生态中的同期攻略、玩家投稿或后续改版报道 | 当时国服玩家看到或总结的玩法；不能证明日服 A21 规则 |
| `ContentStatic` | 当前指定 serverPVF 的静态文件与项目导出 | 文件中存在的内容、字段和资源引用；不能单独证明原版客户端可达、运行时执行顺序或线协议 |
| `CurrentImplementation` | 当前仓库生产源中的解析、周期和调用链 | 证明本服务端现在会怎样解释并执行规则；不能倒推日服 A21 原版行为 |
| `Unknown` | 本轮未找到足以支撑结论的资料 | 必须保留为取证问题，不能按常识补全 |

置信度说明：`Confirmed` 表示有同期原始玩家记录或当前文件直接字段；`High` 表示多个同期来源相互吻合；`Medium` 表示转载/汇总能够旁证但来源链不完整；`Hypothesis` 仅表示待验证推断，本文不把它写成实现要求。

## 3. 旧国服玩家闭环（2014 年版本）

### 3.1 入口、等级与入场资源

| 结论 | 地区/时期 | 证据 | 置信度 |
|---|---|---|---|
| 角色达到 70 级后，可从格兰之森山麓进入「封印的藏宝地」 | 国服，2014-04 | 百度经验 2014-04-24 的实玩步骤；前瞻网 2014-05-16 汇总 | `High` |
| 每次入场消耗 1 个「导航人偶」 | 国服，2014-04 | 百度经验 2014-04-24 明确写入场需消耗一个导航人偶 | `Confirmed` |
| 每日 06:00 系统赠送 1 个导航人偶 | 国服，2014-04 | 百度经验 2014-04-24 | `Confirmed` |
| 另可在商城以 10 万金币/个购买导航人偶 | 国服，2014-04 | 百度经验 2014-04-24；前瞻网 2014-05-16 | `High` |
| 每天最多挑战 3 次：免费 1 次，另购 2 次 | 国服，2014—2015 | 前瞻网 2014-05-16 明确写最多 3 次；2015 年特玩和 17173 男气功百科继续复述同一上限 | `High` |
| 不消耗疲劳值 | 国服，2014-04/05 | 百度经验与前瞻网均有说明 | `High` |

这里的“每天 3 次”是旧国服规则的最可信重建。它来自一个“每日赠 1 + 额外购买 2”的组合，并非当前 A21/PVF 文件直接给出的值。后期回顾资料出现过“每天 5 张”说法，与 2014—2015 年同期资料冲突，本文不采用。

前瞻网还提醒：任务栏或快捷栏已满时可能收不到免费人偶。这是一条转载/汇总中的运营细节，仅作 `Medium` 旁证；它不能证明当前客户端的邮件、背包或补发行为。

### 3.2 地图、封印与中央房间

1. 玩家进入后在分支房间中寻找四类元素封印怪。
2. 17173 原作者投稿将四类怪物写为瑟冥特克、亚德炎、冰奈斯、雷沃斯。
3. 击杀其中一类封印怪会解除相应通路，使玩家能够进入中央区域。
4. 中央区域有宝箱，并出现烈焰彼诺修（俗称火女）和光之城主赛格哈特。
5. 击杀领主才结束副本；攻略明确提示可以跳过非必要怪物，直取领主以缩短通关时间。

这一结构由 2014-04-25 的原作者地图攻略和 2014-04-27 的速通投稿互相补强，整体置信度为 `High`。公开页面没有给出服务端机关状态、房间同步消息或“击杀哪一只精灵对应哪一道门”的可执行数据结构，因此这些实现细节仍需从 A21 ACT、客户端代码和实机线包中确认。

### 3.3 奖励循环

同期资料支持的玩家目标包括：

- 普通怪物掉落对应材料；
- 中央宝箱可能产生白金宝箱；
- 白金宝箱开启后随机获得白金徽章；
- 中央区域的火女、光之城主有机会掉落相应卡片；
- 攻略还提到远古材料、深渊票、矿石等，但来源多为汇总列表，具体怪物、概率和版本边界不清楚。

17173 原作者在 2014-04-25 的文章中明确把“远古粉”标成无人证实，说明当时玩家社区也没有验证这一掉落。本文将远古粉排除在可靠闭环之外。

未找到可靠资料证明存在「封印的藏宝地」专属兑换 NPC、活动货币商店或累计兑换机制。历史闭环应表述为**门票入场 → 选择元素路线 → 中央宝箱/领主 → 随机掉落**，不能补写兑换商店。

### 3.4 通关、离开和重试边界

| 问题 | 调查结果 | 状态 |
|---|---|---|
| 正常完成条件 | 同期攻略明确说击杀领主后副本结束 | `Historical-CN / High` |
| 门票在选图、加载、进入首房还是其他阶段扣除 | 未找到可靠说明 | `Unknown` |
| 主动退出是否返还门票/次数 | 未找到可靠说明 | `Unknown` |
| 死亡、失败或回城是否返还门票/次数 | 未找到可靠说明 | `Unknown` |
| 断线后是否可重连、续关或返还 | 未找到可靠说明 | `Unknown` |
| 通关后是否允许“再来一次”，以及是否重新扣票 | 未找到可靠说明 | `Unknown` |
| 组队、队长票或队员分别扣票 | 公开资料把副本描述为单人活动，未找到可依赖的组队规则 | `Unknown` |

这些缺口直接影响玩家可恢复性和资源一致性。服务端实现前应优先用真实客户端观察正常通关、菜单退出、死亡回城和断线四条路径，并逐条记录票数、剩余次数、角色位置和客户端提示。

## 6. 给 #154 的可执行取证清单

以下不是历史结论，而是把 `Unknown` 收敛为 `ClientVerified/WireCaptured` 所需的最小实验集。

1. **入口可达性**：分别测试无票、仅持有 10003196、仅持有 10003235、两票同时持有；记录 UI 文案、入场按钮状态和实际扣除。
2. **次数边界**：同一角色连续进入至少四次，并跨原版客户端声称的重置点复测；区分“持票补给”与“服务器每日挑战次数”。当前实现的通用补给以北京时间零点换日，不应当成原版 06:00 行为的验证替代品。
3. **四元素机关**：每次只击杀一种封印怪，记录房门/传送点变化、全房间状态和相关收发帧；验证是否必须四选一。
4. **宝箱与领主**：分别测试先开宝箱再杀领主、忽略宝箱直杀领主、先杀非必要怪，记录结算、掉落归属和宝箱物品 ID。
5. **离开矩阵**：在首房、机关后、中央房分别执行菜单退出、死亡回城、进程断开和网络断开；每次记录票、次数、位置、疲劳、耐久与重连提示。
6. **日常任务可达性**：只观察任务 UI/NPC 是否真正提供 20747—20749；在没有客户端证据前不注册、不补奖励。
