# 疲劳药首版

用户授权（2026-09-29）：药品不共享次数，先完成一个版本。

## 行为

- 每个角色、每个物品ID独立计次，从PVF读取恢复量、每日使用上限、冷却、等级及期限。
- 未声明每日次数（-1）的药品不凭空加每日上限；24小时冷却仍按完整间隔执行。
- 仅城镇使用；恢复空间不足拒绝，不浪费药品。每日次数以公共业务日规则计算，当前默认06:00。
- `FatiguePotionDomainService` 校验和编排；复用 OpeningInventoryDomainService 扣药/背包回执，复用 CharacterFatigueDomainService.RefundAsync 恢复。恢复不改变今日累计消耗。
- `IConsumableUsageTable` 是独立道具计次持久化接口，使用既有 character_daily_counters 表，key=`consumable_used_{itemId}`，value=本周期次数，last_consumed_at=完整Unix毫秒时间戳。无需迁移、新表、逐角色timer或每日批量清表。
- 扣药、恢复、计次通过同一个 DomainTransaction 提交；失败统一回滚。
