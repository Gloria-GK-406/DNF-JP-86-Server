|---|---|---|---|
|0087C490|保管箱内部拖动|1/源slot/源模板|1/目标slot/现有模板或0|

`008824D1..00882504`：op1/2仅消费A且要求A.kind1，写保管箱绝对值；B忽略。`00882509`起op0处理双端点；双保管箱端点走本地交换，其他方向分别更新房间与保管箱。
