## 1. dstr.dat 格式（Confirmed，客户端静态）

客户端目录下的 `dstr.dat`（3,173,376 字节）是**字符串表**，不是普通数据文件：

1. 它是 MZ/PE 镜像（资源 DLL），仅两个节：`.rdata`(95B) + `.rsrc`(3,171,920B)。
2. 初始化代码 `0x028C1320`（源归属 DNFShared\GameScript\RDARScriptAnimation.cpp，归属为邻近推断）：
   - 用 exe 同目录拼出 `dstr.dat`（加密字面量 VA `0x3620D34`，解出 `dstr.dat`；打开失败则弹
     `dstr.dat is not exist. error code=%u`（`0x3620CE0`）+ `Fatal Error`（`0x32D7CDC`））。
   - 按全局 `[0x4E0EA1C]` 选择资源 ID **0x66 或 0x6A**（语言二选一）。
   - FindResourceW/LoadResource/LockResource 舞步在 `0x2CA8D00`（资源类型为宽字符串 `"FILE"`，
     字面量 `0x36DC728`）。
3. 资源解码 `0x2CA8A00(this, resPtr, size, out)`：
   - 校验魔数 `SC01`（逐字节 cmp 'S','C','0','1'，`0x2CA8A49-0x2CA8A6A`）；
   - 读 `u32`（偏移 4，正文原始长度）；
   - 正文（偏移 8 起）做**差分链 XOR**（`0x2CA8AB0` 循环）：
     `plain[0] = cipher[0] ^ 0x5819AF17`；`plain[i] = cipher[i] ^ cipher[i-1]`（4 字节粒度）；
   - 结果交给 `0x27BB120(buf, rawSize, &out)`。实测解码后直接是明文
     （`//====...` + `//*** [D:\Projects\Client\First\conv\RDAR\...]` 头），本资源未再压缩。
4. 查询入口 `0x28C14C0(id, ...)`：惰性初始化（`[0x4E0EA1E]` once 标志）后按 id 查表，
   返回 UTF-8 文本。资源 0x66 = 中文表，0x68 = 日文表（内容与 0x66 同 ID 体系），0x6A = 另一语言表。
5. 行格式：`<十进制ID>><UTF-8 文本>`，`\n` 为字面转义。

> 实现脚本：`pvf_extract.py`（PVF）/ 本目录 `dstr_res_*_plain.bin`（解码后的资源明文）。
> 曾走过的死胡同：先按 8 字节循环 XOR 解得到"表面明文"（零头 + 伪重复模式），该方向错误；
> 正确算法以 `0x2CA8A00` 指令为准。
