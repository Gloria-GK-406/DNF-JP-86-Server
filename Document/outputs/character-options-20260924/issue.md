# 角色设置 blob 逐字段语义解析

当前 CMD 0x01C0 SAVE_CHARACTER_OPTION 上传 u32(512)+512B，NOTI 0x0187 负责登录回放。1123 的设置未持久化，技能帮助每次登录首次开技能栏都会弹出。

本次先补原样保存及回放，属于过渡态，不代表设置系统语义建模完成，也不据此证明技能帮助对应的具体字段。

## 后续调查与验收

- 对 512 字节 payload 的每个字段建立偏移、宽度、类型、含义、默认值、读写入口、作用域及证据等级；包括位字段逐位含义。
- 用客户端静态调用链与单项 UI 差分交叉验证，重点定位技能帮助首次展示标志；未知、保留及未使用区域必须明确标注，不能凭样本强行命名。
- 核对换角色、重登、设置重置、客户端版本差异，以及 0x01C0 / 0x0187 的往返格式。
- 形成版本化协议字段表及可重复样本，明确仍未闭合的区域；每一字段/字节都必须有解析状态。
- 在证据充分后评估类型化模型迁移，保留未知字节兼容与旧 blob 迁移策略；不能用字段默认值覆盖用户现有设置。

暂时方案：按角色隔离、严格长度校验、原样保存完整 516B（含长度前缀）、登录按现有 0x0187 下发。不新增猜测性的业务含义。原样存取验收不能作为关闭本调查 issue 的依据。
