### 技能帮助：第一组 noticeId=8（ClientStatic + 上报实帧）

- `0x013D8140` 起线性解码到 `0x013D8936`：调用 `0x013AB2E0(8)` 查询第一组编号集合。已存在时走帮助控件状态设置；未存在时重置窗口内字段。

- 本次日志出现 `CMD 01DE body(4B)=08000000`，但服务端 Unhandled。

### 两组提示状态的协议

| 组 | C2S 上报 | S2C 全量回放 | 客户端集合 |
|---|---|---|---|
| 第一组 | CMD 01DE，u32 noticeId | NOTI 01A1，u8 count + count×u8 id | notice manager 起始集合 |
| 第二组 | CMD 01F8，u32 noticeId | NOTI 01B9，u8 count + count×u8 id | 同 manager +0x14 集合 |

两组 ID 是独立命名空间，客户端接受 0..127。不要将两组相同数字合并。

- NOTI 01A1 handler `0x0118B100`：先 `0x013AB2C0` 清第一集合，再逐项调用 `0x013AB3C0(id,false)`。
- NOTI 01B9 handler `0x0118B160`：先 `0x013AB2D0` 清第二集合，再逐项调用 `0x013AB4F0(id,false)`。
- 注册点 `0x0119AEE4..0x0119AF03` 将两 handler 分别绑定 01A1、01B9。
- `0x013AB2E0` / `0x013AB350` 查询两集合；`0x013AB430` / `0x013AB560` 插入并上报。
- 非回报插入用于接收全量快照，避免回放触发上行循环。
