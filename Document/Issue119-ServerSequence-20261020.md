## 行为

普通 EPLP 将退出选项与后续确认分开：state 1 的 option 0/1/2 结束精确旧 run，先 ACK 后投影一次城镇；option 3 不再执行普通退出，旧 run 消失后的 `(1,3)` 静默。无 run 的 option 2 保留明确回城兼容，但有新选图意图或身份已变化时不覆盖新状态。特殊塔与祭坛分流保留。

退出通过 `LeaveDungeonCommand` 调用既有领域服务。退出租约覆盖清理、ACK 与城镇投递；普通 000F 选图和 0010 事务建局参加同一选中会话边界。组租约在调用者上下文同步安装借用帧，再按账号排序逐个获取锁，避免异步帮助器丢失 AsyncLocal 所有权，导致命令管线等待自己的锁。

选图目标仍由原有 entry intent 持有；迷宫仍按当前任务事实选择。没有客户端/PVF 补丁、任务代提交、强制开图、额外延迟或新 pending 字典。
