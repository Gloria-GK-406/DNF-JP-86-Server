# 装备品级与调级箱

2026-10-09，基准 e3378e2d。装备保存客户端属性种子，客户端负责计算品级与属性；已有装备不会重新随机。普通创建统一使用正31位随机种子，排除客户端五个固定属性种子。

调级箱由独立领域服务处理，只允许角色当前背包中的真实装备和有效携带材料。PVF确定箱子类型及可作用部位；每次扣一个箱子，与只更新装备种子处于同一事务。身份、强化、附魔、增幅、锻造和其他状态保持原值。普通箱可能升档、降档或保持同档，不保证每次显示变化。魔法封印选项不在此次重抽范围。

协议与取证以 [CMD0051](../protocol/game/server-to-client/CMD-0x0051.md) 和 [请求记录](../protocol/game/client-to-server/0x0051.md) 为准。封蜡流程尚未实现。

实机验收：将目标装备放入背包，用普通品级调级箱连续调整；检查装备属性/品级刷新、每次扣一个箱子、耗尽后箱子消失。再重新登录确认结果保存，并检查强化、附魔等原值未变。请求字段及错误文案尚需当前 A21 实帧验收；此次不修改客户端或 PVF。
