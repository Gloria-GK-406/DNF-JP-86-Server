# 装备品级与调级箱

2026-10-09，基准 e3378e2d。装备保存客户端属性种子，客户端负责计算品级与属性；已有装备不会重新随机。普通创建统一使用正31位随机种子，排除客户端五个固定属性种子。

调级箱由独立领域服务处理，只允许角色当前背包中的真实装备和有效携带材料。PVF确定箱子类型及可作用部位；每次扣一个箱子，与只更新装备种子处于同一事务。身份、强化、附魔、增幅、锻造和其他状态保持原值。普通箱可能升档、降档或保持同档，不保证每次显示变化。魔法封印选项不在此次重抽范围。

协议与取证以 [CMD0051](../protocol/game/server-to-client/CMD-0x0051.md) 和 [请求记录](../protocol/game/client-to-server/0x0051.md) 为准。封蜡流程尚未实现。

基础品级0051尚未单独补录明确实机接受反馈；不能将01C8词条调级验收直接迁移至0051，也没有新增归档实帧。剩余专项验收：将目标装备放入背包，用普通品级调级箱连续调整；检查装备属性/品级刷新、每次扣一个箱子、耗尽后箱子消失。再重新登录确认结果保存，并检查强化、附魔等原值未变。请求字段及错误文案尚需当前 A21 实帧验收；此次不修改客户端或 PVF。

## 魔法封印指定词条品级

用户于2026-10-09授权“直接搜索相关info然后实现部署吧”。`01C8` 接入独立协议切片，调用装备品级领域服务的 `RerollMagicSealGradeAsync`；共享身份/容器/锁/材料/事务校验，规则通过独立内容源读取真实PVF概率和不可调整词条。基础品级 `0051` 行为保持不变。

只重抽序号0/1/2中所选的一条，两品质字节写相同百分比，类型、其余词条、UID、基础属性种子、强化附魔增幅锻造等不变。不是转换词条类型的01B6，也不是装备合成的0197。每次耗一个普通箱（15/897由实际PVF确认）；最高箱的封印特殊规则暂不接入。扣箱及更新装备同事务；重放防重复结算。后提交经EventService先刷新装备和材料，最后回单字节ACK，失败回00+原因。

取证、字段与回包见 [请求](../protocol/game/client-to-server/0x01C8.md) 和 [响应](../protocol/game/server-to-client/CMD-0x01C8.md)。70两个字段的品级编码与上游的“属性数值+百分比”编码存在差异；选用70，用户已确认所测试指定词条品级调整正常路径可用，记有限范围ClientVerified，不沿用上游忽略词条序号并连带调整基础品级的逻辑。

自动检查覆盖指定三条、属性/身份/持久化不变、PVF四档及禁用名单、异常回滚、并发扣箱、重复seq、拒绝信封、材料耗尽清槽、A21请求宽度和真实TCP入口。协议全量曾出现一次服务图解析失败，隔离复跑与全量复跑均通过；未作生产代码修补，不据此声称消除了测试环境偶发性。

剩余专项验收：在魔法封印装备上切到词条品级调整，分别选第一/第二/第三条多次操作，检查仅所选条的C/B/A/S及对应数值变化，箱子每次减一；允许同档和下降。耗尽后应有拒绝且能继续操作。重登后结果、装备基础品级和其他属性应保持。此次只部署服务端，不改客户端/PVF。
