# 幸运星与武器租赁

2026-10-20；本轮基线`90c5678b`。本页描述CurrentImplementation及自动回归目标，实际客户端操作尚待用户验收；静态读取结论见[协议证据](../protocol/patterns/data/probes/lucky-star-rental-20261020.md)。

## 归属和依赖

`IAccountLuckyStarDomainService`管理账号余额、角色金币购星、幸运星道具入账及整次地下城通关奖励。`IEquipmentRentalDomainService`管理角色租赁、续租和当前面板，单向调用幸运星服务消费。两个规则服务分别读取共享PVF内容源；规则服务接收当前角色事实，内容源不参与资产写入。

余额仍保存于`accounts.lucky_star`。租赁装备通过既有物品投递和容器路径创建真实UID，`equipment_rental_instances`保存角色、UID和模板关系，期限取自物品`ExpireTime`；不维护第二套库存或独立期限。原`character_rentals`历史表保留，登录投影继续读取；本轮操作面板以真实UID关系为准。部署前核实测试库旧表为空，无既有租赁迁移。`lucky_star_clear_rewards`记录run+角色的通关处理，即使达到上限没有增加星币，也不因后来消费而重新补领。

金币、星币、物品与租赁关系加入同一`DomainTransaction`。拒绝、满包或写入失败不允许出现部分扣费。已穿戴装备相关状态推送继续复用完整角色状态投影。

## 当前规则

- 核心PVF：`etc/chnrentsystem/rentsysteminfo.etc`，14个具体职业、8个档位；目录各档基础价为3/5/10/15/20/25/30/40星。目录档位用于商品及价格配置，职业按精确职业和装备声明交叉验证。服务端租赁/续租不按角色等级拦截；穿戴时继续按装备最低等级及有效霸王契约检查。
- 幸运星新增上限400，金币购星100000/星，适正地下城按PVF配置奖励1星并遵守排除名单。适正资格采用既有推荐等级上下界判断口径，在通关经验升级之前判断。
- 原有超额余额不截断，可正常消费；购星和道具兑换不能完整入账时整单拒绝。通关奖励可封顶为0并记录本次已处理。
- 租赁期24小时，生成时捕获操作时钟并写入绝对到期秒。有效租赁最多10件；同角色同模板已有有效实例时按当前报价续租原UID，期限重设为now+24h，不累计剩余时间。不同模板可并存。
- 新租使用InventoryOnly；满包拒绝并回滚，不转邮件。物品品质和强化/交易/分解/仓库等限制沿PVF及现有物品规则执行。
- 到期按当前装备说明在切频道或重登时回收，复用通用过期物品清理；查询不显示过期/丢失实例，不根据租赁关系重新生成装备。本轮不把租期绑定06:00，也不新增在线即时扫描任务。
- PVF折扣值及活动开关存在，但当前活动开启与装载映射未闭合；初版使用目录基础价，不自动启用历史折扣。续租原UID属于本轮明确的产品规则，仍需用户实机核对。

当前PVF部分守护者商品与装备自身可用职业声明不一致（例如401020032）。本轮遵守装备自身限制拒绝这些商品，没有擅自改写PVF。

## 协议与同步

A21使用CMD03CF租赁、CMD03D0购星，二者body均22B（外层帧头另14B），忽略正文前14B冗余。03CF后两个u32分别为模板和界面上下文；03D0为购买模式1和数量。界面上下文不作为价格或权限依据。

03CF成功正文为`01 + u32 result`，0成功、1同时租赁超过10件、2物品栏满。03D0为`01 + u32 mode + u32 resultOrQuantity + u32 total`，公共失败至少`00 + reason`。普通获得通知使用mode2/second0；second1会触发历史999上限提示，不能误用作获得一星。

登录、操作及重复请求状态恢复共用完整NOTI03C1编码：余额、条数及模板ID/绝对到期秒列表。购星ACK先于03C1，避免客户端用已经更新的余额错误计算本次增量。购星/租赁接入既有请求执行去重；重放读取当前物品和租赁状态，不重放扣费或奖励。幸运星道具沿既有UsePlan校验后入账、消费，并记录相应当前状态恢复需求。

## 用户实机验收

1. 打开物品租赁界面，购买1星及多星，核对金币扣除和账号余额；不足金币、达到上限时不扣资产。
2. 租本职业的武器，核对基础价、真实背包物品、最高级品质和约24小时期限；正常穿戴使用。
3. 重租同模板，核对仅保留一份装备、重新计算24小时且正常扣费；不同模板按上限10件处理。
4. 切换角色确认账号余额共享，重登确认装备和期限保留；通过正常游戏日时间验证到期重登/换频道回收。
5. 合格地下城通关增加1星；重复结算、排除地图、非适正不重复或错误发放。使用幸运星消耗品核对数量与余额。
6. 背包满时尝试新租，核对没有扣星、没有邮件补发；无效选择或客户端重发不产生额外装备。

2026-10-20实测后调整：客户端在霸王契约有效时已展示更高等级租赁档位。按用户选择移除租赁及续租等级校验，允许先租后用；没有契约且等级不足时仍无法穿戴，租期照常计时，未新增退租退款。回归覆盖70级租80级天霜寒气、原UID续租，以及无契约/契约有效/契约过期的穿戴判定。此调整替代初版Spec中的租赁等级限制，原任务封存记录保留为历史证据。
