# 复活币实现与实测

实现：请求者付款，指定同实例死亡角色复活。持久化扣币与运行时存活状态使用同一事务；提交后立即清除全灭截止时间。NOTI 0020 广播，ACK 0029 仅付款人，随后同步付款人币计数。复活后再次全灭重新计时。

自动验证：Application 1532 通过、117 跳过；Protocol 配置 PVF_ARCHIVE_PATH 后 1002 通过。覆盖扣到零、重复请求、无币、非法目标、数据库失败回滚、队友扣付款人、第二次全灭新计时，以及 ACK 字节和请求长度。

实机待测：
1. 单人死亡后倒计时内按 X 一次：满血蓝、扣一枚、计时消失，继续活动超过 15 秒不回城。再死再救验证本地待办队列。
2. 双人一人死亡，另一人使用复活币：目标复活，两端状态一致，仅付款人扣一枚。
3. 双人全灭后倒计时内救起一人，超过原截止时间不强制回城。

候选配置 Dungeon:RevivalAckFlag=1（可切 0 对照）。失败 ACK 错误码 0 的客户端提示未确认。尚不宣称实机验收通过。P2P 不由服务端构造。

虚弱机制与疲劳不在本次实现中。
