# 黑钻默认权益

2026-09-28，基线 `ae8379dd`。

`Premium:BlackDiamondEnabled` 默认 `true`。配置由现有配置服务在启动时读取，修改后需重启服务并重新登录。关闭时不提供黑钻，即使数据库存在历史 type 56 记录；历史记录保留但不参与黑钻判定。

`PremiumServiceDomainService.For(account).ReadAsync` 在查询结果中合成唯一的 type 56 记录，不写 `account_premiums`，账号下各角色共享此资格。`IsActiveAsync(BlackDiamond)` 直接返回配置；购买续期入口拒绝黑钻，其余契约保持原有规则。

显示期限采用每次查询时的 UTC 当前时间加 365 天，登录沿用 i64 剩余秒数（通常 31536000 秒），重新登录后自动顺延，不落库续期。服务端资格仅由开关决定，客户端在线倒计时不影响服务端资格。定期同步比较黑钻是否存在，不比较其滚动到期时间，避免每分钟重复发送魔王契约快照。

商城 CMD0041 仍以原有失败信封结束网页票据请求，再用 NOTI01F7 提示“黑钻权益由服务器统一设置，无需购买。”；没有支付、续期或网页跳转。黑钻不加入魔王契约的八槽快照。
