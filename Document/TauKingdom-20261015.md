# 牛头怪乐园一期（2026-10-15）

## 结构与职责

旧入口使用通用地下城服务；每天补票依赖零点登录批次，兵书的 etc 路径只消费物品，未应用经验。

新入口由 `ITauKingdomDomainService` 管理资格、活动和冻结入场等级，委托公共 Admission 完成凭证/消费/失败回滚、普通地下城完成房间实体与通关。PVF 内容源经规则服务向业务提供事实。没有复制掉落、疲劳和结算实现。

`ITauKingdomRuleService` 支持 DGN3700，活动 2215 默认全天开放；GM 显式禁用优先。NOTI006C 使用 `taukingdom/0/0`（两个整数只为满足原生解析结构），不发送另一个 TauLevel 玩法的 NOTI0482。

## 本期规则

- 单人、27 级以上、普通难度；拒绝练习、循环、镜像/深渊入口。每次消费 1 张 690001556，不耗疲劳；失败或事务回滚不扣票。
- PVF 原路线 MAP26000 → 26001 → 26009：50 个士兵、50 个士兵、Boss。所有战斗怪物等级在入场时取角色等级；后续升级不会改变本局等级。保留 DGN 经验权重 7，不额外乘第二次。
- 62040 Boss 的既有独立掉落表负责 3 本特级兵书 690001555，角色等级资格 1..85；86 级不掉。不重复发奖、不编造衣角/近卫概率。
- 牛头票游戏日 06:00 新增 1 张；登录、在线回调及发布补检共用持久领取记录。离线不补多日，满包转邮件。其他每日补给仍是零点首次入场批次。
- 四种兵书 690001552..555：固定 1000/10000/100000 或当前升级所需经验的 1% 向下取整，使用等级 20..84。扣书、经验和技能点变更同事务；到期、非法声明、等级不符与异常不扣书。重复 effect 请求不重复给经验。
- 新兵书生成到期时间为下一个游戏日 06:00，复用现有登录及在线清理；门票自身不设置每日过期。

## 部署后的验收顺序

1. 使用你准备的 27..84 级角色，登录检查每天 1 张票；重登不重复发。打开牛头怪乐园，确认普通单人可入，无票时拒绝。
2. 入场门票少 1，疲劳不变。依次打完 50 + 50 + Boss 三房间，怪物等级与入场角色等级一致；确认普通回城/再次挑战可用。
3. 拾取 Boss 的 3 本特级兵书；用一本，数量减 1、经验正确增加，必要时升级/技能点刷新。
4. 正常退出并重登，核对票、经验和物品持久化。兵书显示到下一个 06:00 的期限。
5. 有条件时保持在线跨 06:00：门票仅新增 1、旧兵书清理；离线跨日后登录只补当前周期，不补历史天数。
6. 86 级角色仅用于观察不掉书/不可用书的边界，不能代替升级角色的兵书效果验收。

部署遵守用户条件：检测到游戏客户端仍在运行时不停止旧服务、不替换运行文件，只准备产物并报告待部署。
