# A21 永久装扮期限修正

用户实机反馈永久装扮显示四千多天。原实现将永久到期时间保存为int.MaxValue（2038年），下发时减去当前Unix时间，得到四千多天；它并不是客户端的永久标记。

## 客户端证据

固定A21镜像身份同 [商城取证](../protocol/patterns/data/traces/a21-cera-feedback-20260909.md)，以下为RVA。客户端资源dstr.dat SHA-256为 `60E9857773831B341BAE0D490FCAEAF0AF184B9776717E2FCF293E1BC7F92F10`，FILE/102资源以SC01链式XOR解密后：1059为“剩余时间 : 无期限”，3030为“使用期限已到， 下次登录时将会消失”。

- `0126E840..0126E850` 读取物品+FD0后执行test eax,eax / sete al，只有零返回true；tooltip `020232F9..02023307` 据此选择资源1059。
- `0126E860..0126E870` 对同一值执行test / sets al，负数返回true；tooltip `0202332F..0202333D` 据此选择资源3030。
- 因而线上剩余时间为：0永久、正数剩余秒数、负数已到期（本实现发送-1）。置信度Confirmed（读取与显示指令），本轮修复后的实机显示仍待用户复测。

## 实现与兼容

新永久装扮的到期事实保存0（SQL NULL仍表示没有装扮事实）；商城、赠送与拾取的创建路径保持一致。所有背包快照/增量及穿戴信息通过同一转换：永久下发0，有限期限下发剩余秒数，到期下发-1。否则将到期钳制为0会误显示永久。

兼容历史int.MaxValue占位：编码时也按永久下发0。无需重购，不直接修改玩家数据库，不会将7天/30天等正常期限改成永久。到期清理/删除物品不是本次修复范围。

回归覆盖0、历史-1存储值、int.MaxValue、已过期、刚好到期、剩余1秒与1天，并对背包、支援角色、角色穿戴的实际帧验证字段。商城三种期限、拾取和赠送持久化测试同步改为永久0。原始结果位于 [Verification/Avatar-Permanent-20260909](Verification/Avatar-Permanent-20260909)。
