# 技能材料消费分流

operation=1保留丢弃，operation=2独立为技能材料消费。Handler识别业务原因再定位存储，不再以“是否账号无色”判断业务。

- `DiscardItemCommand` / `DiscardAccountMaterialCommand`：主动丢弃，领域仅接受原因1。
- `ConsumeSkillMaterialsCommand`：调用独立技能材料领域服务，以材料列表进行完整校验与原子扣除；不依赖丢弃服务。普通携带材料必须为未锁定堆叠物，装备不作为技能材料接受。
- 事务后Event核对当前收件会话，发送成功ACK及最终绝对数量；不用将减量再次当增量发给客户端。
- 保持单条19B网络边界，多条解码和ACK扩展另行验证；批量领域行为已有失败不部分扣账的测试。

## 验证

Application相关测试51项，Protocol删除消息测试11项，全部通过、无跳过。包含普通丢弃回归、操作原因分流、账号与携带材料消费、最后一个晶体、余额不足、未知操作、无效报文、禁止消费装备、旧会话、重复地址和混合材料事务回滚。Release发布成功。
