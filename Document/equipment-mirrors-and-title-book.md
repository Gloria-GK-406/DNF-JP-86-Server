# 通用镜像装备与称号簿

2026-10-08；分支 `task/abyss-research`。证据等级：CurrentImplementation / AutomatedValidated；本次原生客户端验收待用户测试。

## 职责变化

原实现将称号簿中的物品实例搬到装备栏；换装和卸下沿用真实装备规则，导致旧称号进入背包。现在称号簿保留原实例，装备时复制一个可删除的镜像。镜像卸下或被替换时删除，称号簿原实例不受影响。真实装备仍沿用正常移动规则。

`ItemSnapshot.IsMirror` 是通用物品实例属性，`MirrorSourceUid` 可记录原实例身份，用于区分相同模板 ID 的不同称号。SQLite `items` 增加 `is_mirror`（默认 0）和 `mirror_source_uid`；旧数据不会按物品 ID 推断成镜像。82B item core 和客户端协议布局不变。

领域层 `IItemMirrorDomainService.RemoveAsync` 负责显式取出并删除镜像；物品移动服务与称号簿服务调用它。原始 store/container 的 `TakeAsync` 仍只分离实例，不能暗中删除。持久化和运行态存储均拒绝将镜像放到角色装备栏以外的位置，也拒绝更新实例时改变镜像身份。

## 行为

| 操作 | 结果 |
|---|---|
| 从称号簿装备 | 保留书中原实例，生成新 UID 的装备镜像；保留解封状态和物品属性 |
| 镜像换镜像 | 删除旧镜像，创建新镜像；无需背包空位 |
| 真实称号换成书中称号 | 真实称号放入背包空位；背包满则拒绝，原状态不变 |
| 真实装备替换镜像 | 删除镜像，真实装备正常装备；原背包格清空 |
| 镜像卸下到有效背包格 | 只删除镜像；即使目标格已占用，也不交换、不改变目标物品 |
| 无效目标 / 同槽操作 | 拒绝或无变化，不删除镜像 |
| 镜像存入称号簿 | 删除镜像，保留书中原实例 |
| 按原有规则显式取出真实称号到背包 | 搬出书中原实例，同时删除指向它的已装备镜像 |
| 重新登录 | 已装备镜像保留；已删除镜像不会重新生成 |

## 通知与协议

镜像删除产生 `ItemMirrorRemoved`，称号操作产生 `TitleStored` / `TitleWithdrawn`。事件服务投递给协议订阅者，由其生成通知；领域服务不直接调用通知总线。

`CMD 0x0013 / 0x019C / 0x019D` 保持现有响应布局。每角色投影门保证操作回包先完成，然后用 `NOTI 0x000E` 校正发生变化的称号簿分类槽位，并发送 `NOTI 0x000D` 装备与背包快照，以及 `NOTI 0x0002` 当前外观。仅删除装备镜像不刷新称号簿。`NOTI 0x0166` 整类列表保留用于登录和只读查看，避免在操作后清掉已打开窗口的条目引用。镜像变化不会被转换成称号解锁公告。
