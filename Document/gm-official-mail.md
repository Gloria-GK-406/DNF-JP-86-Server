# GM 官方邮件

在 [GM 后台](gm-web-admin.md) 的“官方邮件”页面操作；管理员需要独立 SendMail 权限，可以没有 QueryPlayers/ViewAudit。页面只查询必要收件角色身份，不提供账号资产。操作记录总页面仍需 ViewAudit；个人邮件发送历史在邮件页查看。

先填标题、正文、每人金币和物品 ID/数量，再查找并明确选择角色。跨页保留选择，按 ID 计次，同账号两个角色也会各收到一封。单批最多 100 个角色；预览显示真正发送的文本、收件人、每人及全批数量，确认后整批提交。预览之后返回编辑会取消该确认，必须重新预览。

草稿每管理员一份，保存后可刷新/重新登录恢复；“重新加载草稿”显式覆盖当前编辑。个人模板最多 20 份，保存内容与附件，不带收件人；加载模板保留当前选择。保存/覆盖/删除带版本检查，遇到冲突应重新加载，再确认内容，不自动覆盖。

支持永久普通装备、永久堆叠物和金币。每人最多 10 个展开物品附件及一份金币：装备每件占一个附件、各有不同 UID，堆叠物一行按数量领取；0 金币不生成附件。时装、宠物、宠物装备/消耗品、期限道具、复活币/虚拟资源、权益服务和未知/不支持实例声明会被拒绝。账号共享材料通过原邮箱领取进入账号材料袋。后台不能输入强化、红字、附魔或现有玩家 UID。

实际展示为正文，或“标题 + 换行 + 正文”，最多 511 个 UTF-8 字节。中文通常占 3 字节；以预览为准，超限拒绝，不截断。系统官方来源、提交起 30 天有效，玩家在原邮箱领取；满背包或金币上限导致领取失败时附件仍保留，腾出空间/金币容量后再领。

一次确认产生一个 UUID，随完整内容提交。相同管理员用同编号/内容重试返回原邮件编号，不重复发放；改内容复用编号返回冲突。结果暂未确认时，页面保存冻结请求，刷新仍可查询原编号或按原内容安全重试，禁止新建编号再发；“记录未找到”并不证明先前请求已回滚。持久化结果列出每位收件角色、邮件 ID、装备 UID 及实际期限。在线提醒未确认不改变已发送状态，不代表客户端已读或已领取。

## 待真实客户端验收

后台 HTTP/SQLite/页面判据与客户端表现分别验收；以下客户端项目在用户执行前不标 ClientVerified。测试环境及测试玩家资产需要显式操作授权后才可准备，不使用现服做自动化验证。

| 项目 | 操作 | 预期 |
|---|---|---|
| MAIL-01 | 保存草稿，刷新/退出再登录，加载内容模板 | 草稿及明确角色可恢复；模板只替换内容，保留当前收件人 |
| MAIL-02 | 给一个离线角色发送纯文字官方邮件，登录打开邮箱 | 系统官方来源；中文标题/正文与预览一致，30 天期限 |
| MAIL-03 | 给两个明确角色批量发送材料、金币 | 各一封，各有相同附件数量；其它角色不收到 |
| MAIL-04 | 给一个角色发 2 件普通装备并领取，重新登录 | 两个不同 UID；初始耐久/封装正常，领取及重新登录后仍存在 |
| MAIL-05 | 发账号共享材料并领取 | 进入既有账号材料袋，数量正确，不额外进入普通物品栏 |
| MAIL-06 | 背包满/金币到上限时尝试领取，腾出容量后再领 | 初次失败不消失，后续仅领取一次 |
| MAIL-07 | 给在线角色发送，再用原编号重试 | 邮件仅一份；在线提醒正常或明确未确认，重新打开邮箱可看到持久化邮件 |
| MAIL-08 | 预览超长中文、期限/时装/宠物附件及无效目标 | 明确拒绝，全批无部分邮件 |
| MAIL-09 | 后台记录查看、刷新及网络失败恢复 | 结果/邮件 ID 可追溯；未确认请求只查原编号或原内容重试 |

## 隔离页面夹具

自动化使用 `GmMailBrowserFixtureTests.ExplicitMailBrowserFixture`。显式设置 `DNF_GM_MAIL_BROWSER_FIXTURE=1`，并把 `DNF_GM_MAIL_BROWSER_FIXTURE_DIRECTORY` 指向任务工作区 `artifacts/gm-mail-browser/spec004/` 内新的子目录；已有 test.db 会拒绝启动，不会清库。仅监听 127.0.0.1:18083，游戏/登录器网络关闭，创建隔离 operator 与 45 个合成账号，角色 1/2/3 可接收邮件。预置“测试补偿”模板但不发邮件；物品示例 27312（普通装备）、3（堆叠物）、3037（账号材料）来自当前只读 PVF。

设置 `DNF_GM_MAIL_BROWSER_FIXTURE_VERIFY_ONLY=1` 可做启动/预览/模板和页面自检后正常停止；常驻模式在夹具目录创建 stop.txt 停止，最长 15 分钟。不能与共享输出的 .NET build/test 同时运行。页面始终测试隔离资产，不把合成生命周期当作真实游戏客户端收件证据。
