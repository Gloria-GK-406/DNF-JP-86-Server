## 5. HTTP及非Game入口

| 入口 | 设计场景 | 基线来源 |
|---|---|---|
| Launcher bootstrap/login/register | ENV、AUTH、ROLE | 正式启动器/HTTP接口采样；运行期票据重新签发，不重放旧密钥 |
| GM初始化/登录/退出/权限/玩家查询 | GM-001、GM-002 | 正式HTTP调用；不要求伪装为A21游戏包 |
| 官方邮件、三币及操作收据/审计 | GM-003—GM-008 | HTTP操作和玩家客户端收取/领取两端证据 |
| 活动、补给与马战设置 | GM-009、对应活动域 | 正式HTTP配置+游戏通知+持久化事实 |
| 物品目录/图标/提示及服务器身份 | GM-010、ENV | HTTP请求及配置/PVF身份；浏览器渲染不纳入无客户端自动判据 |
| 定时任务、到期与离线恢复 | DAILY、活动域、RECOVER | 正式真实时间与正式Host重启；不注入替代调度器 |
| UDP发现及客户端辅助网络 | ENV、AUTH、PARTY | 用正式启用配置采集实际行为；如首期未实现相应客户端驱动，显式标缺项，不宣称全入口已自动覆盖 |

## 6. 更新规则

新增/删除注册或新玩法时同步主表编号和此映射；新增目录必须明确归入功能域或列为“当前无业务/待调查”。当前180键与115目录映射无漏项，仅证明此提交的设计清单完整。某功能尚无可批准的实机流程时保留阻塞，不造预期，也不自动降为通过。未来host提交改变后应重新生成清单差异并审核受影响场景。
