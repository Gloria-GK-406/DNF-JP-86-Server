# Spec Result: Integrated Select Character Lifecycle

G7 is complete and independently approved. Select Character now owns one explicit,
generation-safe application lifecycle from read-only preflight through exact registration,
entry preparation, typed delivery, publication, post-entry synchronization and rollback.

## Delivered

- Exact selected-session identity and runtime directories with connection-generation
  replacement, stale cleanup protection and account-scoped transition gating.
- Read-only admission/wire preflight before lifecycle side effects, followed by registered
  durable preparation and exact compensation for every late failure.
- Cohesive services and peripheral adapters for dirty item-lease persistence, daily refill,
  dungeon-effect recovery, expert-contract/PvP skill preparation, quest seeking, pet
  revival, position persistence and dungeon rejoin.
- Typed X-07 and X-09-X-18 trigger/recipient coordination while Networking remains the
  sole framing layer and performs no repository lookup, target discovery or mutation.
- Required-owner versus best-effort-peer delivery, publication timing, listener-local
  cleanup, close-after-gate behavior and truthful runtime replacement after mutations.
- G7 coverage and historical migration documentation that distinguish implemented
  code-reversed behavior from later client confirmation.

## Verification

Fresh real-PVF full solution verification passed 488 tests with two intentional
missing-archive negative-path skips. Host built with zero warnings/errors, started and shut
down cleanly. Dependency, identity, nested-command and diff checks passed. Independent
complete code review is approved and the final plan-drift classification is aligned.

## Execution-time Corrections

Complete review exposed lifecycle-order, concurrency and legacy-fidelity issues that were
fixed before acceptance: durable mutations now occur inside exact registration/rollback;
outbox claim and dead-letter are lease-bound; dirty leases persist avatar details through a
narrow item-only contract; close never waits while owning the disconnect gate; PvP skill
preparation preserves character-specific adjuncts; dungeon settlement uses its durable
session baseline; and expert-contract reconciliation distinguishes inapplicable skills from
an applicable zero cap.

## Remaining Validation Boundary

The protocol and lifecycle remain code-reversed from the legacy implementation. Real
client execution and packet-capture confirmation are intentionally outside this Spec and
remain the next validation activity, not an unimplemented G7 component.
