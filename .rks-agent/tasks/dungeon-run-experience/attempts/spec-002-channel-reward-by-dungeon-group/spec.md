# Specification: 频道奖励按档案声明的副本归属发放

## Why and Outcome

现在每一次击杀都付 5% 的频道奖励，不问在哪个频道、不问跑的是哪张图。这个数是从四个抓包样本反推出来的，代码旁边还写着「档案没有声明它」——而 `channel_info.etc` 里逐行声明着：哪个频道绑哪个副本组、该组加成百分之几，以及每个组含哪些副本。本仓启动时就把这个文件整份读进内存发给客户端，从来没解析过它。

结果要变成这样：在绑定了本局副本所在组的频道上打怪，通告里多出「赛丽亚的祝福奖励」那一行，金额是档案声明的百分比；换一个没绑这个组的频道打同一张图，那一行不出现。比率写在档案里，不在服务端的配置里。

## Task Perspective

- Core outcome: 频道奖励的**归属条件**存在并生效，比率取自档案。
- Necessary support: `channel_info.etc` 的两段被解析成「频道 → 副本组 → 百分比」；当前连接所在的频道号能在发经验的那一刻同步取到。
- Peripheral assurance: 解析失败、频道未声明、行残缺时的行为是「不付」而不是「起不来」或「照旧付」。

## Scope and Non-Goals

### In Scope

- `channel_info.etc` 的 `[dungeon]` 组与 `[server]` 行的解析。
- 击杀时按（所连频道、本局副本）决定频道奖励的有无与金额。
- 解析与查找的各种缺失、残缺、越界情形。
- 撤掉服务端一侧的频道比率配置项。
- 让这条规则在实机上正反两面都能被看见的部署配置。

### Non-Goals

- 通关结算的频道加成。结算此刻不发经验，没有可加的基数。
- `[server]` 行里与经验无关的字段。
- 频道类型对经验的影响——档案有这一列，没有证据说它参与计算。
- 按频道限制可进入的副本。

## Constraints

- 已验证的线级字节不变；频道奖励仍走 `+0x1A`。
- 解析失败不得引入新的启动失败，也不得阻止击杀发经验。（既有行为是脚本文件读不到时服务端拒绝启动，本成果不动它。）
- 2026-08-27 的四个抓包样本在「副本属于该频道的组」这一条件下仍须复现 65 / 75 / 132 / 153。

## Definitions

| Term | Meaning |
|---|---|
| 副本组 | `channel_info.etc` `[dungeon]` 段里的一块：一个组名（形如 `` `[granfloris]` ``）加一串副本号 |
| 频道行 | `[server]` 段里的一行：频道号、显示名、频道类型、组名、经验加成百分比，其后还有若干与经验无关的字段 |
| 归属 | 本局副本号出现在该频道那一行所指组名的副本号列表里 |

## External Behavior and Data Rules

- 档案里绑到副本组的频道，其经验加成百分比当前一律是 `5`；绑 `[deathtower]` 与 `[trade]` 的两行是 `0`。本 Spec 不写死这些数，读它们。
- 一个组名在 `[dungeon]` 段里出现多次，或一个频道号在 `[server]` 段里出现多次，都是矛盾声明：矛盾的那一项作废（不付），而不是任选其一。
- `[server]` 段的首行是一个孤立的计数标量，不是频道行。
- 百分比之外的解析细节：组名与显示名以反引号包裹，字段以空白分隔。

## Observable Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 本局副本属于所连频道声明的副本组时，击杀支付一笔频道奖励，比率为该频道行声明的百分比 |
| RQ-002 | 本局副本不属于该组时，不支付频道奖励 |
| RQ-003 | 所连频道在 `[server]` 段中没有对应行时，不支付 |
| RQ-004 | 频道行残缺、频道类型或百分比不是合法数、百分比超出 0–100 时，该频道不支付 |
| RQ-005 | 同一组名或同一频道号被声明多次时，该组/该频道不支付 |
| RQ-006 | 频道行声明的百分比为 0 时，不支付（不产生一笔金额为零的加成行） |
| RQ-007 | 频道脚本解析不出任何频道行时，服务端照常启动，击杀照常发经验与其余加成，只是没有频道奖励。脚本文件本身读不到时服务端本来就起不来，那是既有行为，本成果不改变也不依赖它 |
| RQ-008 | 支付出去的频道奖励落在 `+0x1A`，客户端画作「赛丽亚的祝福奖励」 |
| RQ-009 | 频道比率不是服务端配置项：`experience.json` 有无、写什么，都不改变它 |
| RQ-010 | 2026-08-27 的四个抓包样本，在副本属于所连频道的组这一条件下，仍得 65 / 75 / 132 / 153 |
| RQ-011 | 部署同时提供一个绑定含实测副本之组的频道与一个不含它的频道，并在文档中说明各自跑哪张图会看到什么 |

## Assumptions

- 抓包那一局所连频道的副本组包含 144。日志只记了金额，没记频道号；这条由「144 在 `[granfloris]` 组、绑该组的行写 5、5% × 62 = 3」相合推出。实机若与之矛盾，以实机为准。
