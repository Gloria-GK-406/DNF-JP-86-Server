## 三处如实标注

1. **结算帧那二十三个固定槽在 A21 一个都没测过。** 因此结算侧不付频道奖励与账号权益加成——付了报不出来。测法记在 `Docs/ExperienceNoticeSlots.md` 第七节。
2. **`[clear exp bonusrate]` 在本档案里是 1**，任何实测都区分不开"乘了它"与"没乘"。读取并参与是构造上的选择，与已在用的 `[monster exp bonusrate]` 同形同源。
3. **`etc/premiumlist.etc` 里有三个 premium type 声明了经验率**（type 5 与 12 的 `[exp] 5`、type 84 的 `[bonus exp] 20`），而代码此前断言"档案没为任何 type 声明"。注释已改正，行为未改：接线需要"档案声明 → 账号行 type"的映射，属下一个成果。这一处与频道比率是同一种错法的孪生。
