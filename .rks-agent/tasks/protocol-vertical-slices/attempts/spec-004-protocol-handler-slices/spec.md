# Specification: Protocol Handler Slices

## Why and Outcome

切片目录已经存在，但每个切片只装了一半。读者打开一个协议的目录，能看到它怎么收、怎么发，却看不到收到之后发生了什么——消息 handler 在应用层按功能分组，命令与命令 handler 在另一个按功能分组的目录里，消息 DTO 则和其余三十多条消息挤在一个文件里。回答"这个协议做什么"仍要跨三个编译单元拼凑。

本成果之后，一个协议的六类制品——消息 DTO、入站解包、出站编码、消息 handler、命令、命令 handler——同处一个目录，协议的接线集中在切片项目的模块内。这是根任务要交付的最终形态。

同时收尾两件只能在形态确定后做的事：把"消息 handler 不得直接实施业务语义"这条边界逐个 handler 审计并记入项目文档；以及把一处归属错位的注释放回它能被验证的地方——它当前以硬编码副本的形式声明着另一个编译单元的事实，那份副本没有任何机制看管。

## Task Perspective

- Core outcome: 每个已实现协议的六类制品位于同一个目录，且迁移未改变任何行为。
- Necessary support: 被抽象接缝钉死的类型必须留在原处而非随切片搬走；编译期依赖方向必须是切片单元依赖应用单元，且承载传输、抽象与数据契约的单元均不得反向依赖切片单元。
- Peripheral assurance: 零逻辑变更的逐文件比对、逐个 handler 的业务语义审计结论、既有断言未改的证明、以及全量测试对齐基线。

## Scope and Non-Goals

### In Scope

- 消息 DTO 自其单一集中文件拆入各自的切片；协议身份契约与被抽象接缝直接引用的投递类型留在数据契约单元。
- 消息 handler、命令与命令 handler 迁入各自的切片目录。
- 协议的消息 handler 与命令注册自应用层模块迁入切片项目的模块；命令总线、管线行为与领域服务注册留在应用层模块。
- 针对被迁移制品的既有测试随之迁移。
- 逐个消息 handler 审计其是否直接实施业务语义或状态迁移，产出可复核的结论。
- 项目文档记录新的编译单元职责与引用图、新增一个协议的固定动作、切片可拥有与不可拥有内容的边界规则、以及 handler 不得承载业务语义的规则。
- 归位一处跨编译单元后失效、现以硬编码副本存续的断言：使其位于能验证它的编译单元内并恢复符号引用，原处只保留该处能自证的部分。

### Non-Goals

- 协议身份契约与投递类型的迁移。
- 任何字节布局、加密参数、组帧规则、投递次序、解包判定与丢弃语义的改变。
- 命令总线、管线行为、执行闸门与访问模式取值的改动。
- 领域服务、仓储与内容源的迁移或改写。
- 共享字段读写原语的抽取。
- 新增或删除任何协议、消息、命令或注册项。
- 若审计发现某个 handler 确实承载业务语义，对其行为的实质性改写。该情形只记录，不在本成果内改动。

## Constraints

- 迁移部分不得夹带逻辑变更：除文件位置、命名空间、using、可见性修饰与迁移直接导致的失效引用修复外，不得包含任何行为改动。注释归位是本成果明确授权的例外，须单独列示。
- 承载传输、抽象与数据契约的编译单元均不得依赖切片单元；承载传输的单元亦不得依赖应用单元。
- 线级可观察行为必须不变：未知线上帧键静默丢弃、出站按端点校验、Channel 载荷的加密与压缩参数、Game 出站帧头、选择角色的静态帧流与补充投影的有序投递及其失败补偿次序、登录失败体仍不可编码。
- 消息 handler 不得直接实施业务语义或状态迁移，须经命令与领域服务到达。
- 不得以放宽类型、抑制诊断或关闭"警告即错误"的方式换取编译通过。
- 既有 580 项测试须全部继续通过，且断言内容不得改动；迁移可改变测试的位置、命名空间与 using。

## Definitions

| Term | Meaning |
|---|---|
| 协议身份契约 | 消息目录枚举、两个消息标记接口与两个端点的消息元数据记录——由抽象接缝、传输与派发器共同依赖的稳定类型 |
| 六类制品 | 一个协议的消息 DTO、入站解包、出站编码、消息 handler、命令、命令 handler |
| 切片 | 切片单元内属于同一个协议的一组文件所在的目录 |
| 钉死类型 | 被本成果不得修改的抽象接缝以参数或返回值形式直接引用，因而无法随切片迁移的具体类型 |

## Assumptions

- 除投递类型及其成分外，消息 DTO 在切片单元之外零引用。若迁移中发现反例，该类型的归属须重新评估而非放宽引用方向。
- 消息记录的成分类型随其所属消息进入同一切片。
- 命令与其 handler 同处一个文件是既有写法，迁移保持该形态而不拆分。
- 纯观测型 handler（不发送任何命令、只记录并查询在线用户）满足业务语义边界，因为它们不产生状态变更；审计仍须逐个给出该判定而非整体推定。
- 基线中存在一次未复现的宿主启动测试瞬时失败。同类瞬时失败不计为回归，但须如实记录。
