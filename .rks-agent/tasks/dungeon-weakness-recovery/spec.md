# Specification: 虚弱生命周期

## Why and Outcome

将临时登录值投影替换为服务端内存虚弱状态，落实用户已确定的失败惩罚和自然恢复。

## Scope

覆盖自然恢复、失败退图与连接清理、回城/重登投影。付费恢复和免虚弱资格排除。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 默认等级至少 20 失败退图设为 10；正常通关不施加。相同 run 退出最多一次施加。入场拒绝/回滚不视为中途失败。 |
| RQ-002 | 内存记录 Value、IsRecover；无记录返回 100，满 100 移除。单一 60 秒周期对恢复者增加 9 点，不补周期。 |
| RQ-003 | 成功入本幂等暂停，离本恢复；离线不暂停或移除，重登使用现值，服务器重启清空。 |
| RQ-004 | SetWeakness 不接收数值，内部判断等级和规则；Recover 清除虚弱。配置初值、门槛、周期和增量。 |
| RQ-005 | 登录、回城、在线恢复用 NOTI 0021 投影当前值，属性保持现有客户端计算；替换临时登录注入。异步投影必须检查当前会话，避免旧连接或旧值覆盖新状态。 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001 | 19/20 级边界；失败后 10，恢复至 19 后重复退出仍 19；通关离开保持原值；旧 run 退出不影响新 run。 |
| AC-002 | RQ-002 | 十周期为 100；暂停时任意周期无变化；可配置增量能夹取 100；全恢复后不再产出恢复变更。 |
| AC-003 | RQ-003 | 暂停/恢复各重复执行不改变数值；离线周期仍递增；新服务正常。入场失败不新增惩罚。 |
| AC-004 | RQ-004 | 默认与配置规则有效，非法范围明确拒绝；Recover 重复安全。 |
| AC-005 | RQ-005 | 编码 0021 单字节当前值；登录/回城和周期投递经当前会话约束；旧诊断配置不能覆盖业务值。 |

## Success Evidence

自动化验证负责规则与服务端生命周期；实机由用户接手，顺序为失败退出、等待恢复、入本暂停、离线重登、通关免罚。未执行实机前只报告实现和自动验证结果，不宣称 ClientVerified。
