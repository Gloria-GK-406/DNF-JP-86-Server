# TaskContract: 新·金角银角实现与部署待验收

## Context

### Source Request

2026-10-19 用户：“金角银角还是和之前的一样，如果没有什么特殊机制之类的就直接按藏宝地一样的顺序实现就行。先派子代理看看什么情况”。调查后用户授权：“那你先继续收集然后开始创建功能后部署，我再验收。部署后给我一个验收清单”。

### Current Situation

当前基线 task/next-round-20261019@ccc0e845；藏宝地已经用户验收。#155 的 DGN4123 是四房战斗副本，PVF给出单人、最低50级、难度2、无疲劳、无放弃惩罚、经验倍率0、无票和次数上限3。需要补齐专属计数通知、活动准入与持久额度；奖励兑换与开启材料语义存在双扣风险，须继续查证。当前没有本玩法实机验收。

## Goal

交付可在当前客户端测试的新·金角银角完整玩法循环，完成必要调查、实现、回归与部署，提供明确验收清单；最终实机验收由用户完成。

## Scope

### In

- 核定当前4123入口、专属次数消息及奖励购买/开启语义。
- 实现活动入口和准入、角色每日三次及失败回滚、状态刷新与持久化，复用现有地图/战斗/结算链。
- 保留当前PVF地图候选、疲劳/退出惩罚/经验和奖励规则，修正闭环所必需的共用缺陷并保护既有玩法。
- 验证、构建并部署当前测试服务，保护现有玩家数据和可恢复运行版本，提供实机验收清单。

### Out

- 恢复旧版灵符插房、旧金银角双图或历史限时纪念任务。
- 修改客户端二进制或PVF资源；未经证据调整掉率、增加额外奖励或改变其他活动规则。
- 将构建/回归通过视为玩家实机验收；自动关闭#155。
