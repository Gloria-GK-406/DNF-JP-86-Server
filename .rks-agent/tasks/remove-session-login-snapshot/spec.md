# Specification: 选角结果只在登录响应期存在

## Why and Outcome

修理后的装备耐久已写入权威物品数据，但进图消息从会话内旧登录结果重新投影，令客户端显示倒退。本任务让后续投影查询当前领域状态，使登录结果成为一次性组包值，而不是角色运行期的第二真源。

## Scope

包括所有生产环境对 `ISelectedSessionRuntimeDirectory` 中 `SelectCharacterResult` 的读取与替换，及因此需要调整的投影、业务通知、生命周期和测试。不改变既有协议布局、数据库迁移和数值规则；不部署。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 选角发布后，运行时会话只记录精确连接身份和必要的发布/持久化标记，不保存可变角色聚合。 |
| RQ-002 | 所有离开选角入口之后的装备、耐久、金币等物品相关投影从当前物品领域读取。 |
| RQ-003 | 任务、等级、技能、宠物、状态、世界内容等消费者从各自权威领域构造当前投影，不靠替换会话中的旧结果维持同步。 |
| RQ-004 | 旧连接无法读取、替换或删除新连接的状态；延迟通知只发送到对应代际。 |
| RQ-005 | 清除以会话物品副本为真源的冗余写回机制，文档反映新边界。 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001 | 发布、查询、移除目录时只处理精确会话和标记；生产目录与接口不含整份登录结果字段或同义缓存。 |
| AC-002 | RQ-002 | 给角色修理装备后，在选择副本、进入副本、回城和其他角色查看投影中显示当前耐久；不会回灌旧耐久。 |
| AC-003 | RQ-003 | 等级/任务变化在同一登录期的后续消息和结算中可见，不依赖更新会话聚合；相关现有行为回归通过。 |
| AC-004 | RQ-004 | 旧连接被替换后，其查询或退场不影响新连接；所有读取前校验当前代际。 |
| AC-005 | RQ-005 | 无生产路径在物品移动或高级道具变化后手动修补会话结果；租约仅在确有未落库修改时持有数据。 |

## Success Evidence

目录和消费者静态审计、关键投影与代际测试、完整解决方案构建与相关测试通过；将未能实机验证的客户端显示效果明确保留为待测，不以自动测试冒充实机结果。
