# Routing Decision

- TaskContract: `.rks-agent/tasks/character-state-finds-its-owner/TaskContract.md`
- Contract revision: `1`

## SDD Readiness

- Intent and outcome stability: 稳定。所有者在本轮对话中逐项裁决了每一样状态的归宿——身份归
  角色实例、坐标归专门的领域服务、设置归领域服务、连招归 store 与实例、任务那一层不新建、
  疲劳按用量记账——并且每一条都给了理由。其中三条与我的判断相反且被所有者纠正，所以归宿是
  所有者定的而不是推断出来的。可观察的结果也定了：第一批逐值不变，第二批疲劳真的会扣、扣光
  会被既有拒绝码拒。
- Requirement stability: 15 条成功条件，每一条都能独立核对。搬家类的靠「读取点枚举，逐个说明
  去向」核；疲劳类的靠存储形状、跨期判据、拒绝码引用计数核；护栏类的靠既有机检判据的 diff 核。
- Execution direction: 已知。目标形状在仓库里有现成样板——任务那条通路（领域服务交出实例，
  实例背后是三段式 store）就是这套词汇的完整实例，连招要建的是同一形状；惰性期号机制也已有
  现成实现，疲劳只需要自己的边界。成果如何切分由所有者明确授权给执行方决定。
- Remaining uncertainty: 只剩非语义的局部选择——承载身份的那个 record 同时是入场编解码器直接
  消费的快照类型，「挪到实例下」挪多远（暴露成员 / 删字段）是 Spec 层的边界决定，两种做法都
  满足所有者「身份要有主人」的意思。已写进契约的 Assumptions。

## Marginal Control Value

- User precision signal: 明确偏精度。所有者亲自指定 multi-spec；在本轮对话里逐项推翻了我的
  几个判断并要求把理由记下；上一轮任务里也明确要求过评审与验证不得省。同时他对速度有一个具体
  诉求——疲劳要能先占位，好让他继续实机测试——这是范围决定而不是精度让步。
- Direct failure mode: 具体且已被实证过两次。其一，第一批的判据是「行为逐值不变」，第二批必须
  改变行为；同一轮里做，任何差异都能被归给「那是第二批该改的」，逐值不变这道护栏就没了——
  上一轮 `commands-reach-only-domain-shapes` 正是因为这个理由分的三批。其二，空转接缝的调用点
  无人证明：上一轮评审把一个协议处理器整段回退到读陈值，全量判据仍然全绿，因为那条路径零判据。
  疲劳占位正是同一种形状。
- Useful control: 两个各有独立验收口径的 Spec；完整变更集的独立评审；以及对占位调用点的变异
  验证（SC-7 直接把它写成了成功条件）。
- Time-for-quality rationale: 这一轮跨 Data / Abstractions / Application / Persistence / Protocol
  五层，动 5 个搬家点并从零建一个子系统。逐值不变的护栏是这类结构工作唯一能自动发现夹带的
  东西，把它拆出来单独成立值这个时间；而占位调用点的变异验证成本只有一次改坏与还原，却是
  「到第二批才发现调用面是错的」的唯一拦截点。

## Structural Selection

- Selected workflow: `multi-spec-workflow`
- Boundary evidence: 两个成果的验收口径互斥。第一个是「服务器对客户端逐值不变」，第二个**必须**
  改变可观察行为（疲劳会扣、耗尽会拒）。合成一个 Spec 会让第一个的判据失去意义。两者也各自
  是可交付成果：第一批做完，角色状态已经各归各位，即使第二批不做也成立；第二批不牵动第一批的
  任何归宿决定。回滚边界同样独立——接受或回滚任一个都不影响另一个。
- Why Direct is insufficient: Direct 拿不到「两套互斥判据各自成立」这件事。它只有一个当前工作区
  状态，无法在同一轮里既主张逐值不变又主张行为改变；也没有地方记录哪一处期望值改动对应哪一次
  被授权的行为变化。
- Reroute conditions: 若在第一批执行中发现某一样状态的归宿其实依赖疲劳系统的实现（例如坐标或
  设置的落地时机被疲劳的存储通路牵动），则两个成果之间出现了真实依赖，独立接受不再成立，应
  停下重新路由。反之，若第二批开工后发现疲劳的三样输入中有一样在仓库里不可达（例如账号权益
  的到期语义无法判定），那是第二批自己的阻塞，不改变本次结构选择。
