# SAO共享塔一期规格

## 结构变化

当前普通CMD0010直接进入请求DGN，普通通关不改变SAO状态。重构后入场路由识别SAO，SAO领域服务读取共享进度决定实际DGN，通过公共Admission缴费/创建；通关事务调用SAO服务竞争推进和首队奖励。Protocol仅编码结果，Persistence持有共享真源，Infrastructure只提供内容。

## Requirements and acceptance

| Requirement | Acceptance |
|---|---|
| RQ-001 共享进度而非个人爬塔；首次1层，1..100映射来自PVF | AC-001 不同角色读同一进度，下一次进入对应当前层；100通关后轮次+1、层数1；重开数据库保持进度 |
| RQ-002 当次run冻结轮次、层数；只有真实通关能结算 | AC-002 主动退出/未清图/错run不能推进；再次挑战重新走SAO入场 |
| RQ-003 每轮每层第一支队伍获得10004331额外奖励，全员各一份 | AC-003 两场同层竞争只能一个winner；winner重放、普通后到者、跨轮旧副本不再重复推进或获得首通奖励 |
| RQ-004 推进、首通归属、成员领取与物品派发同事务 | AC-004 任一成员发奖异常时整次回滚；满包转邮件；实际奖励幂等由持久记录保证 |
| RQ-005 沿用每人1张门票，无疲劳，不新增每日3次上限 | AC-005 入场构造失败回滚；请求后续层也由服务端共享进度决定 |
| RQ-006 NOTI03E9共享进度投影 | AC-006 两u32编码与静态读取一致，登录/选图/本次通关刷新；TryRound取业务轮次是本期映射，须标待实机；不声称已完整还原03EA |
| RQ-007 SAO活动历史固定期限修复并同步开发客户端 | AC-007 只修改SAO活动条目expiration date，不移除永久/期间系统的通用逻辑；逐档案验证无关内容一致，原档备份，运行客户端占用时不强替换 |
| RQ-008 名称占位符调查 | AC-008 核对客户端DGN名称与字符串引用；有可靠定位则修复，否则报告确切未知，不编造dnf键 |
