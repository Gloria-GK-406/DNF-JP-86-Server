# TaskContract: 角色静态规则与动态状态模型重构

## Context

### Source Request

用户已依次明确：角色由静态规则数据和动态数据组成；职业 1—86 级属性应直接读取或在启动时预计算，规则服务可直接查询；技能规则实例回答说明、累计 SP/TP 消耗、职业/等级上限与学习资格，已学技能只保留角色实际学习状态；动态模型细节委托 Agent 处理。

最终执行授权：『ok，好。可以了，起个sdd完成这次重构吧。重构结束后我们再说学习技能的问题』。

### Current Situation

基线 main `8b19eaac9863e23da4703fa644bfd0cb882b6cd6`。角色实例、技能持久化、事务和通知机制已存在；部分业务仍读取选角快照。属性内容源只读取创建初值，未提供完整职业等级成长查询；技能定义缓存按已学技能组合建键，技能费用算法属于选角准备规则，maximum-level 多值声明被取首项。已有登录、等级经验、物品操作和出售能力必须保持可用。

## Goal

形成可投入现有角色流程使用的静态规则与动态事实模型：共享、只读、可高效查询的职业属性和技能规则；角色动态状态归属明确；已有消费者共用这些规则和当前事实，后续学习技能可直接在此基础上实现。

## Scope

### In

- 明确基础职业、转职方向、觉醒阶段及等级的领域表示，并集中处理 PVF/存储/协议表示转换。
- 提供当前 PVF 所支持职业组合的 1—86 级属性规则查询；已有声明直接读，需组合的结果在初始化阶段准备；完整结果与适用范围可验证。
- 共享技能规则实例：职业技能目录、等级上限、前置声明、累计 SP/TP 成本、免费/自动成长基线；技能点总量可查表，角色剩余点数由总量、动态奖励和实际学习投入得到。
- 允许规则服务返回不可变规则实例，实例持有静态规则并接受显式事实；重构相关接缝与现有调用。
- 梳理角色身份、成长、已学技能、额外奖励等动态事实的归属与读写入口；保留背包、任务等已有独立业务边界，消除本范围内将过期会话投影当作当前事实的调用。
- 迁移创建、选角、已有升级/经验及技能点查询等现有生产路径；保持事务、持久化与协议适配一致，修正已确认的成长与多值技能上限缺口。
- 相应测试、架构约定更新和有决策价值的简明文档。

### Out

- BUY_SKILL、REFUND_SKILL、快捷栏等新技能协议及学习技能用例；重构后另行讨论。
- 新增转职/觉醒协议、支援兵或自由决斗玩法、技能伤害结算、Buff 计算系统。
- 重写背包、任务、商城、网络传输及其他不受本次模型变更影响的领域。
- 修改客户端二进制或基准目录、修改上游、变更远端 issue、推送、合并、部署或清理工作区。

## Constraints

- 用户确定的静态/动态边界：规则与角色状态分开；动态角色不能各自持有一份可漂移的静态规则结果；规则实例不自行查询角色数据库或会话状态。
- 保留既有 Command → 领域服务 → Event、项目依赖、事务提交与通知语义；规则实例用法作为本次已授权的规则层约定扩展。
- 不以新增持久化 SP/TP 余额替代推导；免费技能与动态额外奖励必须计入正确。
- 上游只能作为规则线索，不能直接当作当前客户端实机证明。未证实的属性单位/映射不得包装成确认结论。
- 保持既有协议布局和已验证行为；已确认读取错误与缺失成长查询按本次正确规则修正，不能为保留错误而阻止重构。
- 所有数据库验证使用隔离副本或临时库，不修改运行中的角色数据；迁移不得丢失已学技能、装备、金币等角色事实。
- 用户文档优先 Markdown，设计说明放 Document；SDD 工件使用任务目录。

## Success Conditions

| ID | Observable condition | Required evidence |
|---|---|---|
| SC-1 | 职业/转职/觉醒表示统一且合法性可判，存储与协议转换明确 | 覆盖合法组合、无效组合和往返表示的检查，现有路径使用该表示 |
| SC-2 | 属性规则可直接查询所有支持组合的 1—86 级结果，运行请求不重新解析成长档案 | 真实 PVF 覆盖检查、代表职业/转职/觉醒及等级边界与独立计算对照、初始化和查询成本测量 |
| SC-3 | 规则服务可取得共享只读技能规则，正确回答累计成本与职业/等级准入 | 元素点燃多值上限、剑魂十字斩/血之狂暴、SP/TP/免费基线等代表案例及定义缺失行为 |
| SC-4 | 剩余技能点取当前事实计算，静态缓存与角色已学组合脱钩 | 不同角色/技能页/等级/额外奖励的真实规则与存储测试，现有生产查询迁移证据 |
| SC-5 | 动态状态有单一归属，当前角色数据不依赖旧选角副本；相关操作提交与回滚一致 | 现有读写路径核查、升级或学习记录变化后立即查询、失败回滚及重载状态检查 |
| SC-6 | 现有创建/选角/经验和物品业务保持可用，没有接入新技能协议或扩大范围 | 相关回归与全解决方案验证，完整变更审查，范围与持久化兼容性证据 |
