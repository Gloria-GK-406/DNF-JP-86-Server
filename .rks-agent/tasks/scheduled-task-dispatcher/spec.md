# 注册式调度器

日期2026-10-14；基准1a0d8f9e。

## Before / After

当前后台组件各自持有计时循环。新增通用注册机制后，消费者注册任务身份、时间规则、补执行策略和回调；共享调度器只管理到期与执行生命周期。旧业务后台组件不在本次迁移范围，不能顺带注册删除物品。

## Requirements and Acceptance

| ID | Requirement | Acceptance |
|---|---|---|
| RQ-001 | 任务注册定义稳定唯一ID、异步回调、计划；重复或非法定义启动前失败 | AC-001：实际DI注册重复/非法拒绝，空注册无业务及常驻timer |
| RQ-002 | 支持固定间隔与指定固定时区的每日时刻；计划有严格未来Next和最近已到Last | AC-002：边界前/正点/后、UTC+8六点、间隔锚点，计划测试不依赖机器时区 |
| RQ-003 | 单一等待循环唤起到期任务；不同任务可并行但全局并发受限；同任务不可重叠 | AC-003：可控时间实际回调，多任务阻塞仍执行、上限与慢任务合并回归 |
| RQ-004 | Skip启动仅等未来，RunOnce启动执行最近已到期一次；运行中错过多个周期合并，不能爆发重放历史 | AC-004：跨日跃迁、启动策略、慢回调补一次；明确跨重启可能重复，消费者幂等 |
| RQ-005 | 尝试次数有限、异常隔离，每次尝试独立scope并释放；停止传播取消且不再派发 | AC-005：失败后其他任务成功、重试次数/服务实例生命周期、取消/等待释放；不强行放弃还在运行的回调后并发重试 |
| RQ-006 | 回调通过scope获取业务服务；调度器不含账号/清理/事务/NOTI逻辑 | AC-006：正式接线无真实业务注册，差分/独立审查，记录下一阶段在线清理+登录共用逻辑边界 |

## Limits

静态DI注册，同进程执行。时间规则固定时区偏移，不实现DST/cron全集。重试只在前次回调返回/抛错并完成scope释放后发生；取消协作式，不能承诺强制终止不响应token的任意代码。有限重试耗尽后本轮结束，后续正常周期仍可执行。

## Next Cleanup Boundary

后续定时回调只能枚举仍在线的精确角色会话，按既有账号闸与命令事务调用同一过期清理领域逻辑；离线由登录流程调用，不做全库六点删除。在线变化再走EventBus；本次不实施该回调。
