# TaskContract: 牛头怪乐园可玩闭环

## Context
当前DGN3700已有入口与三房间资源，通用日补票有领取记录，但无专属入场领域服务；怪物角色等级替换与经验书效果未接通。0482属于8014等TauLevel模式，不适用此图。

## Goal
完成旧牛头怪乐园的单人入场、角色等级适配、每天一张票和经验书使用闭环，供用户测试角色验收。

## Scope
- 独立乐园领域服务，27级以上、单人、固定普通、不耗疲劳、每次一张690001556；复用公共入场凭证、消费、地图与回滚。
- 固定三房间路线，入场等级冻结；经验沿用DGN权重7；现有Boss独立掉落不重复发奖，不改既有等级范围。
- 牛头票6点游戏日新增1张，登录/在线同周期不重复，离线只补当前周期；复用日补给和调度器，不改变其他补给的既有日界。
- 四种兵书固定/百分比经验、20..84等级限制、到期检查，扣除与经验同事务；新书次日6点过期并复用已有清理。
- 全天开放活动2215，保留现有活动配置职责；不增加历史7次或7票硬限制，不发送0482。
- 验证后检查实际游戏进程；没有客户端才可部署并重启，有客户端仅报告就绪等待用户指定时间。

## Constraints
沿用工作分支task/next-round-20261013和当前工作区，保留无关WireSmoke缓存。Application分层与handler约束遵循AGENTS；复用现有领域模型和Event服务。不得替用户创建/修改测试角色，不改其他活动、PVF、参考client或发行包，不做PR/推送/合并/版本提升。
