# TaskContract: 地下城入场资格与费用凭证重构

## Context

### Source Request

“行，就按这个把入场判定和cost消费部分重构吧。写任务契约后实施。”

### Current Situation

普通、循环、深渊、镜像、异界的资格检查与材料、次数消费分散；普通地下城出生房和后续新房间已经消耗疲劳。资格与目标地图选择必须分离。

## Goal

现有地下城入场统一为资格判定生成每位参与者的凭证、消费凭证、执行玩法入场三个阶段；任一阶段失败不遗留扣费或部分队员入场。

## Scope

### In

- 迁移已实现普通、循环、主动深渊、镜像、异界的资格与入场材料、次数收费职责。
- 统一强类型资格结果、每队员凭证数组、消费结果和失败原因，保留现有协议错误映射。
- 普通地下城疲劳只作为资格条件；出生房与后续首次房间原有扣除各执行一次。
- 自动化回归、结构职责说明与任务证据。

### Out

- 不实现绝望塔、大会、祭坛或随机深渊新玩法，不改变现有玩法数值与开放规则。
- 不部署、不修改客户端/PVF/真实数据库、不提交远端或发布。

## Constraints

- 资格判定只读取状态；地图、楼层选择仍由玩法入场逻辑负责。
- 单人和组队统一使用凭证集合；无费用凭证有效。
- 收费先于实际运行实例/初始房间创建；收费与入场共用事务，失败整体回滚。
- 普通地下城凭证不产生疲劳费用，不重复扣出生房或新房间疲劳。
- 保留 DomainService -> RuleService 分层及 EventService.DirectAsync 次数结算路线。

## Success Conditions

| ID | Observable condition | Required evidence |
|---|---|---|
| SC-1 | 各现有入口均依次执行资格、凭证消费、实际入场；目标选择与资格职责分离 | 调用路径与结构审查 |
| SC-2 | 免费入场凭证有效；无疲劳拒绝，有疲劳时新房间只扣一次 | 回归测试 |
| SC-3 | 材料、深渊替代门票、每日次数维持原语义，组队失败指明队员 | 对应入口回归 |
| SC-4 | 任意队员消费失败或后续创建失败，全部收费与运行状态回滚 | 真实事务失败路径测试 |
| SC-5 | 凭证不能重复收费或跨本次请求使用，收费时校验当前事实 | 凭证消费回归 |
| SC-6 | 既有入场失败回包与成功投影兼容，构建和相关判据通过 | 独立评审及验证记录 |

## Authorization

| Capability | Evidence | Authorized scope |
|---|---|---|
| task | “行，就按这个把入场判定和cost消费部分重构吧。写任务契约后实施。” | 契约、隔离工作区、实施、测试、独立评审及本地结果提交 |

## Assumptions

- 保持现有已实现玩法规则；绝望塔的每日和额外门票规则留给后续玩法任务。
