# Specification: 地下城入场资格凭证与收费

## Why and Outcome

将资格判定、收费和实际入场分开，使普通、循环、主动深渊、镜像、异界沿用一致执行骨架。资格可以读取塔等玩法状态，但不决定入哪层或创建地图。当前不增加新玩法。

## Scope

保持现有等级、任务、难度、材料替代、次数周期、疲劳和协议拒绝语义。具体目的地和迷宫仍由玩法服务选择。

## Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 资格检查只读，成功为全部参与者生成同一次入场的凭证数组；任一队员不满足时不收费 |
| RQ-002 | 凭证声明本阶段费用；允许空费用；费用消费先于房间和运行实例创建 |
| RQ-003 | 普通地下城疲劳仅检查余额，凭证没有疲劳费用；出生房扣1，后续首次房间扣1，重访不扣 |
| RQ-004 | 普通材料和深渊替代票统一规划，重叠物品不超扣；保留持有但不消费的要求与账号材料 |
| RQ-005 | 镜像和异界次数仍经 DirectAsync 同步写 UsageQuota；每日周期与上限保持原规则 |
| RQ-006 | 凭证仅能在本次事务消费一次，消费时复核当前资源；组队消费或后续入场失败整批回滚 |
| RQ-007 | 各层职责清晰：玩法选择目标；资格服务检查与收费；Visit 创建运行实例及房间；协议层映射错误 |

## Acceptance Criteria

| ID | Covers | Criterion |
|---|---|---|
| AC-001 | RQ-001,RQ-002 | 免费入场产生有效凭证且可消费；第二名队员缺材料时所有人资源不变 |
| AC-002 | RQ-003 | 零疲劳拒绝；普通首次入场只扣出生房1点，移动至未访问房间再扣1，返回不扣 |
| AC-003 | RQ-004 | 同物品的普通费用和深渊费用合并校验、扣除，持有要求不扣，材料不足返回原失败类别 |
| AC-004 | RQ-005 | 镜像与异界成功后次数持久化；拒绝、回滚和跨日维持既有行为 |
| AC-005 | RQ-006 | 凭证重复或跨事务消费被拒；消费后创建失败及第二队员写入失败真实数据库恢复且无运行实例 |
| AC-006 | RQ-007 | 独立审查覆盖所有生产入口；相关应用和协议判据通过；无部署或客户端改动 |

## Success Evidence

现有入场、材料、深渊、镜像、异界、循环、协议和事务回归，加凭证复用与消费先于创建失败的新判据。结构性变化以代码路径审查和 Document 说明判断，不用依赖形状单测代替业务验证。
