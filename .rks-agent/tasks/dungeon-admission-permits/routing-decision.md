# Routing Decision

Ready: 资格、凭证消费、入场职责及疲劳边界已由用户明确。

Value: 普通与深渊材料可能重叠、组队部分扣费、创建失败未回滚及疲劳重复扣除是具体风险。持久化 Spec 和独立结果评审约束这些跨路径遗漏，收益高于记录成本。

Structure: single-spec-workflow，一个统一入场验收边界。

Controller Selection: sdd-lite / focused-delivery。执行路线已确定，无需额外 Plan；独立评审和真实事务失败判据足够保护本次变更。

Reroute: 如需改变现有玩法规则或出现独立功能验收边界，停止扩展并重新界定范围。
