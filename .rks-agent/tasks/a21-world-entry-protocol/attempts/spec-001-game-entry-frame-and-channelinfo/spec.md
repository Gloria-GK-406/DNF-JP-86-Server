# Specification: A21 游戏端点入站帧边界与初始连接通知

## Why and Outcome

A21 客户端连上本服务器的游戏端点后立刻走不下去：它发来的第一条命令被按错误的帧边界
切开而无人接收，而服务器回给它的初始连接通知比客户端要求的少八个字节且两处取值不符，
客户端因此在几秒内主动断开。

本规格要达成的可观察结果：A21 客户端连上游戏端点后保持连接，并继续发出它的登录命令。

## Task Perspective

- Core outcome: A21 客户端在游戏端点上不再断开，而是继续推进到发出登录命令。
- Necessary support: 入站帧边界与客户端一致；初始连接通知的内容为客户端所接受；
  客户端的连接检查命令得到它期待的应答。
- Peripheral assurance: 每条具名字段可追溯到实测字节；协议知识库与帧基线记录同步反映
  这些结论并保留被推翻结论的原因。

## Scope and Non-Goals

### In Scope

- 游戏端点入站帧的头部边界与字段含义。
- 初始连接通知的报文体内容与顺序。
- 客户端连接检查命令的接纳与应答。
- 上述三者在协议知识库、其目录状态与帧基线记录中的表述。

### Non-Goals

- 登录命令本身的请求解析与应答内容。
- 账号花名册、选人与进入世界的任何报文。
- 频道端点的行为（实测已为 A21 客户端接受）。
- 服务架构、分层、切片边界与命令总线语义的任何改变。

## Constraints

- 每条具名字段的含义必须能指向实测字节；不得以上游实现的写法作为依据。
- 协议知识库不得收录凭据、令牌或个人可识别信息；客户端登录命令的样本不得入库。
- 服务架构保持不变。

## Definitions

| Term | Meaning |
|---|---|
| 游戏端点 | 客户端在选定频道后连接的那个服务端点，与频道端点是两套帧格式 |
| 初始连接通知 | 客户端连上游戏端点后由服务器主动下发的第一条通知，客户端据此确定频道身份、地址与两张派发表的大小 |
| 连接检查命令 | 客户端在游戏端点上周期性发出的存活探测命令，本规格中它不承载任何领域语义 |
| 派发表大小 | 客户端两张报文派发表各自的条目数，客户端把它当作校验值 |

## External Behavior and Data Rules

- 入站游戏帧的头部为 14 字节，依次为：一字节选择子、二字节报文类型、四字节整帧长度、
  四字节校验值、一字节保留位、二字节逐帧递增的连接内计数。报文体长度等于整帧长度减 14。
- 出站游戏帧的头部仍为 15 字节，本规格不改变它。
- 初始连接通知的报文体依次为：一字节接受标记、频道名字符串、两个值为零的 32 位整数、
  一字节服务器序号、一字节频道编号、一个零字节、一个 32 位服务器时间戳、
  值为一的 32 位地址计数、对外公布的游戏主机字符串、两个 32 位 UDP 端口、
  一个值为零的 32 位附加地址计数、两个内容为 ASCII 字符零的标记字节、
  32 位命令派发表大小、32 位通知派发表大小、一个值为零的 32 位尾部整数。
- 字符串字段的形式为 32 位长度前缀加其后的 ASCII 字节。

## Observable Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 游戏端点按 14 字节头部切分入站帧，报文体长度为整帧长度减 14 |
| RQ-002 | 客户端发来的空体命令被交付为空体，而不是被读成一字节报文体 |
| RQ-003 | 入站帧头部的保留位与连接内计数被分别识别，计数值随该连接上的每一帧递增一 |
| RQ-004 | 初始连接通知的报文体按 External Behavior and Data Rules 所列顺序与字段构成 |
| RQ-005 | 初始连接通知报告的命令派发表大小为 1271，通知派发表大小为 1218 |
| RQ-006 | 客户端的连接检查命令得到同一命令类型的应答，其报文体为单字节 0x01 |
| RQ-007 | A21 客户端连上游戏端点后不再断开，并继续发出登录命令 |
| RQ-008 | 协议知识库中游戏帧、初始连接通知与连接检查命令三条记录及其目录状态反映本规格结论，被推翻的旧结论保留其被推翻的原因 |
| RQ-009 | 帧基线记录与仓库说明中关于入站游戏帧头部长度的表述与 RQ-001 一致 |

## Assumptions

- 已留存的 A21 已知良好会话代表该客户端接受的行为；与本仓既有结论冲突时以其为准。
- 入站帧头部末两字节被视为一个 16 位计数：实测样本中该计数最大到 189，从未越过 255，
  因此高位字节参与计数这一点是推断而非实证；低位字节逐帧递增一则由 190 条实测帧证实。
- 对外公布的游戏主机取值是否必须与频道列表中的一致，本规格不作要求；已知良好会话中
  两处一致，本仓亦一致。
