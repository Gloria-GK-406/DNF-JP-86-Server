# Specification: 怪物死了会按档案掉东西

## Why and Outcome

现在杀死一只怪，服务端回的那一帧里掉落条数恒为零。那不是缺陷，是一个当时诚实的决定——
没有内容模型就不发明掉落。现在内容模型查清了，写在 `Docs/DropRates.md` 里。

结果要变成这样：在副本里杀死一只怪，它按档案声明的规则掉出金币与物品，东西躺在地上，
能被捡起来。掉什么、掉几件、什么品质，每一个数都能指回档案里的某一行。

同一台机器还要能被二期的翻牌直接换一张费率表拿去用。

## Task Perspective

- **Core outcome**：一次击杀产出符合档案的掉落，并出现在地上。
- **Necessary support**：读档案的两类内容源（费率表、物品池）；把它们变成一次掉落的纯规则；
  本局的场景槽编号；可复现的随机源。
- **Peripheral assurance**：对真档案的数值判据；「不是自洽的错读」这一层的判据；
  爆率增强接缝在一期不改变任何结果。

## Scope and Non-Goals

### In Scope

- 怪物费率表的读取与其五个率、三张加成表的对应。
- 稀有度判定，含基数取自表、门槛相同即该档为零。
- 装备与堆叠物两个物品池的读取、入池资格、分桶与加权。
- 由等级、稀有度取出一件物品的纯规则。
- 一次击杀的掉落编排：五个率各自独立掷。
- 掉落出现在击杀通告里、有本局唯一的编号、能被既有拾取路径取走。
- 同一输入重问给同样结果。
- 爆率增强的改率接缝（一期空实现）。

### Non-Goals

- 翻牌、独立掉落、世界掉落、次元、深渊、可破坏物打破时的另掷、怪物自有掉落池。
- 补偿与保底的实现。
- 金币进入角色账户（金币可落地，拾取金币不在本期）。
- 怪物档次的建模（见 Assumptions）。

## Constraints

- **档案是数值的唯一来源。** 分母、门槛、倍率、入池资格都从档案读出。
  写死其中任何一个都不满足本 Spec，即使结果看起来正常。
- 只有上游一个来源的读法必须在成果物里标注为读法。
- 已验证的线级字节不得改变。
- 同一局同一间房重新描述时，掉落不得改变。
- **判据要能分辨「读对了」与「读了个自洽的错」**：断言档案里的具体数值，
  而不是断言实现与自己一致。

## Definitions

| Term | Meaning |
|---|---|
| 费率表 | 按等级段给出金币与四个物品类型槽各自掉落几率的表，另有档次/难度/组队三张倍率表 |
| 稀有度阶梯 | 一组累积门槛加一个基数，摇一个基数以内的数落在哪段就是哪档 |
| 品级带 | 由怪物等级换算出的一段物品品级范围 |
| 物品池 | 按 `(品级, 稀有度)` 分桶、桶内按权重可抽的物品集合 |
| 入池资格 | 物品自己声明的、决定它能否被随机产出的那个值 |
| 场景槽编号 | 一件掉落物在本局内的运行号，客户端据此指认要捡哪一件 |

## External Behavior and Data Rules

- 一次击杀的掉落是一个列表，长度可以为零、一或多。
- 五个率各自独立决定，互不排斥。
- 每个命中的物品类型槽各自掷一次稀有度。
- 金币的数额另有等级表与浮动百分比。
- 掉落随击杀通告一起送达，每件带本局唯一的编号。
- 客户端按编号请求拾取，走既有的拾取路径。

## Observable Requirements

| ID | Requirement |
|---|---|
| RQ-001 | 费率表按「低级 高级 + 五个率」读出，三张加成表各五组与五个率一一对应 |
| RQ-002 | 稀有度按累积门槛判定，**基数取自表**，门槛与前一位相同的那一档概率为零 |
| RQ-003 | 稀有度的六档都可达，史诗与传说的概率不为零 |
| RQ-004 | 装备池与堆叠物池按 `(品级, 稀有度)` 分桶、桶内按权重可抽 |
| RQ-005 | 一件物品能否进池由它自己声明的资格值决定，未声明者不在池中 |
| RQ-006 | 给定种类、等级、稀有度可取出一件品级在带内的物品；桶为空时不产出而非报错 |
| RQ-007 | 一次击杀按五个率各自独立掷，全部未中时不产出任何掉落 |
| RQ-008 | 命中多个率时产出多件，彼此编号不同 |
| RQ-009 | 掉落随击杀通告送达，携带物品、数量与编号 |
| RQ-010 | 客户端可按编号取走一件掉落，重复请求同一编号不再给第二次 |
| RQ-011 | 同一局同一间房以同样输入重问，掉落逐字段相同 |
| RQ-012 | 爆率增强的接缝存在；一期的实现不改变任何掉落结果 |
| RQ-013 | 只有上游一个来源的读法在成果物中被标注为读法而非事实 |
| RQ-014 | 既有的击杀、经验与拾取路径的可观察行为不变 |

## Assumptions

- 怪物档次尚未在本仓建模，档次倍率因此取不到真值。一期按普通档处理，并在成果物中写明
  这是缺省而非结论；掉落率会偏低，是有界偏差而非编造。
- 击杀通告里掉落记录的字节布局取自上游构包器，尚未用带掉落的真实帧验过。
  本期第一次真的往里写内容，实机若与之不符以实机为准。
- 「五个率独立掷」「类型槽到种类的映射」「门槛四组对应四个类型槽」这三条只有上游一个来源，
  按 RQ-013 标注即可，本 Spec 不要求为它们取得新证据。
