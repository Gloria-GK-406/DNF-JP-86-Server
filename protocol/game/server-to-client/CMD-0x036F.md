# CMD 0x036F PREMIUM_SERVICE：魔王契约服务快照

Game，Server → Client，cmd=0x01/type=0x036F。这是服务端主动发送的CMD族消息，不是NOTI 0x036F，也不要求先收到同号请求。

## 布局与证据

小端body共77字节：`u8 result=1 + u16 variant=1 + bytes[74] snapshot`。客户端通用CMD分发消费结果字节，业务handler读取变体及快照。

以下偏移均相对74字节快照起点（完整body偏移需加3）：

| 偏移 | 宽度 | 含义 |
|---|---|---|
| 0..5 | 6 | 当前置零，未证明业务语义 |
| 6+9*s | u32 | 槽s到期Unix秒，绝对时间；0表示未开通 |
| 10+9*s | u8 | 槽s已用次数 |
| 11+9*s（s=0..6） | 4 | 当前置零，未证明业务语义 |

s=0..7；最后一槽到期字段位于69..72，次数位于73。最后一槽没有尾部4字节；不得将次数写成i32，否则越界。服务端投影已过期/缺失槽为零。

槽映射：0黄金卡牌免费翻、1双倍袖珍罐、2任务助手、3BUFF服务、4HP/MP自动恢复、5免费解除虚弱、6自动修理、7高效开罐。580..587只是服务端内部权益键，不是客户端premiumType。

布局证据：客户端静态调查v2（ClientStatic）及现编码器；用户实机验证证明当前快照可用于期限显示，不将用户反馈冒充逐字节抓包。详见[调查报告](../../../Document/outputs/premium-service-client-analysis/premium-service-a21-investigation.md)。

## 抽象流程

- 商城CMD0040：按PVF商品确定服务槽、期限、价格；同一事务扣款并续期，有效订阅从原到期时刻延长，过期订阅从当前时刻起算。
- 提交后发送购买成功ACK、余额及必要物品更新，再发送完整八槽快照；不是只发送本次购买的槽。
- 正常A21角色入场结束后发送完整快照，包括无权益的空快照，刷新客户端缓存。历史ReferenceSequence对照模式不追加此消息。
- NOTI0042只是权益提示，不能代替这份期限快照。
