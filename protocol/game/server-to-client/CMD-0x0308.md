# CMD `0x0308` 循环地下城准备响应

Game 服务端 → 客户端，selector `01`、type `0308`。

| 成功 body offset | 编码 | 用途 | 证据 |
|---:|---|---|---|
| 0 | u8 | 0 失败，非 0 成功 | ClientStatic / High |
| 1 | u32 | 非零时允许继续接取任务；实现取 1 | ClientStatic 判定非零；上游取值候选 |
| 5 | u32 | 循环任务 ID，非零时发送 `001F` | ClientStatic / High |

实现成功示例：`01 01 00 00 00 63 3B 00 00`（任务 15203）；失败为 `00`。
响应处理 RVA `00D05C70`。客户端在 `001F` 接取成功的 Circle 分支自动构造 `0010`。

本响应仅说明准备握手结果。接受任务、正式入场、材料消耗、奖励与界面通知分别由后续命令负责。
完整成功 body 尚未标记 ClientVerified；需真实客户端验收，不能把服务端编解码测试视为客户端证明。

实现与验收说明：[循环地下城单人闭环](../../../Document/CycleDungeon-20261009.md)。
