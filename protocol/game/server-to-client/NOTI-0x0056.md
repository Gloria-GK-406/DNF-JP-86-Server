- 子类 1 失败样本等级字节为 12，显示「+13 …失败」：失败时应发**失败前的等级**。
- 子类 3 数量 2 显示「获得了2个[…]」，数量 1 走无数量文案。
- 子类 7（uid 版）显示「[+12 物品]」；子类 0x12（名字在包内）不显示等级。
- uid 为 9999（无此角色）时不显示。
- **uid 子类型的可见范围**：接收方只显示本频道会话中见过当事人的 uid。两人同频道但从未同区域时，接收方看不到；换频道后客户端清空已知角色表，之前见过的也看不到；不换频道的一方保留旧记录，仍能看到对方。因此带 uid 的子类型不能用于全区广播。
- 同时发出的 01F7 mode 2 文本与系统行同样显示，正文中的 `%s %d` 原样显示，不作格式串。
