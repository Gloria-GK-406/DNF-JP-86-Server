# NOTI `0x0344` `BUY_RESTRICT_ITEM_LIST`

## 身份与证据边界

Game / Server → Client / `cmd=0x00` / `type=0x0344`。A12 的同名协议为 `0x02DA`，不可按编号通用位移推导。

证据级别：**ClientStatic / High**。旧参照入场帧仅证明空列表长度为 4 字节；此次未新增非空列表原始抓包，也尚未获得本轮限购界面实机验收。

## Body

| Offset | 类型 | 含义 |
|---:|---|---|
| 0 | u32 | 列表项数 N |
| 4 + 12 × i | u32 | 限购声明 ID，不是商品 ID |
| 8 + 12 × i | u32 | 限制结束的 Unix 秒，或永久限制 sentinel |
| 12 + 12 × i | u32 | 当前购买标志；0 受限，非 0 可购买 |

长度 `4 + 12 × N`。读取指令：`0x0116182C` 读 count；`0x01161894/0x0116189D` 读 ID/endTime；`0x011618E3` 读 flag。调用的 u32 读取原语为 VA `0x027C5310`。

handler 在 `0x01161817` 清除原限制列表，在 `0x0116181E` 恢复所有 PVF 默认标志，然后应用当前列表。因此购买通知必须携带完整快照，不能只发送新增的一条。

`endTime=0x7FFF53F0`（2147439600）被 `0x011618F1` 作为永久限制 sentinel 检查。有限期条目通过 `0x00B35950` 加入计时列表；`0x00B231B0` 更新当前标志。计时显示通过 Unix 秒计算日／时／分。

不要与 NOTI `0x02C2 CASH_SHOP_PURCHASE_LIMIT_INFO` 混用：后者是商品剩余数量路径，而此协议是受限状态及结束时间路径。

## PVF 与当前实现

`etc/cerashop.etc [buy restrict item]` 的光明之心礼包记录是 `32 101236 30 1`。A21 parser VA `0x02B22371–0x02B2246F` 逐项读四个整数，第三、第四字段存入 byte；第四字段复制为默认和当前标志。`0x00B4762C` 调用该 parser，并传入商城 `+0x212C0` 限制表。

本次服务端把第三字段解释为冷却天数，采用账号范围限购：正数购买后冷却相应天数，0 使用永久 sentinel，初始标志仅支持 1；其他标志仍显式拒绝。**第三字段的运营语义及原服账号/角色范围尚未独立证明，此段是 CurrentImplementation 规则选择，不是 70Reference 或官方规则结论。**

新记录由 `SetPurchaseRestrictionEffect` 在共同事务中写入 `account_purchase_restrictions`。购买后的 `CeraShopPurchaseCompletedHandler` 与登录后的 `AccountEntryStateDomainService` 读取同一完整状态；到期条目以 flag=1 投影，未到期／永久条目以 flag=0 投影。

编码映射：[PurchaseRestrictionCompatibilityMessage](../../../Server/src/Dfo.Server.Protocol/Game/StateSynchronization/StateSynchronizationMessages.cs)，body 为 `StateSynchronizationPayloadCodec.EncodeCompatibilityEntries`。
