## A21 客户端读取（2026-11-12）

证据：ClientStatic，`DNF.unpacked-b1-debug.exe`（SHA-256 `D7618A10…A99A`）静态反汇编；地址为 VA
（= 本页 RVA + `0x400000`）。完整推导见
[好友与黑名单客户端证据](../../../.rks-agent/tasks/friend-relations-first-batch/research/client-evidence.md)。
上方 A12 区的「8 字节」形状不适用于 A21。

handler `01161580`（RVA `00D61580`）读 `u32 subcmd`（`0116158F`），`subcmd>4` 忽略，否则经跳转表 `01161630`
调用好友/黑名单对象 `[03A5C994]` 的方法。该对象只有一张 `map<(server,name), 条目>`（`this+8`），好友、
永久黑名单、客户端本地的临时遮断都是同一节点上的三个标志。Confirmed。

| subcmd | 方法 | 作用 |
|---:|---|---|
| 0 | `01A31EA0` | 全量重建：只保留临时遮断节点，其余（含永久黑名单）全部清掉，再按 subcmd 1 读入，期间不弹提示 |
| 1 | `01A2FEC0` | 增量添加，每条弹 44448「[%s]%sさんを友達に登録しました」 |
| 2 | `01A2E4B0` | 删除，每条弹 44449「[%s]%sさんを友達から削除しました」 |
| 3 | `01A2ED90` | 就地更新 ch/level/job/转职，不动标志 |
| 4 | `01A2F0A0` | 改名：`u32 count × {u8 server, dstr 旧名, dstr 新名}` |

### subcmd 0 / 1：好友列表

```text
u32 subcmd          ; 0 或 1
u32 count           ; 有符号，<0 时放弃（01A2FEF8）
count × {
  u8   server       ; ≥0xFA 时放弃本条及其后全部（01A2C655）
  u16  ch           ; → 条目 +0x24
  dstr name         ; 1–255 字节（01A2C698 ReadDStrW max 0x100）
  u8   level        ; → +0x26
  u32  job          ; → +0x28
  u8   grow         ; → +0x2C（经 019DAFB0）
  u8   bl           ; → +0x2E = (bl≠0)，即「在黑名单中」标志
  u32  tail         ; → +0x38，未见读取（High，见下）
}
```

条目读取 `01A2C600`，Confirmed。逐条插入 `01A2FCD0` 的规则（Confirmed）：

- 该 `(server,name)` 已是好友 → 插入失败，**其后条目全部不读**（`01A2FD24`→`01A2FF8B`）。所以同一份表里
  名字不能重复；玩家若对某好友做了客户端本地的临时遮断，该节点会在 subcmd 0 中保留下来，下一份全量表读到它时
  同样中断（服务端无法感知，属客户端限制）。
- 已存在但不是好友（例如只在黑名单里）→ 只置好友标志，线上的 ch/level/job/bl **不写入**（`01A2FE08`）。
- 不存在 → 整条插入。

**全量会清掉黑名单**（RQ-004）：`01A31F62 cmp byte [node+0x5F],0 / je 跳过` 只把临时遮断节点复制到临时 map，
随后清空原 map 并交换（`01A32047` 起）。`CMD 0x0078` 应答写的是同一张 map（`0111F91B → 01A2F4B0`），
所以全量之后黑名单页为空，直到再收到 `0x0078` 应答；被拉黑的好友只剩线上 `bl` 字节决定的标志，加入日期丢失。

**末尾 4 字节**（RQ-003）：只存到条目 `+0x38`（`01A2C74D`）并随条目复制（`01A2B91A`、`01A2B9EB`）；在好友/黑名单类
（`01A2A000–01A34000`）与好友窗口绘制区（`02480000–0248A000`）没有任何读取。ClientStatic / High。写 0 即可。

### subcmd 2：删除

`u32 subcmd=2, u32 count × {u8 server, dstr name(1–255 字节)}`（`01A2E4B0`）。每条调 `01A2DD70` 清好友标志，
三个标志都清零时删节点，并清掉角色表里该角色的好友记号（`01A2DF7B`）。**名字不是好友则失败，其后条目不再读**
（`01A2E571`）。Confirmed。
