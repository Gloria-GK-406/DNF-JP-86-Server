```text

u8   status         # 0 正常；0x4D 黑名单；0x5A GM；其他非 0 显示文案 328「不在线或在不同频道」
dstr name           # ≤ 30 字节
```

### 本仓实现（CurrentImplementation）

用于把私聊（[CMD 0x0011](../client-to-server/0x0011.md) mode 1、7）**投递给对方**：

| 字段 | 取值 |
|---|---|
| mode | 请求 mode 原值 |
| status | 0 |
| name | 发言者角色名 |
| srv | 0 |
| text | 请求正文原样 |

- 不给发送者回帧，与 70 相同（70Reference `086c9f74`）。
- 对方离线或名字不存在时静默，不回任何帧；这是用户决定，与 70 回 `0x15` 不同。
- **最大 body 296 字节** = 1 + 1 + 4 + 30 + 1 + 4 + 255。依据：正文超过 255 字节、发言者名字超过 30 字节的请求
  被命令拒绝（角色创建上限 18 字节，数据库无约束，所以按帧上限把关）；编码器对超限字段直接抛异常。
