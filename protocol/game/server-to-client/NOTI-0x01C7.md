## A21

**2026-08-24。** 上面的机器区由 **A12** 客户端（SHA-256 `F78F0AEA…`）的静态普查生成。
本节记录 **A21** 客户端（SHA-256 `1F8244D3…`）上不同的部分。判据除另有注明外，都是一份
A21 参照会话，归档于
[a21-world-entry-20260823.log](../../patterns/data/traces/a21-world-entry-20260823.log)
（section L 是入场序列的逐帧顺序）。

A21 在**入场**时发一次，参照 body 203 字节：

```text
[0]      u8   keyType（参照为 0）
[1..4]   u32  后续字节数（参照 198）
[5..]    99 × u16 键位，下标即动作，0x0086 表示未绑定（参照里 40 项是它）
```

`1 + 4 + 198 = 203`，闭合。**登录时另有一帧，只带账号级的一个槽（body 7）**，
两者共用同一 type 与布局。

一个从未存过键位的角色若发空表（`body = 5`），与参照差 198 字节。服务端因此在角色无存储
键位时代入一份 99 项默认表（`DefaultCharacterHotkeyTable`），逐字节转抄自参照会话。
**该表是「参照角色的键位」还是「出厂默认」没有证据**——抓包固定的是长度与布局。
