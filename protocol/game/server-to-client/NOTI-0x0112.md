## A21 客户端读取（2026-11-12）

证据：ClientStatic，`DNF.unpacked-b1-debug.exe`（SHA-256 `D7618A10…A99A`）静态反汇编；地址为 VA

[好友与黑名单客户端证据](../../../.rks-agent/tasks/friend-relations-first-batch/research/client-evidence.md)。

handler `0116F000`（RVA `00D6F000`），Confirmed：

| Offset | Size | Enc | 含义 | 证据 |
|---:|---:|---|---|---|
| 0 | 2 | `u16` | ch；0 = 下线 | `0116F03D` |
| 2 | 1 | `u8` | server | `0116F056` |
| 3 | 4+N | `dstr` | 名字，1–255 字节 | `0116F083 ReadDStrW(buf, 0x100, NULL)` |
| 3+4+N | 1 | `u8` | bl：接收者是否拉黑了此人 | `0116F097` |

处理：调 `[03A5C994]->01A2BFF0(server, name, {ch, bl≠0})`，找到节点就**覆盖** ch（`01A2C0C6`）与黑名单标志
（`01A2C0DD`），找不到返回 0。handler 不看返回值，随后无条件在聊天框打一行：

| 条件 | 字符串 | 文字 |
|---|---:|---|
| ch=0，server=自身群 | 670 | %sさんがゲームを終了しました。 |
| ch=0，server≠自身群 | 19247 | [%s]%sさんが退場しました。 |
| ch≠0，server=自身群 | 671 | %sさんが %d チャンネルに接続しました。 |
| ch≠0，server≠自身群 | 19248 | [%s]%sさんが%dチャンネルに接続しました。 |

推论（High）：发给不是观察者的人也会打出这行字，所以只能发给观察者；`bl` 必须如实填写，写 0 会清掉接收者本地
对此人的黑名单标志；server 写自身服务器群（本仓客户端为 1，见 `0x0122` 样本），否则提示带 `[服务器名]` 前缀。

**与 USER_LEAVE 的先后**（RQ-051）：本 handler 不查角色表，先后不影响它。但 ch=0 的好友只有在接收者的角色表里
**查不到**时才显示离线（见 [NOTI `0x0111` 在线显示](NOTI-0x0111.md#在线显示rq-005)），所以凡是持有该角色
CNUser 的接收者都还要收到 [NOTI `0x0006`](NOTI-0x0006.md)。两帧先后无所谓，缺一不可。
