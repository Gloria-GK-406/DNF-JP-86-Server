## 载荷

普通装备成功52B：

| 顺序 | 字段 |
|---|---|
| 1 | u8 result=1 |
| 2 | i16 罐子来源槽 |
| 3 | i16 奖励main槽 |

普通装备尾部按参照服保留，未额外命名未知语义。当前只允许单件普通装备；时装/宠物等变体不支持。
