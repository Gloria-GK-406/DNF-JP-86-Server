## 服务端实现映射

选角替换、正常退出和断线清理继续由 `SessionCleanupAnnounced` 广播本帧；它表达的是角色对应的
客户端实体生命周期已经结束，不是角色离开某个 town/area。

2026-09-15 双客户端实机路径反证了旧实现把 `0x0024 SET_USER_AREA` 跨区也映射为本帧的做法：
队长先跨区后，队友左上角队伍列表丢失队长；队友随后跨区时卡在“正在连接”。结合该 body
只有全局 `wire userId`、没有 town/area 范围，以及服务端确定性发送路径，当前结论是：
`USER_LEAVE` 会销毁客户端按该 userId 持有的角色/队员对象，连带丢失其 P2P 状态。
因此跨区改为向旧区域受众发送 `0x0018 AREA_USERS` 权威名册，不再发送本帧；真正退出或连接清理
仍发送本帧。该因果链已由服务端路径和 UI 现象关联，尚待本次改动后的双客户端实机复验。
