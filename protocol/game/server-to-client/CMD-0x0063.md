## 失败与重放

失败仅00+reason，当前映射16材料不足，13期限不支持，D2安全限制，其余17。客户端显示原因并关闭合成窗口，不读取成功载荷。

原会话重复结算请求不重发增量成功。先发01+00+两个12B空结果（26B），再当前库存快照。静态确认count0跳过消费、template0跳过产物插入并关闭7F；先后顺序避免UI临时材料恢复覆盖当前快照。恢复依赖已初始化合成窗口，不跨连接/角色，仅专用重放标记启用，通用全状态刷新不包含。
