## A21 普通与巅峰斗兽场状态

**ClientStatic / Confirmed。** `00D60560–00D60680` 以头部 `u16` 查找大厅用户，依次向该用户下的 `+0x500` 和 `+0x514` 写两个记录。每个记录读取四个 `u8` 和一个 `u32`，合计 18 字节。普通匹配类别 0 使用前者，类别 7 使用后者。记录的第三个字节等于 1 时，“开始对战”继续走斗兽场匹配而非购买。第四字节和末尾 `u32` 的表现还需实机核对。

**CurrentImplementation。** 两组按胜数、负数、进行中标记、当日开轮数和保留值 0 投影。选角进入及返回匹配大厅时刷新，购票成功时同步。CH60 实机确认大厅显示进行中的挑战以及胜场，普通对局不会改变该挑战的计数。
