### 布局（ClientStatic：读取 Confirmed，含义 High）

handler VA `01166B60`：

```text
u8   mode
u8   serverId       # 与当前服务器对象虚函数 +0x98 的返回值比较（该值来源未读出）
u8   serverGroup    # 只写入行对象 +0x1C

u16  uid
dstr name           # ≤ 29 字节
dstr text           # ≤ 511 字节
```

serverId 与 channel 都对上时走带发送者的普通分支；否则按 mode 着色并带频道信息显示，不匹配无害。
发送者名等于自己时，客户端在本地扣对应喇叭（VA `01167347` 起）。

70Reference：布局少 serverId／serverGroup，为 `u8 mode, u8 channelNo, u16 uid, name, msg`。

### 本仓实现（CurrentImplementation）

用于频道喇叭（[CMD 0x0011](../client-to-server/0x0011.md) mode 13，同频道）与服务器喇叭（11、12、57，全服），
收件人**含发言者本人**：

| 字段 | 取值 |
|---|---|
| mode | 请求 mode 原值 |
| serverId | `GameProtocol.ServerIndex`（= 1，与 NOTI 0x0001 下发同值） |
| serverGroup | 0 |
| channel | 发言者监听端口解析出的 `ChannelId`，与 NOTI 0x0001 同源 |
| uid | 发言者 `WireUserId` |
| name | 发言者角色名 |
| text | 请求正文原样 |

- 服务端扣 1 个喇叭，并在本帧之后给发言者补发 [NOTI 0x000E](NOTI-0x000E.md) 槽位绝对状态，覆盖客户端本地扣减。
- **最大 body 554 字节** = 1 + 1 + 1 + 1 + 2 + 4 + 29 + 4 + 511。依据：正文超过 511 字节、发言者名字超过 29 字节的
  请求被命令拒绝（角色创建上限 18 字节，数据库无约束，所以按帧上限把关）；编码器对超限字段直接抛异常。
