# CMD 0x010F UPGRADE_CHRONICLE 券开光结果

A21 handler `0x0111A950`（VA；RVA `0x00D1A950`）。ClientStatic / Confirmed，取证见
[客户端开光路径](../../../Document/tasks/requiem-weapon/client-re-emancipate.md)。尚无 S2C 实帧，未 ClientVerified。

失败：`u8 0, u8 错误码`。成功：`u8 1`，券值不为 5 时接 `u8 N` 与 N 行 `{u8 列表, u16 槽, u32 扣减量}`。
客户端按列表（0/0x1D 主背包，1 装扮栏）取槽，数量不大于扣减量则整格移除，否则减数。
handler 不放入任何新物品；成功提示按券值：4/6–19 为 dstr 0xEC3B「装备转换成功！」，2/3 为 0x6A3F，0/1 为 0xA511。

券 19 适用的失败码（跳表 `0x0111ACCC/0x0111AC94`）：

| 码 | 客户端文案 | 当前服务端用途 |
|---|---|---|
| 0x01 | 错误信息 | 无会话、请求无效、事务失败 |
| 0x04 | 槽中缺少物品 | 券或目标不在请求槽，或模板与请求不符（含重放） |
| 0x07 | 未修理（0x8A28） | 目标耐久未满 |
| 0x11 | 无法对当前物品使用该功能 | 券值无策略，或目标无对应 `[emancipate]` 块 |
| 0x13 | 快捷栏或穿戴中（0x8A27） | 目标在穿戴栏或快捷栏 |
| 0x16 | 缺少进化所需的道具（0x8A26） | `[input]` 或券不足 |
| 0x1B | 该物品禁止使用 | 券或目标过期、不在城镇 |
| 0xAF | 异界气息（0x8A29） | 目标增幅类型 0x80 |
| 0xD6 | 物品已锁定 | 券或目标锁定 |

另有 0x0D/0x0E（装备 Lv 过高/低）、0x1A（删除失败）、0xD9（Lv 不符），当前服务端不产生；其余码客户端静默。

当前派送顺序（CurrentImplementation）：本 CMD（扣减行为券与各材料实际扣量，账户材料按主背包 354.. 槽投影）→
各扣减槽绝对值 NOTI 0x000E（账户材料归零的槽交给 ACK 移除，不再补发）→ 目标槽先清后填，填入同 UID 的新模板。
同格换 ID 是否需要先清在本协议路径尚待实机；若异常，改为把目标槽也写进扣减行再放入。
