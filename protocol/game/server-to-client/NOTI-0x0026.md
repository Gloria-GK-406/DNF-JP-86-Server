### 当前服务端投影边界（2026-09-16）

上述“本仓不发掉落”是早期状态，现已失效。普通怪物掉落由 PVF 率表和物品池决定，死亡时进入
Cell 地面物集合，由 DungeonRun 编号，后续 `GET_ITEM` 按同一编号领取。任务的
`[monster reward item]` 则按 Cell 参与者各自携带的任务预先判定为直发产物；死亡时按仍有效的
任务和背包上限写入该角色背包，不占地面编号，也不进入本帧的掉落记录。

`+44` 是**每条记录自己的归属 actor**，不是整帧字段。普通掉落保持击杀上报者为 fallback；带领域
`OwnerCharacterId` 的专属地面物在协议投影边界解析成该参与者的 wire user id。领取路径还会再次按
领域角色校验 owner；直发任务物品不进入此协议投影。
