## 证据与样本

<!-- 人工区：重新生成不会触碰本节及其之后的一切内容。 -->

`samples/0x0252-2026-08-17-01.hex` —— 8 字节 `0F0000007F000001`。

**静态普查在这里是错的。** 索引记的长度规则是 `≥ 12`，而实机只有 8 字节。按普查写解码器会把
每一条真实帧都拒掉。原因推测是 walk 沿着一条真实发送不会走的构包路径多数了字段——这是
第一个有实机反证的静态长度错误，记在此处以免后来者再信那个 12。

本条属于[进图上报族](../../../Server/src/Dfo.Server.Protocol/Game/MapEntryReports/MapEntryReportSlices.cs)：
入场批次被客户端接受、开始加载城镇时连发的一批 fire-and-forget 上报。同族六条
（`0x0002` / `0x0023` / `0x003F` / `0x01F8` / `0x0252` / `0x02B3`）共用一个 handler。

其中**五条**客户端确实没有注册 CMD 接收 handler，所以"无响应"有普查作证。
**`0x0002` 是例外**：它注册了响应 handler `0x008C62C0`（见 [`0x0002`](0x0002.md)）。
我们对它也不回帧而客户端继续前进——那只说明**被容忍**，不说明不需要。

**2026-08-17 首次观察**，与它们同批出现的还有 `0x000F` / `0x0010`。
