成功：新人依次收到一帧 USERINFO 子类 0 名册（全部成员含新人，按 uid 排序；上游 `PvpRoomHandler` 进房，A21 `13E7340` 上游地址建立的角色记录是后续 USERINFO1 与 `0x000B` 的前提）、每名已有成员的子类 1（`+3` 路由 uid 为该成员 uid）、已有成员的 NOTI `0x000B` 端点、
本人 USERINFO 子类 1、本人 NOTI `0x000B`、CMD `0x0033` `01 + 8×u8 ready`（上游 `BuildEnterSuccessBody`）、NOTI `0x002B`（新座位）、

NOTI `0x002B`（新座位）与 USER_STATE（新人，2）；随后按离城处理原区域。经决斗邀请入房时同样投影，只是不发 CMD 成功体。
