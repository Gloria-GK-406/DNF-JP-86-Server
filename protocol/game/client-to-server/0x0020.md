## 服务端实现说明（非 ClientVerified）

服务端按上游已证实的行为跳过两字节前缀，再读 `u16 questId`，在事务内删除该角色的进行中任务；
成功回包按上游 `QuestAckBuilder.BuildGiveup` 为 `01 + u16 questId`，拒绝回包为 `00 + u8 reason`。
成功后另发进行中任务与 NPC 可接任务快照。以上经过服务端回归测试，尚未用 A21 客户端实测确认回包及通知显示。
