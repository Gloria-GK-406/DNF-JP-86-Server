队长侧保留单人队并出现“保留队伍/移除队伍”的原生选择。空 body 本身没有可写入 `.hex` 的内容。

[`PartyCommandSlice.cs`](../../../Server/src/Dfo.Server.Protocol/Game/Party/PartyCommandSlice.cs) 的
`LeavePartyDecoder` 只接受空 body。handler 在账号 transition gate 内按完整 selected-session identity
离队：

- 普通成员离开：向离开者发 `NOTI 0x0009 type=3` 清除旧队伍，再向幸存者刷新
  `0x0099 → 0x000B → 0x0009`；
- 队长离开：解散队伍并向所有原成员发 `NOTI 0x0009 type=3`；
- 迟到旧连接：精确会话校验失败，不得清掉替代会话后来加入的队伍。

断线、返回选人和同账号替代复用同一精确离队语义；本 type 自身不发送 CMD response。
