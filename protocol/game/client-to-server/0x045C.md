上游 `GameProtocolHandler` **没有为这个 type 注册任何 handler** —— 它走到分发表末尾就没了。
本仓因此把它登记成有意不回的一类（`IUnansweredReport`，debug 级日志），而不是继续留在
`Unhandled Game frame` 里：一个没实现的洞和一个照着上游不回的决定，在线上长得一模一样，
