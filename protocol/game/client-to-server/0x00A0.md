### C→S：普通礼包与选择界面

| 形态 | body | 证据与置信度 |

| 基本 | `i16 sourceSlot`，恰 2 字节 | Confirmed，RVA `00E676A0..00E676C9`；另有构包点 `016783FA` |

选择形态总长 `5 + 4*n + 5*m`；selected IDs **没有独立线级计数字段**。选项尾部 count 在 `0111B65B` 写 u8，随后 `0111B6D0` 写 ID、`0111B6E1` 写属性。两个 context 来自 UI 状态，暂不赋予职业、性别等未经确认的语义。

### S→C：CMD 0x00A0 奖励弹窗
