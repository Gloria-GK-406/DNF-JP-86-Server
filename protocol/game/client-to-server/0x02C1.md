这里的“+29”指36字节尾部第30个字节，不是29个flag。解析时只在值等于1时设角色保护字段+39C。

### 缓存、模式与回退

- 悬停索引须有效并与当前悬停位置一致；无缓存且计时条件满足才发查询，随后启动参数为`0x12C`的计时器。
  未独立确认计时器单位，不把该值直接记为300毫秒。
- 模式0完整复制六整数；模式2将异界两项与暗精灵项改为-1；模式1还将镜像、绝望已用改为-1。
  业务名称未知，本服使用0。其他模式不会经过这些完整赋值分支。
- 镜像值-1回退满10；异界普通-1回退规则上限、额外-1回退0；暗精灵-1回退规则上限。
  绝望“回退满次数”的判断实际复用镜像缓存值是否为-1，不是单独测试绝望字段。
  层数没有-1特殊分支。不要混搭不一致的回退标记，更不能把显示回退当成准入许可。
- 回包用错误索引会更新错误角色缓存；刷新只在当前悬停角色匹配时继续。
