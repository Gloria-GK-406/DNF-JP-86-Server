## A21

地址均为 VA（RVA = VA − `0x400000`，见 [game-frame](../../patterns/game-frame.md)），客户端 SHA-256
`1F8244D3…`（全值见 [evidence.md](../../evidence.md)）。来源标签：ClientStatic = 该客户端静态反汇编；
70Reference = 70 版服务端 `df_game_r` 对照；CurrentImplementation = 本仓实现。**无实机抓包或实机确认**；
下文唯一的线级字节是 2026-09-11 的样本。

本请求打开 1:1 对话窗口。相关协议：[NOTI 0x016A](../server-to-client/NOTI-0x016A.md)（开窗）、
[CMD 0x0011](0x0011.md) mode 43（窗口内发言）、[NOTI 0x016F](../server-to-client/NOTI-0x016F.md)（对方的话）、
[CMD 0x01A5](0x01A5.md)（关窗）、[NOTI 0x016E](../server-to-client/NOTI-0x016E.md)（对方离开）。

### 请求布局（ClientStatic，Confirmed）

构包函数 VA `024E7EB0`（机器区构包点 RVA `0x020E7ED3` 在其中），本 type 只有这一个构包点：

```text
dstr targetName    # i32 长度 + 字节；body 只有这一项
```

### 客户端行为（ClientStatic，High）

- 入口为玩家右键菜单（VA `02596311`）等，统一经 VA `024EAB20` 发出。客户端选项 `0x1B`／`0x1C` 开启时
  客户端自行拦截，不发送。
- 发送后**不本地开窗、不计时、不提示**。
- 特殊状态：`[game+0xF48]` ∈ {8, 0xD, 0x14, 0x16, 0x17, 0x18}（判定 VA `0163D300`／`0163D150`，含决斗场）时，
  `024EAB20` 不发本请求，改为本地建窗，会话 id 保持 -1；该窗口内的发言因此是 0x0011 mode 33（跨服情形 37），
  见 [0x0011](0x0011.md#会话窗口内发言)。

### 应答：经 NOTI 0x016A 推送，没有 CMD 应答

机器区由「客户端未注册 CMD 表 handler」推断本请求「很可能是 fire-and-forget 的上报」。前半句成立：
没有 CMD `0x01A3` 应答，服务端不回 CMD 帧。后半句不成立：结果由 [NOTI 0x016A](../server-to-client/NOTI-0x016A.md)
推给双方，客户端**只有收到它才建窗**（ClientStatic，Confirmed，handler VA `024EAFA0`）。客户端没有超时，
服务端不回则什么都不出现。

70Reference（Confirmed）：70 没有实现 1:1 对话。`PacketDispatcher::PacketDispatcher()`（`08590a2e`）中
0x1A2–0x1A7 槽位为空，CMD `0x01A3`–`0x01A6` 经 `doDispatch`（`08594922`）返回 0 被静默丢弃。

### 本仓实现（CurrentImplementation）

代码：[`OneToOneChat/`](../../../Server/src/Dfo.Server.Protocol/Game/OneToOneChat/)（`OpenConversationDecoder`、
`GameOpenConversationCommandHandler`），会话保存在内存中的
[`ChatConversationDomainService`](../../../Server/src/Dfo.Server.Application/Chat/ChatConversationDomainService.cs)。

- **解码**：body 必须恰为 `4 + len`，且 1 ≤ len ≤ 64（与私聊对方名字同一上限），否则抛 `InvalidDataException`，
  连接按既有解码失败路径断开，不改状态。
- **开窗**：分配会话 id（不发 0，也不发 `0xFFFFFFFF`——那是客户端窗口的 -1），给发起方与目标各推一条
  NOTI 0x016A，名单为 [对方, 自己]。
- **不回任何帧**：发起方不在世界内；目标名不存在、不在世界内或就是自己；任一方存储的名字为空或超过 127 字节；
  两人之间已有会话且双方仍在开窗时的那个选中会话里（从任一方再次请求）——重发 0x016A 会让双方各多一个窗口。
  若其中一方已换了选中会话（重登、换频道）而旧会话未清理，旧会话作废，开新会话。
- **不发结果码 77／100／101**：客户端对 100、101 本就静默；77 是黑名单提示，本服尚无屏蔽名单检查
  （`ChatPreSendChecks` 当前恒通过）。
