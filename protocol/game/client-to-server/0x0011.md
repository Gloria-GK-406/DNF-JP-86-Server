### 请求布局（ClientStatic，Confirmed）

主发送函数 VA `01A62E20`，构包 VA `01A63C1F`：

```text
u8   mode
u16  targetUid
u32  aux                      # 含义见下表
dstr text                     # i32 长度 + 字节
-- 仅 mode ∈ {1, 7, 36, 37, 38} 追加（尾部表 VA 01A64434）--
dstr targetName
u8   targetServerGroup
```

机器区 offset 7 之后两行 `?` 即这两个尾部字段。正文：客户端发送前要求少于 255 个宽字符，并把
`%` 替换为空格。dstr 读取原语 ReadDStrW（VA `0274FCB0`）要求 `0 < len < max`。

### u32 aux（High）

| mode | aux 内容 |
|---|---|
| 喇叭类（下列物品表中的 mode） | 所用喇叭的**背包槽位索引** |
| 1:1 会话 43、48 | 会话 id |
| 其余 | 0 |

物品 id 不上线，由客户端写死在表 VA `01A6426C`：11→36、12→898、13→37、14→1120、15→2660655、
34→2680400、50→10002758、56→9999820、57→10151255。

### 会话窗口内发言

1:1 对话窗口（[CMD 0x01A3](0x01A3.md) → [NOTI 0x016A](../server-to-client/NOTI-0x016A.md) 所开）有自己的发送函数
VA `024EF150`，构包点 VA `024EF38B`（机器区第四个构包点 RVA `0x020EF38B`）。布局与上面相同，但**尾部两字段无条件写入**
（ClientStatic，Confirmed）：

```text
u8   mode           # 窗口会话 id ≠ -1 时 43；= -1 时 33；跨服情形 37
u16  uid            # 按名字查到的 uid，查不到为 0
u32  aux            # mode 43 时为会话 id
dstr text
dstr name           # 发送者自己的名字，不是对方
u8   server         # 0
```

- 发出后客户端把自己的话写进窗口，不进主聊天框（High）；窗口路径没有连发冷却（High）。
- 会话 id 为 -1 的窗口来自 0x01A3 的「特殊状态」（含决斗场）下的本地建窗，因此其中的发言是 mode 33／37（High）。
- 应答 handler（下节）对拒绝按通用错误表弹框，与 mode 无关；窗口里已显示的那句话不会回滚（High）。

**不采用上游含义**：上游参照服务端把 mode 43 的尾部 dstr 注释为目标名，与上面的构包不符，实际是发送者自己的名字。

### 本仓实现（CurrentImplementation）

代码：[`Server/src/Dfo.Server.Protocol/Game/SendChat/`](../../../Server/src/Dfo.Server.Protocol/Game/SendChat/)。
映射如下，其余 mode 一律拒绝（含 5、8、33、37、48 及任何未映射值）：

| 种类 | mode | 投递 |
|---|---|---|
| 区域 | 3、45、46 | [NOTI 0x000C](../server-to-client/NOTI-0x000C.md)，含发言者 |
| 队伍 | 2、9 | NOTI 0x000C，含发言者 |
| 私聊 | 1、7 | [NOTI 0x0041](../server-to-client/NOTI-0x0041.md)，只给对方 |
| 公会 | 6 | 静默（范围恒空） |
| 频道喇叭 | 13（物品 37） | [NOTI 0x0076](../server-to-client/NOTI-0x0076.md)，同频道 |
| 服务器喇叭 | 11（36）、12（898）、57（10151255） | NOTI 0x0076，全服 |
| 1:1 会话 | 43 | [NOTI 0x016F](../server-to-client/NOTI-0x016F.md)，只给会话对方 |

- **应答**：成功与静默（无队、不在区域、私聊对方不存在或离线、公会、mode 43 的任何失败）不回；拒绝回 `[0, 0x11]`。
  `0x11` 取自 70，A21 显示待实机。
- **拒绝条件**（mode 43 除外）：mode 未映射；正文为空或超过所投 NOTI 的正文上限（0x000C／0x0041 为 255 字节，0x0076 为
  511 字节），不截断；喇叭槽位无法映射、槽位物品与 mode 不符或扣除失败；发言者名字超过所投 NOTI 的名字上限。
- **mode 43**：aux 作会话 id。发言者须以当前选中会话是该会话的成员，正文 1..1023 字节，发言者存储名字
  1..127 字节；满足则给会话另一方（须仍在开窗时那个选中会话里）推 NOTI 0x016F，sender 取存储名字。发言者本人不收，
  因为客户端已本地显示。任何一项不满足——包括会话已因对方关窗或下线而结束——都**静默丢弃，不回 `[0, 0x11]`**，
  否则客户端会对一句已显示在窗口里的话弹错误框。尾部 dstr 与 u8 不读（mode 43 不在尾部 mode 集合 {1, 7, 36, 37, 38} 内，
  多余字节按下条规则忽略）。
- **mode 33／37**（会话 id 为 -1 的本地窗口）仍按未映射 mode 回 `[0, 0x11]`：没有服务端会话可投递。
- **解码**：长度不足、正文长度字段 < 0 或 > 1024、对方名字长度 > 64 时抛 `InvalidDataException`，连接按
  既有解码失败路径断开（`GameNetworkPlugin.Decode` 记 Error 后重抛），不投递、不改状态。已知字段之后的
  多余字节不读也不拒绝。dstr 字节原样转发，不做编码转换。
