## A21

地址均为 VA（RVA = VA − `0x400000`，见 [game-frame](../../patterns/game-frame.md)），客户端 SHA-256
`1F8244D3…`（全值见 [evidence.md](../../evidence.md)）。来源标签：ClientStatic = 该客户端静态反汇编；

1:1 对话窗口关闭时发出，属于 [CMD 0x01A3](0x01A3.md) 所开的会话。

### 请求布局（ClientStatic，Confirmed）

关窗函数 VA `024EEE70`，构包点 VA `024EEEFE`：

```text
u32 conversationId   # 窗口 +0x230，即 NOTI 0x016A 下发的 id
```

### 客户端行为（ClientStatic，High）

- 只在窗口会话 id ≠ -1 时发送；本地建的窗口（id = -1，见 0x01A3「特殊状态」）关闭时不发。
- 发送后把窗口 id 置 -1 并摘除窗口，不等应答。客户端没有本 type 的 CMD 应答 handler（机器区），
  机器区「服务端不必回帧」对本条成立。
- 对方离开（[NOTI 0x016E](../server-to-client/NOTI-0x016E.md)）不会让客户端关窗或发本请求。

70Reference（Confirmed）：70 不处理本 type，收到后静默丢弃（见 [0x01A3](0x01A3.md)）。

### 本仓实现（CurrentImplementation）

代码：[`OneToOneChat/`](../../../Server/src/Dfo.Server.Protocol/Game/OneToOneChat/)（`LeaveConversationDecoder`、
`GameLeaveConversationCommandHandler`）。

- **解码**：body 必须恰为 4 字节，否则抛 `InvalidDataException`，连接按既有解码失败路径断开。
- **结束会话**：发送者在世界内，且 id 指向它以当前选中会话参与的会话时，整条会话结束；若对方仍在开窗时的
  那个选中会话里，给对方推 [NOTI 0x016E](../server-to-client/NOTI-0x016E.md)（id + 离开者名字）。离开者不收任何帧。
- **静默忽略**：不在世界内、id 不存在、发送者不是成员，或只是该角色旧选中会话的成员。
- 会话结束后对方窗口仍在、id 不变，客户端仍可在其中发 0x0011 mode 43；服务端已找不到该会话，这些发言被静默丢弃
  （见 [0x0011](0x0011.md#会话窗口内发言)）。
- **另一种结束**：任一成员的选中会话结束（下线、回选人、换频道）时，`SelectedSessionCleanupService` 结束它参与的
  全部会话；清理计划的三个投递点（断线 `CleanupNotificationDelivery`、回选人与选角顶替旧会话的命令内投递）都经
  `ConversationDepartureNotices` 在其余清理通知之后给仍在原选中会话的留守方各推一条 NOTI 0x016E。
