### C→S：带装扮属性的礼包入口

**纠正机器区 offset=0 的标签：头部两字节是来源礼包槽位，不是装扮模板 ID。** 模板 ID 位于重复组 offset=0，即整个 body offset=3 起。

body：`i16 sourceSlot, u8 n, (i32 avatarItemId, u8 ability)[n]`，严格 `3+5*n` 字节。Confirmed：RVA `00EBBAA7` 写来源槽位、`00EBBACC` 写 count、`00EBBB29` 写模板 ID、`00EBBB3A` 写属性。

当前实现 n=0..32；n>0 的每个选项必须命中 PVF，ID 不重复，且覆盖此次要创建的全部装扮。n=0 允许通过此共用界面开启没有装扮的普通礼包（例如宠物胶囊）；服务端会再次根据礼包真实内容确认业务类型，不能靠省略属性把装扮礼包变成普通礼包。
