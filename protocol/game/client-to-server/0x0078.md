不匹配待答请求。ClientStatic / High。

本应答写入的名单与 [NOTI `0x0111`](../server-to-client/NOTI-0x0111.md) 是同一张表，`0x0111` 的全量形态会把黑名单条目清掉，

- 切片 `Server/src/Dfo.Server.Protocol/Game/Blacklist/`：`BlacklistListDecoder` 不读 body（请求没有字段，多余字节改变不了应答），
  `GameBlacklistListCommandHandler` 在只读单元里构建列表并以 CMD 回包。发起者不在世界中回 `[1][0]`。
- 应答 `BlacklistListResponse`、编码器与构建 `BlacklistListBuilder.BuildAsync` 在 Game 层
  `Server/src/Dfo.Server.Protocol/Game/BlacklistFrames.cs`，好友全量（NOTI `0x0111` subcmd 0）之后的补发复用同一构建。
- 条目顺序取关系服务的顺序（加入时间，再按目标 ID）；名字取目标的当前名；日期把加入时间换算到服务器本地时区
  （`TimeProvider.LocalTimeZone`）后取年−1900、月−1、日。
- 名字字节上限：客户端只收 1–30 字节。本服创建上限 18 字节，超出者只可能来自旧库；这样的条目跳过并记 Warning，
  不让一条坏名字使整帧错位。条数受关系上限 64 约束，编码器另拒绝超过 255 条与超出 1900–2155 的年份。
