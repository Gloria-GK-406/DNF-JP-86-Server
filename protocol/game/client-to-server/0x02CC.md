## A21 响应布局（2026-09-09）

客户端 `D1E0CB` 先 ReadI32 长度，`D1E0E4 / D1E0ED` 每项读两个 i32；
`D1E111` 再读第二个长度，`D1E124 / D1E12D` 再循环读成对 i32。
指令见[摘录](../../patterns/data/probes/a21-shop-20260909.md)。

```text
u8 ok (=1)
i32 countA
countA * (i32 itemId, i32 purchasedCount)
i32 countB
countB * (i32 field0, i32 field1)
```

两张列表的长度和项宽度 **Confirmed**；第一张列表的累计购买语义 **High**（与请求 NPC、
商品限购声明及参照实现交叉验证）。第二列表业务含义未确认，本仓与参照实现一样填空。
空成功 body 为 `01 00000000 00000000`，**9 字节**，不能省略第二长度。
失败沿共用 CMD 信封返回 `00 00`。
