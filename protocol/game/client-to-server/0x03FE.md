三个构包器：`0087C490` 保管箱内拖动（A{1,源格},B{1,目标格}）；`0087E5E0` 房间→仓库收回（A{0,房间槽},B{1,同 ID 堆叠或首个空格}，无空格提示 `0x54BF`）；
`00880E20` 仓库→房间摆放（A{1,仓库格},B{0,房间槽}）。**个人背包↔情侣仓库不走本协议。**

成功结果应由 NOTI `0x03DA`（op=0，A 源 B 目标）或 `0x03DB` 下发。
