## A21 静态复核（2026-09-18）

`RVA 0x01FEC800` 的两个构包分支都是 8 字节：
`u8 0 | u16 slot/FFFF | u16 material/FFFF | u16 0 | u8 flag`。
但 `RVA 0x0103FC10` 的另一分支是 **7 字节**：
`u8 0 | u16 FFFF | u16 FFFF | u16 1`。当前固定 8 字节 decoder
不能接收后一种形状；其触发条件尚未由运行时证明，不能据此直接改业务收费规则。
成功响应 handler `RVA 0x00D22C40` 消费
`01 | u32 | u8 | u16 | u16`（10 字节）。`u32` 很可能是修后金币，
但这段指令只证明读取宽度/次序；失败分支还分别检查 `0x0A` 和若干其他 reason。
详见[`A21 静态复核`](../../patterns/data/probes/a21-quest-repair-durability-readers-20260918.md)。
普通修理的实际往返与显示仍需成对帧；7 字节路径需先证实触发动作。
