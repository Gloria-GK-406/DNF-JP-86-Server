## A21 证据与当前实现

当前阶段：**实现服务端功能**；尚未归档当前服务端上的真实客户端回城结果。

A21 客户端静态逆向已直接闭合请求体：`Docs/a21-units/unit-012.md` 由客户端自己的包名表确认
`EPLP_COMMAND = 0x0048`，并在构包点确认按顺序写入两个 `u8`（`event`、`btnIndex`）。参照会话转录：

```text
C→S CMD 0x0048  01 02
S→C CMD 0x0048  01 01 02
```

其中响应首字节 `01` 是 CMD 成功信封，后两字节回显请求。该转录保存在
`LeaveDungeonTests` 的独立常量中，避免错误常量同时改变请求与响应测试而自洽通过；原始参照日志
`packet_log.upstream-killexp-20260827.txt` 未归档进本仓，因此这份转录不能冒充本仓实机样本。

当前实现位于 `Game/DungeonClear/LeaveDungeonSlice.cs`：`EplpCommandDecoder` 要求 2 字节，
`EplpCommandResponseEncoder` 发送上述 3 字节响应；`state == 1` 时结束运行并在 ACK 后恢复城镇投影，
其他 state 只回显、不结束运行。`LeaveDungeonTests` 覆盖请求向量、截断、响应字节、消息顺序和无会话分支。

触发与完整顺序属于流程层，见 [world-entry](../../patterns/world-entry.md#房间规则与离开副本同日第二次实机)。
