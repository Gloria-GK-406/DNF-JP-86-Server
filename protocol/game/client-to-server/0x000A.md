## 服务端实现映射与行为

[`PartyCommandSlice.cs`](../../../Server/src/Dfo.Server.Protocol/Game/Party/PartyCommandSlice.cs) 的
`RequestPeerDecoder` 严格拒绝 7/9 以外长度；`RequestPeerHandler` 只消费类型 0。邀请者和目标必须
都是当前选中角色且站在城镇，双方账号 gate 按稳定顺序取得，并在 gate 内重读精确 identity，
因此替代会话不能继承旧邀请。成功只向目标精确会话推送 `NOTI 0x0007`；不发送 CMD response。
