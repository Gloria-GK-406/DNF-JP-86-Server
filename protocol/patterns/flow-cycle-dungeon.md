## 正常流程

| 顺序 | 方向/协议 | 责任与状态变化 |
|---|---|---|
| 1 | C2S CMD000F | 打开选图上下文；普通交互通常目标为 0，重试可能携带旧地图 |
| 2 | 客户端本地 | 按当前区域 PVF 循环候选池选出地图/任务对 |
| 3 | C2S CMD0308 | 8B：`u32 dungeonId + u32 questId`；服务端校验合法配对、资格和连接代际，绑定 Cycle 意图 |
| 4 | S2C CMD0308 | 成功 9B：`01 + u32(1) + u32 questId`；失败 1B：`00`。只确认准备，不接任务、不建副本、不扣消耗 |
| 5 | C2S CMD001F | 客户端按成功响应继续接取任务；服务端核对本次 Cycle 配对，相同任务重复接取幂等 |
| 6 | C2S CMD0010 | 接取成功后客户端发正式入场；按 Cycle 意图选 active quest maze，执行准入并冻结实际难度 |
| 7 | S2C 入场投影 | 复用正常入场与 NOTI001C/001D，投影本局地图、实际难度及已创建 Cell；加载/战斗复用通用运行时 |
| 8 | 战斗及任务 | Cell 权威身份处理死亡、掉落和任务推进；DungeonMapCleared 只更新匹配的 clear-map 目标并同步进度；循环任务保留，等待客户端提交或放弃请求 |
| 9 | S2C NOTI0025/0023 | 即时击杀奖励和结算展示分开；0023 逐对象条目取个人已发奖账本，不再次加经验；翻牌尾部按变长列表推进 |

循环地图随机选择发生在客户端；服务端验证请求配对及资格，不另外随机出一个不同地图。
CMD0010 请求难度是期望值；服务端只从本地图支持且已解锁的难度中选最近值，同距选低，NOTI001C 同步实际值。
区域 `[difficulty level]` 未证实为固定入场难度，不能用它强行覆盖请求。
