# A21 实机会话：进城成功、自动进副本、断在副本装载（2026-08-25）

由 A21 客户端真实走完「启动 → 频道 → 选人 → 进城」的一次会话，帧序由记录型中转
（`scratchpad/proxy.py`，7001→17001 / 10011→20011）重组而得。
**客户端侧抓帧在这台 A21 上不可用**——`0100_NetworkHook` 与 `0050_A21RuntimeFix`
抢同一批 hook（cipher passthrough / socket staging），插件初始化直接失败并使宿主中止。
所以本记录是中转看到的字节，不含客户端的字段切分。

## 结果

- **进城成功且保持连接。** 此前「进城后约一分钟静默退出」的形状消失。
- **客户端自己发出了 `0x000F ENTER_SELECT_DUNGEON`**（body `10 27 00 00` = 10000），
  没有经过选副本界面——一级角色首次进城会被直接拉进新手副本，与参照会话同形。
- 随后 `0x0010 SELECT_DUNGEON`、`0x008F CHANGE_TUTORIAL_FLAG`、`0x0252 SECURITY_STATUS`。
- **断点在副本装载**：服务端答完 `0x001C` / `0x001D` 之后客户端关闭连接，界面弹「网络连接中断」。

## 副本段与参照的差异（下一步要做的）

| 客户端发 | 参照答 | 本仓答 |
|---|---|---|
| `0x000F` | NOTI `0x0002`(519)、**CMD `0x000F`(1)**、NOTI `0x0003`(4)、NOTI `0x001A`(1) | **NOTI `0x0017`(10)**、NOTI `0x0002`(173)、NOTI `0x0003`(4)、NOTI `0x001A`(1) |
| `0x0010` | **CMD `0x000F`(1)**、NOTI `0x001B`(**37**)、NOTI `0x019F`(2)、NOTI `0x001C`(**32**)、NOTI `0x001D`(**23**) | NOTI `0x001B`(**19**)、NOTI `0x001C`(**30**)、NOTI `0x001D`(**21**)、NOTI `0x019F`(2) |
| `0x008F` | CMD `0x008F`(2) | **不答** |
| `0x0252` | CMD `0x0252`(6) | **不答** |

`NOTI 0x0017 USER_AREA` 参照在整局 458 帧里只在**最后回城**时发过两次，选副本时不发。
