# 拍卖行协议族：市场字节、应答信封与列表记录

本页记录拍卖族协议（CMD `0x00B6`–`0x00BD`、`0x014E`，NOTI `0x00B7`）共享的事实。
各协议的字段布局在其协议页人工区；拍卖行的业务规则与领域设计不在本库，见服务端仓
`Document/` 下的拍卖行实现方案与 `Server/src/Dfo.Server.Application/Auction/`。

截至 2026-11-13，本页结论的证据等级如下：

- **本仓没有 A21 抓包，也没有运行时读取跟踪。**
- 布局来自参照服务端 ServerS4A21 在同一份 A21 exe（SHA-256 `1F8244D3…20B00DD`）上的静态分析与实测转述，属于效力顺序第 5 级的上游线索。
- 参照源里的 VA 减去 `0x400000` 等于本仓地址；例如其 `0x01455D60` 即本仓 `0x01055D60`。
- 本仓 CurrentImplementation 按这些线索实现，待实机核对后再升级证据。

## 市场字节

除 `0x014E` 外，每条拍卖 CMD 的 body[0] 是市场（70 的 `PAY_TYPE`）：0 为物品拍卖（金币计价，客户端窗口 7），1 为金币寄售（点券计价，窗口 8）。

70Reference 依据：

- df_game_r `IsAuctionServerDisconnected(u8)` 按此字节选 `CAuctionServerProxy` 或 `CCeraAuctionServerProxy`；
- 错误包为 `CUser::SendCmdErrorPacket(cmd, reason, pay_type)`。

两种市场的同一 opcode 长度不同。只有 `0x00B8` 两边都是 9 字节，只能靠这个字节区分。

`0x00BC`、`0x00BD` 的请求只有 1 字节：

- 上游认为它无法区分市场；
- 第三方实现按 body[0]==1 判寄售，与 70 的 `PAY_TYPE` 一致；
- 本仓按市场字节处理，**待抓包确认**。

## 应答信封

所有拍卖应答都与请求同号。

| 情形 | 格式 |
|---|---|
| 成功 | `[1][市场]`，客户端按 body[1] 选窗口（上游：`0x00B7` ACK 读取点 `0x00D26D8F` 附近） |
| 拒绝 | `[0][原因码][市场]`（70 `Inter_AuctionResultRegist` 写 `result, reason, pay_type`） |
| `0x014E` | 没有市场字节：成功 `[1]`，拒绝 `[0][原因码]` |

**两种搜索 `0x00BA`、`0x00BB` 都以 type `0x00BA` 应答**：上游注释称 ACK 注册表把 BA 映射到读取者，没有 BB；70 的 `Dispatcher_AuctionSearchByNoItmeKey` 回包也写搜索 by key 的号。

## 原因码

客户端拒绝控制器（上游 `0x01455D60`，即本仓 `0x01055D60`）对 11..214 查跳转表：

- 有文案的是 `0x8C..0x9E`；
- `0x7B`、`0xCE` 等 6 个码直接返回，不提示。

本仓用的码与文案：

| 码 | 文案 |
|---|---|
| `0x8C` | 拍卖行关闭 |
| `0x90` | 金币不足 |
| `0x91` | 不可上架 |
| `0x92` | 超持有数 |
| `0x94` | 缺物品 |
| `0x95` | 需优惠券 |
| `0x96` | 不存在该物品 |
| `0x97` | 超上架上限 |
| `0x98` | 价格错误 |
| `0x9A` | 无权限 |
| `0x9B` | 不能竞拍自己的物品 |
| `0x9C` | 已完成竞拍 |
| `0x9D` | 竞拍金额不符 |

- 文案对应来自上游的连点测试。
- 70 拍卖进程内部码（36、43、45、46、47）对应到哪个客户端码，是按文案推断的，`TransErrToReason` 尚未反汇编确认。

## 列表记录

三种列表共用这些字段：

- 8 字节订单身份；
- 当前价（无竞价时 `0xFFFFFFFF`，否则为当前出价或起拍价）；
- 一口价（无为 `0xFFFFFFFF`）；
- 13 字节卖家名（以 0 结尾）；
- u8 剩余小时；
- 117 字节物品显示：83 字节核心 + 30 字节时装镶嵌 + 4 字节颜色。

各列表的记录长度与偏移：

| 列表 | 记录长度 | 主要偏移 |
|---|---:|---|
| 搜索（`0x00BA`） | 168 | 身份 0、当前价 9、一口价 13、卖家名 21、小时 42、物品 43 |
| 我的上架（`0x00BC`） | 151 | 身份 0、当前价 8、一口价 12、卖家名 16、小时 29、物品 30 |
| 我的竞拍（`0x00BD`） | 159 | 身份 0、当前价 8、一口价 12、卖家名 16、小时 37、物品 38 |

**物品显示**：

- 偏移 6 是数量：堆叠物写剩余数量，装备写实例值。
- 偏移 1 是物品 ID，寄售写档位物品 ID。

**订单身份**：本仓在低 32 位写挂单号，高 32 位写 0。寄售的 `0x00B9` 只回传 u32 挂单号，与此一致。

**剩余小时**按 70 `AuctionDictionary::getExpiringTime` 计算：剩余不超过 3600 秒时为 1，否则为 `剩余秒/3600+1`。
